# 🏷️→🧍 ステッカー3D化ツール

ステッカーやカードの写真から被写体を自動で切り抜き、ぷっくり膨らんだ3Dモデルにする単一HTMLツールです。すべてブラウザ内で処理され、画像は外部に送信されません。

## 使い方

`index.html` をブラウザで開き（ダブルクリックでOK・サーバー不要）、写真をドラッグ＆ドロップするだけです。

1. **切り抜き** — 写真の外周から背景色を学習し、被写体を自動抽出。囲まれた背景（腕と胴の隙間など）が残ったらプレビューをクリックして除去。「背景除去の強さ」で感度を調整できます
2. **向き** — 主成分分析で自動的に縦向きへ補正。上下が逆なら「180°回転」、傾きは微調整スライダーで
3. **立体化** — 輪郭からの距離に応じて膨らませた両面メッシュを生成（細い部分は薄く、太い部分は丸く）。「膨らみ」で厚みを調整
4. **書き出し** — `GLB保存`（Blender / Unity / PlayCanvas / 各種3Dビューアで利用可）、`透過PNG保存`（切り抜き画像）

## 仕組み

- 背景除去: 外周フレームの色ヒストグラムから背景パレットを構築 → パレットに近い色を外周から連結拡張 → 最大成分抽出・小穴埋め・1pxエロージョン
- 向き補正: 前景ピクセルの共分散行列から主軸角を推定（PCA）
- 立体化: チャンファー距離変換 → 飽和カーブで高さマップ化 → 前面/背面ミラーの三角形メッシュ（輪郭で閉合）、写真をそのままテクスチャに
- 描画/書き出し: [three.js](https://threejs.org/)（CDN・ビルド不要）、GLTFExporter

## 動作環境

モダンブラウザ（Chrome / Edge / Safari / Firefox）。CDNからthree.jsを読み込むため初回はネット接続が必要です。
