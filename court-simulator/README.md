# ELITE COURT シミュレーター（プロトタイプ）

BASE SPORTS PERFORMANCE（basesp.jp）向けのコート床材 3D シミュレーター試作版です。
`index.html` をブラウザで開くだけで動作します（three.js 同梱・オフライン可）。

## 機能

### 競技コート切替（6種目）
- バスケットボール 3on3（屋外 15×11m・FIBA 3x3 準拠ライン）
- バスケットボール 屋内（28×15m・3Pアーク / キー / ノーチャージ）
- ハンドボール（40×20m・6mライン / 9m破線 / 7mスロー）
- フットサル（40×20m・ペナルティエリア / センターサークル / コーナーアーク）
- テニス（23.77×10.97m・シングルス / サービスライン / ネット）
- テーブルテニス（卓球台 3D モデル付き）

各種目にゴール・フープ・ネット等の 3D 用具を自動配置します。

### 床材 3種（basesp.jp/court.html 準拠）
| 床材 | タイル | 用途 | カラー |
|---|---|---|---|
| ELITE COURT PRO | 304.8×304.8×21mm | 屋内外 | 12色 |
| ELITE COURT CONTROL | 307.1×307.1×12mm | 屋外 | 10色（参考色） |
| ELITE COURT SMOOTH | 304×304×14.55mm | 屋内・木目調 | 木目トーン（参考） |

- タイル目地・表面パターン（トラス / パンチング / 板張り）を床テクスチャで再現
- 左下に**タイル構造の 3D モデル**（表面プレート＋リブ格子＋TPEクッション脚＋連結フック）を実寸比で表示
- カラーチャートは「メイン（コート内）/ サブ（外周）/ アクセント（キーエリア等）/ ライン」の 4 ゾーンに適用可能
- 必要タイル枚数・箱数・概算重量を自動計算

### ブース配置（12種類）
テントブース / キッチンカー / 受付ブース / ベンチ / 観客スタンド / パラソル席 /
のぼり旗 / 自動販売機 / ステージ / 仮設トイレ / ゴミステーション / スコアボード

- パレットからクリックでコート外周に自動配置
- **ドラッグで自由に移動**（0.1m スナップ）
- 選択後に 45° 回転・複製・削除（キーボード: R = 回転, Delete = 削除）

## 操作
- 左ドラッグ: 視点回転 / Shift or 右ドラッグ: パン / ホイール: ズーム
- ブースをクリック: 選択 / ドラッグ: 移動
- 下部ボタン: 俯瞰 / 真上 / サイド / 自動回転
