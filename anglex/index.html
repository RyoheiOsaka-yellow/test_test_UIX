考え方（Revit 準拠）: ファミリ（パラメトリック定義）→ タイプ（寸法セット）→ インスタンス（配置）。タイプ パラメータ[T]の変更は同タイプ全てに、インスタンス パラメータ[I]は1体のみに反映。幾何・重量・集計・見積は同じ部品リストから生成（単一ソース）。
操作: 左ドラッグ回転 / 右ドラッグ平行移動 / ホイール拡縮 / クリック選択 / ダブルクリック＝その部材を画面中央へ / C 選択部材を中央へ / F 全体表示 / ✋ 手のひら＝左ドラッグで画面を掴んで移動 / G 移動 / R 回転 / Delete 削除 / Ctrl+Z 元に戻す。
分解・CAD色: 「分解図」で選択部材を部品ごとにバラし（スライダー・バルーン番号・部品表、行クリックでその部品だけ表示）、「個別部材化」で組立品を単材・板のインスタンスへ。表示スタイル「CAD 図面色」は図面ビューと同じ暗背景・役割色（柱=青 / 梁=緑 / ベース=青緑 / ガセット=紫 / 方杖=黄 / 支持金物=橙 / 配管=水色）で 3D と図面を照合できます。
接合: 「接合」→ 2部材をクリック → 溶接 or ボルト。指示入力例: 「MF-1 と LB-1 を隅肉溶接 6 両側」「PL-1 を MF-1 に M12 ボルト 4本 @100 で接合」「MF-1 に φ15 穴 2個 @100 端から50 脚A」。
確認・補正: 図面から 3D 化した部材には、溶接・穴・アンカー・図面根拠など人が必ず確認する箇所が「確認事項」として付き、3D に旗（⚑）で表示。プロパティの確認事項から「確認済」「溶接指示」「穴あけ指示」を行うと 3D・集計・見積に同期。「ズレ補正」は隙間・レベル・穴位置・配管位置を検出して自動修正。「作業を保存」（Ctrl+Shift+S）で名前付きスナップショット、「作業履歴」から復元。
多社ワークフロー: A社（見積作成）→ B社（利益上乗せのみ）→ C社（工場原価のみ）。各社が触れる項目はフィールド単位で制限され、受け渡しごとに改訂凍結・監査ログ。
