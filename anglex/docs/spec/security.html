データは社内で完結

社内サーバー（既存仮想環境可）に配置。外部通信なし。オフライン版あり。クラウドは貴社専用

2

外部 AI に送らない

図面認識・見積はサーバー／PC 内で処理。外部生成 AI 連携は標準で無効、貴社判断でオン

3

権限で項目単位に分離

営業所・販売・工場で見える列を分ける。画面の出し分けでなくサーバー側でも検証

4

作成・編集・受け渡し・確定・差戻しを日時・会社・担当・前後の値で記録。受け渡しごとに改訂を凍結

Q. 暗号化は？ 通信は HTTPS（社内の IIS / nginx で付与）。保存データは貴社サーバーのディスク暗号化（BitLocker / LUKS）を推奨。

Q. ID 管理・多要素認証は？ 現状はサーバーのアカウント管理（営業所 20 ID ＋ 工場 1〜2 ID）。Active Directory / Entra ID 連携は本導入の要件として対応。

Q. 第三者診断は？ 本番展開前に脆弱性診断を実施する計画。

Q. バックアップ・復旧は？ 日次で貴社ファイルサーバーへ。案件単位で JSON 書出し・読込ができ、作業スナップショットでいつでも戻せる。

Q. 退職・異動時は？ ユーザー管理画面で所属変更・削除。発行済みリンクは差戻し／確定で無効化。
