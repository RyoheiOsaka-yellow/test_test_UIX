# ANGLEX — Fabrication Intelligence（BIM 型 加工品 3D・見積プラットフォーム）

2D図面・CAD/BIMデータから配管サポート（架台・ブラケット・吊り金具・バンド）を **Revit 流のファミリ → タイプ → インスタンス** で 3D 化し、
穴・長穴・溶接ビード・ボルト・Uボルト・アンカーまで作り込んだ製作レベル（LOD400）のモデルから、重量・集計表・見積・加工指示書を **単一ソース** で生成します。
見積は **A社（見積作成）→ B社（利益上乗せ）→ C社（加工工場）** の多社ワークフローでフィールド単位の権限管理・改訂凍結・監査ログつきで受け渡せます。

## 配布ファイル（v1 / v2）
- `dist/ANGLEX_v1.html` — v1 UI（リボン＋プロジェクトブラウザ＋プロパティの BIM ワークスペース型）。分解図・中央へ・CAD 図面色を含む最新版（`index.html` = v1）
- `dist/ANGLEX_v2.html` — 新 UI（サインイン → モード選択 → 案件管理 / チャット見積 / 5 ステップ 3D 詳細）＋分解図・個別部材化。`dist/ANGLEX.html` は v1 と同じ内容。v2 のソースは `v2.html` + `css/app_v2.css`（`python3 tools/build_single.py v2.html css/app_v2.css dist/ANGLEX_v2.html`）
どちらも単一ファイルで、ブラウザで直接開けます（3D ライブラリと PDF ライブラリは CDN から読み込み）。

## 画面構成（v2 = 元デモの見た目）
1. **サインイン** — デモ認証。会社・役割（A社 設計 / B社 販売 / C社 工場）を選んでサインイン。サーバ運用時は `server/server.js` の認証に切り替わります。
2. **モード選択** — 「かんたん見積（チャット）」と「図面から加工指示（3D）」。「顧客・案件管理」からも入れます。
3. **顧客・案件管理** — 顧客ごとに案件（3D モデル）と見積の改訂・受け渡し状況（A社 → B社 → C社）を一覧。再開（3D）／見積／部材選択／削除。
4. **かんたん見積（チャット）** — 製品 → 配管径 → 仕上げ → 数量 を選ぶだけで、ファミリの既定寸法からモデルを配置し、工場原価の概算と「確認すべき加工指示」（溶接・穴・Uボルト・アンカー）をその場で表示。「3D で加工指示を確定する」で詳細モードへ、「見積書を作成」で A社 → B社 の受け渡しへ。自由入力（例: 125A の門型架台 ベース付 めっき 2台）も解釈します。
5. **3D 詳細モード（5 ステップ）**
   - ① CAD取込: ドロップ／サンプル DXF／サンプルモデル／空のモデル／保存済みを開く
   - ② 読込・分析: 解析ログ、部材認識（3 状態・リスク行列）、配置する部材を選ぶ
   - ③ 部材を選択: 図面ビュー（認識枠クリック）と検出部材リスト
   - ④ 部材ディテール: 3D アセンブリ（配置／加工／編集／表示／書出し／作業 のメニュー、部材・画層＝プロジェクトブラウザ、日本語の加工指示チャット）、仕様 & 加工指示（プロパティ・確認事項）、部材断面図、整合チェック（干渉・ズレ・接合）、分解図（部品表・バルーン・個別部材化）、積算コスト、カタログ照合
   - ⑤ 概算見積: 見積の作成・A社 → B社 → C社 受け渡し・帳票出力（従来の見積ワークフローをそのまま内包）

   URL パラメータ: `?view=3d`（サインインを省略して 3D 詳細モードへ）、`?view=chat`、`?view=projects`、`?handoff=<token>`（受け渡しリンク）、`?quality=0`（軽量描画）。

## v1 UI の 3 機能（分解確認 / 中央へ / CAD 図面色）
- **分解図**（ホーム → 分解・確認 → 分解図）: 選択部材を部品ごとにバラす（スライダー）。溶接は分解中は非表示。番号バルーンが 3D と部品表に対応し、行クリックでその部品だけ表示。「個別部材化」で組立品を単材・板のインスタンスへ。リボンの分解スライダーは、部材を選択していればその部品を、無ければ部材同士をバラします。
- **中央へ**: 3D 上の部材を**ダブルクリック**すると、その部材が画面中央に来るようにアニメーションで移動（距離は維持）。`C` で選択部材を中央へ、`F` で全体表示。「✋ 手のひら」（`H`）を押すと左ドラッグで画面を掴んで移動でき、右ドラッグが回転になります。
- **CAD 図面色**（表示スタイル）: 図面ビューと同じ暗背景に、役割ごとのフラットカラー（柱=青 / 梁=緑 / ベースプレート=青緑 / ガセット=紫 / 方杖=黄 / 支持金物=橙 / 配管=水色 / Uボルト=橙 / アンカー=赤 / 溶接=橙）＋明るいエッジで表示し、右上に凡例。3D と CAD 図面の照合用です。

## 分解図・分解（個別部材化）
部材ディテールの「分解図」カードで、分解スライダー（3D を部品ごとに引き離す）、番号バルーン（3D 上に部品番号、部品表と対応）、部品表（仕様・長さ・質量・加工）を表示します。「分解（個別部材化）」は門型架台などの組立品を、単材・板・管のインスタンスへ変換します（位置・向き・穴・仕上げ・材質を保持。ボルト類と溶接は対象外となるので「接合」で再定義してください。Ctrl+Z で戻せます）。

## 起動

```bash
# 1) 静的に開く（ローカル保存モード: localStorage）
cd anglex && python3 -m http.server 8080     # → http://localhost:8080/

# 2) サーバモード（多社アカウント・受け渡しリンク・DWG/JWW 変換中継）
node server/server.js --port 8080            # → http://localhost:8080/  データ: server/data/db.json
#    初期アカウント: a@example.com / b@example.com / c@example.com（パスワード anglex）
#    DWG/JWW/RVT 変換: ANGLEX_CONVERTER_URL=https://<ODA File Converter 等の HTTP ラッパ>/convert node server/server.js
```

依存パッケージなし（Three.js r180 / PDF.js / web-ifc / SheetJS は CDN から読込）。Node 18+。

## 3状態モデル（リスク行列 Case B）
読込・推論した部材は **確定／推論／要判断** を保持します。境界は `js/bim/risk.js` のリスク行列で決まります:
`risk = (1 − 信頼度) × 加工種別コスト（穴2・ピッチ3・溶接4・アンカー4…）× 管径係数（〜50A:1.0 / 〜100A:1.25 / 〜200A:1.6 / 大口径:2.0）`、
risk ≤ 0.6 で確定、≤ 1.8 で推論、それ以上は要判断。読込ウィザードに risk 値と主因を表示します。

## 溶接記号（JIS Z 3021）と現場／工場
溶接 parts は `site`（現場）フラグと記号文字（▷隅肉 / ○全周 / ▶現場 / V突合せ）を持ち、3D ラベル・図面ビュー・溶接集計（工場/現場別）・原価（現場は単価×1.8）に反映されます。指示文「MF-1 と MF-2 を 現場 隅肉溶接 6」、接合ダイアログの「施工」、門型架台の「ベース取付=現場溶接」で指定できます。

## 確認アラート・溶接／穴あけ指示・ズレ補正・作業保存
- **確認事項（人が必ず確認する箇所）**: `js/bim/review.js` が各インスタンスの部品リストから、溶接（脚長・全周/片側・現場/工場）、穴（径・ピッチ・端あき・面）、アンカー、Uボルト、吊ボルト、仕上げ、図面根拠（推論/要判断）、リスク主因をチェックリスト化します。図面から読み込んだ部材（`source='import'`）は全項目が「未確認」で始まり、手で配置した部材は溶接のみ未確認です。
- **3D 旗（⚑）**: 未確認の溶接・穴（面→板ローカル→配置の変換で穴位置に立つ）・アンカー・Uボルト・吊ボルトは位置に、その他は部材上部に件数でまとめて表示。クリックで選択。ステータスバーの「要確認 n」から全体の確認リストを開けます（表示タブの「確認フラグ」で ON/OFF）。
- **溶接指示 / 穴あけ指示**: プロパティの確認事項から実行。単材・鋼板は `welds` DSL（`start:6 site; end:6` = 始端/終端 全周隅肉、site=現場）と `holes` DSL に、組立ファミリは `weldSize`・`baseFix`（現場溶接）・`extraHoles`（`<部品番号>|<面>:z s d [slotNNz]` 行区切り）に書き込まれ、3D・溶接集計・重量・見積に同期します。指示した項目は「指示済」になり、確認後に「確認済」へ。確認状態・メモ・担当はインスタンスの `review` に保存されます。
- **ズレ補正**（ホーム → ズレ補正）: 部材間の隙間（0.5〜60mm）、レベル不一致（±150mm）、穴の板外／5mm 単位外、配管位置の部材外、接触の無い接合を検出し、「補正」で自動修正（寄せて密着 / レベルへスナップ / 端あき 1.5d へクランプ / 5mm へ丸め / 配管位置をクランプ）。Y 方向の隙間はレベルに載っていない側を動かし、両方レベル上なら下側の部材を伸ばして密着（単材 配置軸Y の L、門型架台・ポールの H）。「すべて補正」は同じ部材に影響する補正を 1 回 1 件に制限。
- **受け渡しゲート**: A社が見積を B社へ受け渡す・確定するとき、未確認の確認事項が残っていれば止めます。「確認リストを開く」で処理するか、理由を付けて「承知の上で進める」と、理由が監査ログ（受け渡し／確定の note）に残ります。見積ヘッダには「未確認 n」チップを表示。
- **作業保存**（Ctrl+Shift+S）: 名前とメモ付きでモデル全体のスナップショットをプロジェクトに保存（最大 30 件、ローカル保存／サーバ保存の両方）。「作業履歴」から復元（復元前の状態も自動保存）・削除。通常の自動保存は従来どおり常時働きます。

## 帳票の書出し（CSV / XLSX / PDF）
- 見積: 見積書 PDF（日本語フォント埋込・直接ダウンロード）、XLSX（数式入り: 採用原価・提示単価・販売単価・小計・税）、CSV、加工指示書 PDF（部材ごとの3Dスナップ・穴・溶接・ボルト）
- 重量: 重量計算書 PDF / XLSX（単位質量×長さ、穴控除、めっき付着、合計の数式）/ CSV、集計表 XLSX
- モデル: プロジェクト JSON、glTF/GLB、DXF 加工図（板展開＋穴）、IFC 風 JSON、**SimReady パッケージ**（USDA + USDZ（64byte整列）+ GLB + PBR テクスチャ PNG + 簡略コリジョン（部品 OBB の Cube プロキシ、メッシュは convexHull 近似）+ metadata.json（BOM・質量・重心・bbox・意味クラス）+ サムネイルの ZIP）

## 3D 品質（SimReady 指向）
PBR（アルベド / 法線 / 粗さ / AO）マテリアル、HDRI 環境光（Poly Haven CC0）、GTAO 接触陰影 + SMAA、面取り付き六角ボルト・ナット（30° 円錐面取り）、LOD400 の実螺旋ねじ山、板エッジ・穴の面取り、根元R、溶接ビードの波紋。CDN が使えない環境ではプロシージャル材質と RoomEnvironment にフォールバックします。

## Netlify 運用
リポジトリ直下の `netlify.toml` が `anglex/` を公開します（サーバ不要）。DWG/JWW の自動変換はサーバモード専用のため、Netlify 運用では DXF / IFC / PDF / glTF を直接読み込んでください。
