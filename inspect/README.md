# ANGLEX INSPECT — 受入検査 AI プロトタイプ（株式会社 BANTEC 様向け）

試作・量産部品の **受入検査（寸法検査 → 図面との照合 → 図面への記入 → 成績書）** を自動化するプロトタイプです。
ANGLEX（鉄骨 BIM）と同じ設計言語・3D 描画基盤（three.js r180 / ACES / GTAO / エッジ線）で作っています。

- 単一 HTML: `dist/ANGLEX_INSPECT_v0_1.html` — ダブルクリックで開けます（three.js のみ CDN。フォントも CDN、無くても動作）
- 開発版: `index.html` をローカル HTTP サーバーで開く（`python3 -m http.server` など）。`node build.mjs` で dist を再生成

## BANTEC 様の課題（10/8 議事録・メモより）と対応

| 課題 | プロトタイプでの対応 |
| --- | --- |
| 測定後に紙図面／3D と一つずつ照合し、図面に書き込む。複雑な図面は 1 枚で半日 | ② AI が図面から検査項目（寸法・公差・幾何公差・粗さ・ねじ・注記）を抽出しバルーン番号を付与 → ③ CMM の CSV を取り込むと ④ 全項目を自動判定し、**図面に測定値を自動で書き込み**（赤字・✓/✗）、3D 上で該当箇所をハイライト |
| 海外工場に丸投げ → 工場の成績書が信用できるか分からない | 工場（ベンダー）成績書を取り込み、**当社測定との不一致を自動検出**（公差幅の 30% または 5µm 超） |
| 不良の原因・対応を都度考える | AI 所見: 同方向の偏り（系統誤差）か個体ばらつきかを判定し、推定原因と推奨アクション（再測定・選別・CAR・特採）を提示 |
| 成績書作成 | ⑤ 受入検査成績書を自動生成（印刷 / PDF / CSV） |

## デモの流れ（11/4 訪問用・所要 10 分）

1. **案件一覧** — 3 案件（切削ハウジング・旋盤シャフト・板金ブラケット = 工法の幅）。KPI に「削減工数（試算）」。
2. **ベアリングハウジング（未着手）** を開く → ① サンプル図面・STEP を読込 → ② AI 抽出ログ（27 項目、はめあい記号 H7 の解釈、重要寸法 ★ 9 件）
3. ③ **サンプル CMM CSV を取込** → バルーン No. への自動対応付け（確信度付き）→ 手測定シート → 工場成績書
4. ④ **3D 照合**: 吹き出しの NG（軸受座 φ35H7、止め輪溝幅）をクリック → 公差帯バー・個体別実測・工場値との不一致・AI 所見。断面（Z）で内部の溝を見せる。偏差の誇張 ×200。
5. **図面（書き込み）**: 今まで手で書いていた赤字がそのまま出る。個体切替、印刷。
6. ⑤ **成績書**: ロット判定「不合格（重要寸法 2 件）」、所見、工数試算。印刷 / CSV。
7. シャフト（ジャーナル h6・同軸度 NG、工場値と不一致）とブラケット（曲げ角 NG）を開き、工法が違っても同じ流れで回ることを示す。

> すべて架空データです。実図面・実 CSV・実 STEP は次フェーズで対応（PDF ベクター解析 / OCR / STEP 読込 / CMM 各社フォーマット）。

## 訪問時のヒアリング項目（ROI を固めるため）

- 月あたりの受入検査件数、1 件あたりの平均項目数・所要時間（最長／平均）、担当者数と時間単価
- 使っている測定器（三次元測定機の有無・メーカー・出力形式、ハイトゲージ、ノギス、ピンゲージ…）と、データの出し方（CSV? 紙?）
- 図面の形式（顧客 PDF が中心か、DXF/STEP が入手できるか、スキャン紙図面の割合）
- 工場（国内／海外）からの出荷検査成績書の形式と、照合の現状
- 成績書の提出先・書式（顧客指定フォーマットの有無）、不合格時のフロー（特採・返却・手直し）
- 予算感・導入時期・決裁者、既存ツール（Excel／QC ソフト）との関係

## 構成

```
inspect/
  index.html            画面・CSS（開発用エントリ）
  build.mjs             単一 HTML へバンドル（モジュールを importmap の data: URL に埋め込み）
  js/main.js            アプリ本体（案件一覧 / ステッパー / 一覧 / プロパティ / 取込 / 3D / 図面 / 成績書）
  js/geo/parts.js       精密 3D 形状: 面取り付き積層押出し（水密ソリッド）/ 旋盤 Lathe + 実螺旋ねじ + エンドミル形状のキー溝 + センター穴 / 板金曲げ R
  js/geo/materials.js   切削アルミ・研磨鋼・電気亜鉛めっき のプロシージャル PBR 材質
  js/viewer/scene.js    3D ビューワ（ACES / PMREM / GTAO / SMAA / 影 / エッジ線 / 断面 / 特徴ハイライト / 吹き出し / プローブ点と偏差ベクトル）
  js/drawing/svg.js     図面 SVG 生成（投影図・断面・寸法・幾何公差枠・表題欄・バルーン・測定値の書き込み）
  js/inspect/judge.js   判定（合格 / 注意 80% / 不合格）、ロット判定、工場成績書照合、AI 所見、工数試算
  js/inspect/csv.js     CMM CSV の生成・解釈・バルーン対応付け
  js/data/parts.js      3 部品の図面項目・測定値・工場成績書（架空）
  js/ui/report.js       受入検査成績書
  test/geo.html         形状の単体確認ページ
```
