# Logo Design Intelligence — v15 プロトタイプ

ビルドパックに記述されたパイプラインの、動作する単一ファイル・プロトタイプ。

```
意味 → ゲノム → 構築 → 探索 → 知覚 → 類似 → 人手編集 → 再テスト → エクスポート
```

`index.html` をブラウザで開くだけ。ビルド不要・依存関係なし・ネットワーク通信なし。
UI は日本語/英語を右上のボタンで切り替えられる（既定は日本語）。

## 決め打ちのロゴ形状は存在しない

ゲノムは「あるテンプレートのパラメータ束」ではなく、**小さなプログラム（構成ツリー）** である。

```
genome.tree = [ 分岐, 分岐?, 分岐? ]
分岐        = { プリミティブ, オペレータ 0〜2 個, 役割, 塗り/線 }
```

プリミティブ 8 種 × オペレータ 6 種 × 役割 3 種 × 各パラメータ、これを 1〜3 分岐
組み合わせた空間が探索対象になる。形は毎回この木から計算される。

### プリミティブ（形の原子）

| | パラメータ |
| --- | --- |
| `ring` リング | 半径・開口 |
| `arcband` 円弧帯 | 半径・開始角・角度 |
| `disc` ディスク | 半径 |
| `poly` 多角形 | 半径・辺数（3〜8） |
| `bar` バー | 長さ・太さ |
| `chev` 山形 | 高さ・幅 |
| `cross` クロス | 長さ・太さ |
| `wedge` 扇形 | 半径・角度 |

### オペレータ（合成規則）

| | パラメータ |
| --- | --- |
| `repeat.radial` 放射反復 | 個数・配置半径・位相 |
| `repeat.linear` 直線反復 | 個数・X 間隔・Y 間隔 |
| `nest` 入れ子 | 個数・縮率・ひねり |
| `mirror` 鏡像 | 軸 |
| `shift` 偏心 | 距離・方向 |
| `rotate` 回転 | 角度 |

役割は `ink` / `accent` / `ground`。`ground` は地の色で塗るので、実質的な**抜き**として働き、
カウンターフォームを作れる。

## 操作方法

画面上部のステッパー（6 ステップ）で移動する。各ステップの上には、ビルドパックの
9 段階のどこに当たるかが小さく出る（例: `05—06 PERCEPTION · SIMILARITY`）。

| ステップ | 操作 |
| --- | --- |
| **01 意味** | ブランド名・カテゴリ・オーディエンスを入力し、意味属性を最大 5 つ選ぶ。**入力を変えるとパイプラインは自動で引き直される** |
| **02 ゲノム** | 4 つのテリトリー図版をクリックして選択／解除。下段はシステムの語彙そのもの（プリミティブとオペレータの全図版）で、いずれも同じエンジンで描いている |
| **03 探索** | 2,000 候補がどのスクリーンで何件落ちたかを見る。グラマー別の歩留まりは折りたたみを開く |
| **04 知覚** | 24 の代表が並ぶ。ホバーで構造線、クリックで選択、ダブルクリックで編集へ。**「別の 24 件を出す」で同じ条件のまま引き直せる** |
| **05 編集** | **構成ツリー**でプリミティブとオペレータを差し替え・追加・削除。**変異パネル**は現在の形から 12 通りの派生を出し、クリックで採用できる。すべて取り消し可能 |
| **06 出力** | SVG をコピーまたはダウンロード。ゲノム・構築グラフ・来歴が付随し、受け入れ判定の全項目が並ぶ |

補助操作:

- **← →** キーでステップ移動（入力欄にフォーカスがあるときは無効）
- 編集画面の上部: 構造線、組版切替（マークのみ／縦組み／横組み）、単色、探索時に戻す
- 右上: 言語切替（EN / 日本語）、テーマ切替（システム → ライト → ダーク）

### 構造線について

作図円・接線・軸・センターマークは、表示中のゲノムの**配置結果から導出**して描いている。
リングなら半径と ±ストローク幅の外周・内周、放射反復なら配置円、バーなら長辺・短辺の
延長線、というように、どんな木でも同じ規則で線が出る。パラメータを動かせば線も追従する。

## 品質スクリーン

自由度を上げると「形ではあるがロゴではない」ものが増えるので、構築スクリーンで落としている。

- ストローク下限 2.2u、インク被覆率 5〜50%、アトム上限 26、外形範囲 16〜58u
- **重複配置** — 同じ位置に重なった配置（中心対称形に鏡像を掛けた場合など）
- **融合** — 反復の間隔が狭く、コピーが 1 つの塊に見えるもの
- **埋没** — 同色の塗りの内側に完全に入って見えないアトム（スコアは「見える数」で計算する）
- **単独の塗り** — 素の多角形や円を置いただけのもの

## 実装されている挙動

| 段階 | 実装 |
| --- | --- |
| 意味 | 自由記述のブリーフを 5 軸の意味ベクトルへ一度だけコンパイルし、以降は参照しない |
| ゲノム | ベクトル距離で 4 テリトリーを選定。テリトリーは完成形ではなく**使ってよい語彙と範囲**を決める |
| 構築 | 構成ツリーを配置列へ展開し、そこから SVG と `ConstructionGraph` を生成 |
| 探索 | 64 の構造レシピから約 2,000 の候補ゲノムをサンプリング |
| 知覚 | 妥当性スクリーンの後、16px 可読性・コントラスト・構築の経済性・光学バランス・独自性 |
| 類似 | 木の署名（プリミティブ・オペレータ・アトム数・被覆率など 12 次元）による重み付き距離 |
| 人手編集 | 構成ツリーの構造ごと編集可能。変更前の状態とともに記録 |
| 再テスト | スコアを即時再計算し、探索時の状態との差分を表示 |
| エクスポート | ここで初めてプリミティブを `<path>` へフラット化。ゲノムと来歴を同梱 |

完全に決定論的: ブリーフがハッシュ化されてシードになるため、同じブリーフからは毎回同じ
候補群が再現される（「別の 24 件を出す」はシードにソルトを足す明示的な操作）。

## `00_START_HERE.md` の制約の扱い

- prompt-to-image の経路は存在しない。真実の源は構成ツリー
- 類似判定は**デザイン衝突**のシグナルとして明示。商標・法的クリアランスの主張は UI にも
  書き出した SVG にも一切含まない
- 形状心理学を決定論的な事実として断定しない
- ジオメトリはエクスポート直前までパラメトリックのまま
- すべての編集は個別に取り消し可能で、来歴を保持する

## プロトタイプとしての境界

- ワードマークはライブ `<text>` のまま。アウトライン化は下流タスクであり、受け入れ判定に
  未達として表示する
- インク被覆率・重心・外形範囲はラスタライズではなく解析的推定（重なりは厳密には引いていない）
- コーパスは同じ生成器で作った合成データで、実スクリーニング索引の代替
- ブーリアン演算は「地の色で塗る」擬似的な抜きで、真のパス演算ではない
