# Logo Design Intelligence — v15 プロトタイプ

ビルドパックに記述されたパイプラインの、動作する単一ファイル・プロトタイプ。

```
意味 → ゲノム → 構築 → 探索 → 知覚 → 類似 → 人手編集 → 再テスト → エクスポート
```

`index.html` をブラウザで開くだけ。ビルド不要・依存関係なし・ネットワーク通信なし。
UI は日本語/英語を左下のボタンで切り替えられる（既定は日本語）。

## 操作方法

画面上部のステッパー（6 ステップ）で移動する。各ステップの上には、ビルドパックの
9 段階のどこに当たるかが小さく出る（例: `05—06 PERCEPTION · SIMILARITY`）。

| ステップ | 操作 |
| --- | --- |
| **01 意味** | ブランド名・カテゴリ・オーディエンスを入力し、意味属性を最大 5 つ選ぶ。制約のチェックはスコアの判定基準に直接効く。**入力を変えるとパイプラインは自動で引き直される**（実行ボタンは無い） |
| **02 ゲノム** | 4 つのテリトリー図版をクリックして選択／解除（最低 1 つは残る）。図版はそのテリトリーの最良候補を実際に構築したもので、ポインタを重ねると構造線が浮かぶ |
| **03 探索** | 2,000 候補がどのスクリーンで何件落ちたかを見る。グラマー別の歩留まりは折りたたみを開く |
| **04 知覚** | 24 の代表が並ぶ。カードにポインタを重ねると**作図円と軸が浮かぶ**。クリックで選択、**ダブルクリックでそのまま編集へ** |
| **05 編集** | 右のスライダーとセレクトでゲノムを直接動かす。「構造線」ボタンで作図線を常時表示。スコアは即時に再計算され、編集ログの「取り消す」で 1 件ずつ戻せる |
| **06 出力** | SVG をコピーまたはダウンロード。ゲノム・構築グラフ・来歴が付随し、受け入れ判定の全項目が並ぶ |

補助操作:

- **← →** キーでステップ移動（入力欄にフォーカスがあるときは無効）
- 編集画面の上部: 構造線、組版切替（マークのみ／縦組み／横組み）、単色、探索時に戻す
- 右上: 言語切替（EN / 日本語）、テーマ切替（システム → ライト → ダーク）

### 構造線について

作図円・接線・軸・センターマークは、すべて表示中のゲノムから導出して描いている（手描きの
装飾ではない）。半径を動かせば作図円も一緒に動く。アーキタイプごとに引かれる線が変わる:

| アーキタイプ | 引かれる線 |
| --- | --- |
| aperture | 主円と ±ストローク幅の外周・内周、カウンター円、開口の両端レイ、上下左右の接線 |
| orbit | 軌道円と ±サテライト半径、各サテライトの円と放射レイ、コア円 |
| lattice | 格子の全ライン、外接円と内接円 |
| chevron | 各段の頂点・裾の水平線、腕の延長線 |
| containment | 境界とオフセット、カウンター円、4 本の対角レイ、接線 |
| stack | 各スロット境界の水平線、各部材の端の垂直線 |
| prism | 外接円・内接円、3 頂点のレイ |

## 実装されている挙動

プレースホルダ画像のモックではなく、画面上のマークはすべて構造データから実行時に生成される。

| 段階 | 実装 |
| --- | --- |
| 意味 | 自由記述のブリーフを 5 軸の意味ベクトルへ一度だけコンパイルし、以降は参照しない |
| ゲノム | ベクトル距離で 4 テリトリーを選定。各 16 グラマー = 64 のパラメータ窓 |
| 構築 | 各ゲノムが名前付きオペレーションの `ConstructionGraph` を組み、そこから SVG を出力 |
| 探索 | グラマー窓の内側で約 2,000 の候補ゲノムをサンプリング |
| 知覚 | 妥当性スクリーンの後、16px 可読性・コントラスト・構築の経済性・光学バランス・独自性 |
| 類似 | 56 件の構成コーパスに対する重み付き距離 → クリア／要確認／衝突 |
| 人手編集 | 全ゲノムパラメータを操作可能。各変更を変更前の値とともに記録 |
| 再テスト | スコアを即時再計算し、探索時の状態との差分を表示 |
| エクスポート | ここで初めてプリミティブを `<path>` へフラット化。ゲノムと来歴を同梱 |

完全に決定論的: ブリーフがハッシュ化されてシードになるため、同じブリーフからは毎回同じ
2,000 候補・同じ 24 代表が再現される。

## `00_START_HERE.md` の制約の扱い

- prompt-to-image の経路は存在しない。真実の源はゲノムのみ
- 類似判定は**デザイン衝突**のシグナルとして明示。商標・法的クリアランスの主張は UI にも
  書き出した SVG にも一切含まない
- 形状心理学を決定論的な事実として断定しない。テリトリーの主張は「立場」として記述
- ジオメトリはエクスポート直前までパラメトリックのまま
- すべての編集は個別に取り消し可能で、来歴を保持する

## プロトタイプとしての境界

- ワードマークはライブ `<text>` のまま。アウトライン化は下流タスクであり、完了したふりを
  せず受け入れ判定に未達として表示する
- インク被覆率はラスタライズではなく、アーキタイプごとの解析的推定
- コーパスは合成データで、実スクリーニング索引の代替
