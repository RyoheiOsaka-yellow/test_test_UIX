### 332現象すべてが遊べます
仕様書 §12 の 320 現象（20宇宙 × 16）に拡張宇宙の 12 現象を加えた **332 現象すべて**が、
ブラウザ内で実際に動くシミュレーションとして実装済みです。「さがす」で宇宙を選ぶと、
その宇宙の全現象がライブ計算のサムネイル付きで並びます。

### 必須要件の対応
- **v8 ビジュアルシステム** — 生成りの紙・深緑・くすんだ金、明朝見出し／ゴシック操作系、
  細い warm-gray 罫線、丸いピル、影は 3 段階のみ。宇宙アクセントは面積の 10–20% に限定。
- **レスポンシブ** — デスクトップは 3 カラム。820px 以下では左右パネルがボトムシート化し、
  「あそぶ／見る／しくみ」タブで切り替え。ツールバーは 1 行の横スクロールになります。
- **シミュレーション／描画の分離** — 物理は `Clock` の固定ステップでのみ進み、
  `draw()` は状態を読むだけで書き換えません。フレーム落ち・タブ復帰時は蓄積時間をクランプします。
- **マニフェスト駆動の操作系** — 各ラボの `params` / `initParams` / `presets` / `views` 定義から
  スライダー・プリセット・ビュータブを自動生成しています。画面側にラボ固有の記述はありません。
- **決定論的シリアライズ** — キーをソートし数値精度を固定して JSON 化 → URL に格納。
  「共有」ボタンで生成した URL を開くと同じ状態から再現されます。
- **科学的テスト** — 各ラボの「テスト」ボタンからブラウザ上で実行（計 48 件）。
  保存則・平衡点・収束次数・決定論・統計則・理論値との一致を確認します。
- **Compare / Worlds** — 1 / 2 / 10 / 50 ワールドの同時実行。摂動は現象ごとに定義
  （θ₁、x₀、シード）。
- **Butterfly** — P02 / A01 / M01 で対応。状態空間距離と log₁₀ 差、直近 40 点のスパークライン。
- **メトリクス** — エネルギー、状態距離、周期の推定、⟨r²⟩、方向の出現割合など。
- **ラーニングパネル** — HOOK → TRY THIS → NOTICE → WHY?（+ もう少し深く）→ MODEL
  （+ 仮定）→ REAL WORLD → GO DEEPER → RELATED。
- **Related links** — 現象間を相互に行き来できます。
- **乱数** — `Math.random()` は使わず、すべて `SeededRNG`（mulberry32）を経由します。

## 実装の深さについて（重要）

332 現象は「同じ深さ」ではありません。3 段階あります。

1. **フラッグシップ 10**（P02 / A01 / M01 / R02 / CA01 / W04 / G03 / S03 / QM01 / BH01）
   — 専用エンジン + 48 件の科学的テスト + フルの学習パネル（HOOK〜GO DEEPER）。
2. **正典モデル実装**（大多数）— その現象の標準的な方程式・規則をそのまま実装しています。
   例：エノン写像、ローレンツ族アトラクタ、イジング、BTW砂山、蔵本、Vicsek、
   Barabási–Albert、シェリング、最適速度交通、Crank–Nicolson 量子、測地線など。
3. **簡易表現**（カードとラボに `SIMPLIFIED` バッジ + 「この模型が置いている仮定」に明記）
   — 忠実な実装が GPU / 3D / 専用ソルバーを要するもの。例：メンガーのスポンジ（2次元断面）、
   テイラー–クエット（2次元近似）、BZ反応（同クラスの興奮媒体で代替）、
   重力波インスパイラル（チャープ則の可視化）、ラングトンのループ（巡回CAで代替）など。

**簡易表現であることは必ず画面上に明示しています。** 何が本物で何が近似かを、
利用者が判断できる状態を保つことを優先しました。

## 既知の制約

- A01 は仕様上 `three` 指定ですが、依存ゼロを優先して Canvas2D の投影で描いています。
  3D の見た目は簡略で、深度ソートはしていません。
- CA01 のブラシ描画・W04 のクリック波源・G03 のドラッグ追加天体・EM16 の電荷配置は、
  共有URLには入りません（プリセット由来の状態のみシリアライズされます）。
- カタログカードのサムネイルは「一定ステップ進めた静止画」です（一覧で 332 個を同時に
  animate しないための設計）。動くプレビューはフラッグシップ10のカードのみです。
- 汎用ラボは Worlds / Butterfly に対応していません（フラッグシップ10のみ）。
- QM01 は1次元・単一粒子です。二重スリット（QM02）は2次元グリッドが必要なため準備中です。
- BH01 の光線は焦線（コースティクス）付近で本数が粗く見えることがあります。本数スライダーで補えます。
- ローレンツの時間は壁時計時間ではありません。1× = モデル時間 6 単位/秒で表示しています
  （実時間のままだとアトラクタの形が見えるまで数十秒かかるため）。
- M01 の分岐図は r ∈ [2.4, 4] 固定。パンやズームはできません。
- Worlds は最大 50。1000 ワールドは GPU/バッチ実装が前提のため未対応です。
- KaTeX は入れていません。数式は HTML の文字組みです。
- 音（v8 §10）とスクリーンショット出力は未実装です。

## 次の一歩の推奨

1. **学習パネルの深化** — フラッグシップ10は個別の TRY/NOTICE を持ちますが、
   汎用ラボの一部は宇宙共通の WHY/REAL WORLD を使っています。現象固有の文へ順次差し替え。
2. **科学的テストの拡大** — 現在の 48 件を、正典モデル実装のラボへ広げる
   （イジングの T_c、BTW のべき指数、Vicsek の転移点など、検証可能な理論値が揃っています）。
3. **WebGL 化** — 反応拡散・流体・フラクタルを GPU に載せれば、格子解像度を数倍にできます。
   現在は CPU のため 96×64〜128×88 に抑えています。
4. **簡易表現の格上げ** — `SIMPLIFIED` バッジの付いた現象を、忠実な実装へ順次置き換え。
5. **マニフェストの外部化** — `GLABS` 定義を JSON/YAML に出し、ビルド時読み込みへ。
6. **サムネイルのキャッシュ** — 現在は「さがす」を開くたびに再計算しています。
   IndexedDB へ焼くと初回以降が軽くなります。
