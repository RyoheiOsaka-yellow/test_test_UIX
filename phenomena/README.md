# PHENOMENA — Visible Alpha プロトタイプ

> 世界のしくみを、触って理解する。／ まず触る。あとで知る。

`PHENOMENA_MASTER_SPEC_v13.md` と `CLAUDE_CODE_VISIBLE_ALPHA_v13.md` の内容を、
参考HTML（GREEN×EXPO 2027 什器3Dエディター）のビジュアル言語で組み立てた
インタラクティブ・プロトタイプです。

## 開き方

`index.html` をブラウザで開くだけです。ビルド・サーバー・依存パッケージはありません
（`file://` で動作します）。フォントのみ Google Fonts を参照し、オフライン時は
システムフォントにフォールバックします。

### 4 つの現象
| ID | 現象 | エンジン | ソルバー | ビュー |
|---|---|---|---|---|
| P02 | 二重振り子 | `ode-rigidbody` | RK4 固定 Δt = 1/240 s | 振り子 / 位相空間 / エネルギー |

### 必須要件の対応
- **v8 ビジュアルシステム** — 生成りの紙・深緑・くすんだ金、明朝見出し／ゴシック操作系、
  細い warm-gray 罫線、丸いピル、影は 3 段階のみ。宇宙アクセントは面積の 10–20% に限定。
- **レスポンシブ** — デスクトップは 3 カラム。820px 以下では左右パネルがボトムシート化し、
  「あそぶ／見る／しくみ」タブで切り替え。ツールバーは 1 行の横スクロールになります。
- **シミュレーション／描画の分離** — 物理は `Clock` の固定ステップでのみ進み、
  `draw()` は状態を読むだけで書き換えません。フレーム落ち・タブ復帰時は蓄積時間をクランプします。
- **マニフェスト駆動の操作系** — 各ラボの `params` / `initParams` / `presets` / `views` 定義から
  スライダー・プリセット・ビュータブを自動生成しています。画面側にラボ固有の記述はありません。
- **決定論的シリアライズ** — キーをソートし数値精度を固定して JSON 化 → URL に格納。
  「共有」ボタンで生成した URL を開くと同じ状態から再現されます。
- **科学的テスト** — 各ラボの「テスト」ボタンからブラウザ上で実行（計 20 件）。
  保存則・平衡点・ステップ半減時の収束次数・決定論・統計則を確認します。
- **Compare / Worlds** — 1 / 2 / 10 / 50 ワールドの同時実行。摂動は現象ごとに定義
  （θ₁、x₀、シード）。
- **Butterfly** — P02 / A01 / M01 で対応。状態空間距離と log₁₀ 差、直近 40 点のスパークライン。
- **メトリクス** — エネルギー、状態距離、周期の推定、⟨r²⟩、方向の出現割合など。
- **ラーニングパネル** — HOOK → TRY THIS → NOTICE → WHY?（+ もう少し深く）→ MODEL
  （+ 仮定）→ REAL WORLD → GO DEEPER → RELATED。
- **Related links** — 現象間を相互に行き来できます。
- **乱数** — `Math.random()` は使わず、すべて `SeededRNG`（mulberry32）を経由します。

4 ラボ 20 件すべて PASS（Chromium 141 / headless）。

```
           誤差 2.53e-6 → 1.72e-7（比 14.8、RK4 の理論値 16）

           ⟨r²⟩/歩数 = 0.983・大集団の平均変位 0.59
```

`screenshots/` にデスクトップ（1440×900）とモバイル（390×844）の画面を収めています。

## 意図的にやっていないこと

Visible Alpha の "Do not" に従い、残り 8 つの Signature ラボ、認証、DB/バックエンド、
教育者モード、および不要な抽象化は実装していません。

## 既知の制約

- A01 は仕様上 `three` 指定ですが、依存ゼロを優先して Canvas2D の投影で描いています。
  3D の見た目は簡略で、深度ソートはしていません。
- ローレンツの時間は壁時計時間ではありません。1× = モデル時間 6 単位/秒で表示しています
  （実時間のままだとアトラクタの形が見えるまで数十秒かかるため）。
- M01 の分岐図は r ∈ [2.4, 4] 固定。パンやズームはできません。
- Worlds は最大 50。1000 ワールドは GPU/バッチ実装が前提のため未対応です。
- KaTeX は入れていません。数式は HTML の文字組みです。
- 音（v8 §10）とスクリーンショット出力は未実装です。

## 次の一歩の推奨

1. P02 と A01 のマニフェストを YAML ファイルに外出しし、現在ハードコードされている
   `LABS` 定義をローダー経由に置き換える。追加が「画面開発」ではなく「データ登録」になります。
2. R02 の 1000 ワールドを typed-array バッチで実装し、Worlds UI の上限を引き上げる。
3. Compare Lab（2つの状態を並べて時計を同期）を独立したビューとして切り出す。
4. その後に残り 8 つの Signature ラボへ。まず CA01 / RD01 が既存シェルの再利用度を測る指標になります。
