# 株式会社エコプロジェクト コーポレートサイト リニューアル案

[e-project.jpn.com/profile](http://e-project.jpn.com/profile/) のリニューアルを想定したデザインモックです。
[マルニ工業株式会社](https://maruni-ind.co.jp/) のような、白基調でミニマル・信頼感のあるコーポレートサイトを目指しています。

## 構成

- `index.html` — ワンページ構成（ヒーロー / 私たちについて / 事業内容 / 選ばれる理由 / お知らせ / 会社概要 / お問い合わせ）
- `css/style.css` — デザイントークンベースのスタイル（緑×白×グレーの配色）
- `js/main.js` — スクロール連動の演出（リビール、カウントアップ、ヘッダー、モバイルメニュー）

## 特徴

- 外部画像に依存しない自作SVGビジュアル（ビル群・マップなどはすべてダミーイメージ）
- レスポンシブ対応（PC / タブレット / スマートフォン）
- `prefers-reduced-motion` 対応、セマンティックHTML

## プレビュー方法

```bash
cd site
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## 注意

実績数値・お知らせ記事の一部はダミーです。会社概要（社名・代表者・所在地・連絡先・事業内容）は現行サイトの掲載情報に基づいています。
