# 引き継ぎ — mathcat 移植規約 & 新宿駅B1 人流シミュレータ

日付: 2026-08-07 / 状態: **Phase 1 垂直スライス 検証合格 → Phase 1.5 3Dビュー版 検証合格**

---

## 1. プロジェクト全体像

mathcat v0.1.0(アロケーションフリー・データ指向のJS数学カーネル、`op(out, a, b)` 規約)を、人流・スタジアム・工場向け数理モデル群として **ブラウザJS / Rust+WASM / Python+NumPy** の3環境へ移植する。規約を紙上で決めるだけでなく、実装で検証するために「新宿駅B1 人流シミュレータ」を垂直スライスとして構築した。**スライスは完成・検証合格済み**。次は規約仕様書の1ファイル化(§7)。

## 2. 確定済みの規約(8決定)

1. **カーネル形式**: `op(out, a, b)`。カーネル内アロケーション禁止
2. **メモリレイアウト**: 属性間SoA・成分内インターリーブ。`pos = Float32Array(2n)` に `[x0,y0,x1,y1,...]`。API例 `vec2n.add(out, a, b, n)`
3. **可変長データ**: CSR(counts → offsets前置和 → fill)
4. **クエリ戻り値**: snprintf方式(書込数を返却、バッファ不足は負値)
5. **精度**: geo層 Float64 / ローカル座標 Float32。時刻は Float64 ms + Int32 オフセット
6. **vec3**: CPUでは stride 3、WebGPU連携時のみパディング
7. **AoS⇄SoA変換**: `soa.split2` / `soa.join2`
8. **モジュール階層**: L0 mathcat → L1 geo → L2 field → L3 traj → L4 model → L5 stat → L6 privacy

## 3. データパイプライン(実行済み)

- 入力: `新宿駅構内図3D.html`(8.9MB)→ 抽出 `station.json`(EPSG:6677 IX系、32データセット、1,984フィーチャ)
- 型番: B019=通路 / B001=ホーム / B021=階段 / B022=EV / B023=ESC。`restricted`: **'2'=通行可、'1'=不可**(直感と逆なので注意)
- B1前処理(PILラスタライズ→ユニオンファインド→PCA→RLE):
  - 0.5mセル、**965×1227** グリッド、原点 `(-12381.8, -34673.3)`
  - 歩行可能 234,158セル(58,540m²)→ 最大連結成分 **231,733セル** を採用(5成分中)
  - 出口(階段/ESC/EV)**88箇所**、ホーム軸4本(PCA長軸: 119.1 / 53.4 / 48.4 / 45.4 m)※線路線形が無いためPCAで代替
  - 出力: `b1_pack.json`(106KB)= `{cell, W, H, rle, dests, platforms, render:{walk,plat,fix,conn}}`

## 4. シミュレータ実装(`shinjuku_b1_sim.html`, 131KB 自己完結)

- **場**: RLE展開 → 3-4チャンファーSDF(2パス)→ 8近傍Dijkstra(重み5/7、バケットキュー、斜め角抜け防止)。出口k-means 6群 + ホーム4場 = **計10コスト場(Uint16)**。構築 ~350ms
- **エージェント**: SoAインターリーブ、NMAX=3000、R=0.25m、希望速度 N(1.34, 0.2) clamp[0.8, 1.9]。swap-remove kill(`born[]`含む全属性をスワップ)
- **近傍**: 1mセルCSRハッシュ、毎フレーム再構築
- **力学**: 操舵 `(v_des - v)/τ`, τ=0.5 / 社会力反発 **A=4.0, B=0.12(短距離型)** / **左側通行バイアス: 反発を+0.30rad回転 → レーン形成** / 壁力 = 中距離センタリング(WALLC=1.2m, 2.6t²)+接触反発(WALLR=0.40m, 16(WALLR-sd)) / 加速度クランプ 5 m/s² / 速度上限 2.2
- **勾配**: **バイリニア補間コストの中央差分(h=0.6m)**。壁・未到達セルは「局所基準値+8」に置換(§6の核心修正)
- **不変条件**: 域外クランプ → 軸別壁スライド → それでも非歩行セルなら最近傍歩行セルへ復帰+`wallHits`計上
- **電車**: 4本、period 70+17i s、approach 8s(cubicOut)→ dwell 25s → depart 8s(cubicIn)。降車は**バースト禁止**、1ドア0.7人/sで最初の~12sに分散湧出(計40+Poisson(20))。乗車客2.2人/s湧出、cost≤20で待機、dwell中2.0/s確率で乗車
- **計測**: 基本図(1/8サブサンプル、**待機者と生成3秒未満を除外**、半径1m円密度、0.2刻みビン)、重なり率、貫通、スライド
- **乱数**: xorshift128 決定的、リセット対応
- **UI**: 発車標風ヘッダ(--ink暗+アンバー)、2Dキャンバス俯瞰(2px/m事前描画+パン/ズーム)、統計グリッド、Weidmann参照曲線付き基本図チャート、一時停止/4×速/リセット、prefers-reduced-motion対応

## 6. チューニング履歴(同じ轍を踏まないために)

| 症状 | 真因 | 修正 |
|---|---|---|
| wallHits 40万件 | スライド防御の作動を「貫通」と誤計上 | 貫通=更新後に非歩行セルのみ。スライドは別カウンタ |
| 全域グリッドロック(v≈0.07)・貫通21万 | **スポーン時、歩行セルへスナップ後にジッタを加えて壁セルへ着地**→永久スタック→通路閉塞 | ジッタ後に再検証、壁ならセル中心へ |
| 対向流の正面デッドロック | 対称反発のみで回避項なし | 反発ベクトルを+0.30rad回転(左側通行)。A=2.6,B=0.30→**A=4.0,B=0.12**(長距離ソフト→短距離型) |
| 慢性的壁吸着(スライド500万回)・中密度で減速 | 軸独立4近傍最急降下が**斜め通路の階段状ラスタ壁**へ勾配を向ける | **バイリニアコストの中央差分**に置換。壁セルは1e6でなく局所値+8(勾配爆発防止) |
| 低密度ビン汚染(ρ=0.3で0.39 m/s) | 乗車待機者(停止中)と生成直後の加速中個体が混入 | FDサンプルから待機者と age<3s を除外 |
| 重なり2.5% | ドア一斉バースト湧出 | dwell前半12sへ分散湧出 |
| ビルド反映疑義 | sed的replaceはパターン不一致でも無言で成功する | パッチ後に必ずgrepで実物確認 |

## 6.5 Phase 1.5 — 3D ビュー版(`新宿駅B1人流3D.html`, 2026-08-07 完了)

物理・場・電車・計測は 2D 版と**バイト単位で同一**(§10 までのコードを不変のまま流用、決定的乱数もそのまま)。§11 描画層のみ WebGL2 3D レンダラに置換した。外部ライブラリなし・自己完結(149KB)。

- **床**: 2D 版ベースレイヤ(2px/m Canvas 描画)をそのままテクスチャ化し地面クアッドへ。ミップマップ+異方性フィルタで斜め視点のモアレを抑制。出口マーカーも床へ焼き込み
- **壁**: walk グリッドの境界エッジを**行/列方向にランマージ**して高さ1.1mの腰高カットアウェイに押し出し。10,172三角形(マージ無しだと約10倍)。柱・什器の島も自動的にフェンス化される
- **歩行者**: WebGL2 インスタンス描画(円柱10角+天板、`vertexAttribDivisor`)。インスタンスバッファは `[x,z,kind]` を毎フレーム `bufferSubData`(SoA からのギャザーのみ、アロケーションフリー)。接地影は同じインスタンスバッファを共有する円盤の2回目ドロー
- **電車**: 不透明な濃色の裾(高さ0.45m)+半透明ボディ(α: 停車0.68 / 走行0.50)の2段構成。**最初は単層半透明(α0.38)で床に溶けて見えなかった**→裾の追加で解決(§6の教訓に追記対象)。半透明なので車体越しに乗降・待機列が見える
- **出口**: 緑の発光光柱(88本を1バッファに焼き込み、加算気味のエミッシブ)
- **カメラ**: オービット(左ドラッグ回転 / 右 or Shift+ドラッグ パン / ホイールズーム)。「真上視点」「視点リセット」ボタン付き。初期フレーミングは歩行可能セルの重心+dist 300m
- **mat4/シェーダ**: 自前の列優先 mat4 ミニカーネル(`op(out,...)` 規約)。プログラムは床/単色/インスタンスの3本のみ
- **検証**(ヘッドレス Chromium + SwiftShader, 180シミュ秒): 壁貫通 **0**、重なり **0.00%**、物理 **~1.0ms/step @ N=572**、exited 138 / boarded 91、コンソールエラー 0。WebGL2 非対応環境では 2D 版への誘導メッセージを表示
