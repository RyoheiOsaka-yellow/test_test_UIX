# アルテック 手摺デザインスタジオ (プロトタイプ)

`index.html` 1 ファイルで動く、装飾金物メーカー 株式会社アルテック 向けの
**バルコニー手摺ユニット 3D 分解 / 施工検討ダッシュボード** のプロトタイプです。

元プロトタイプ（VolaTrap Assembly Studio：機器の 3D 分解・設計ダッシュボード）の
UI 骨格（リボン / ドック / 分解バー / BOM / パラメトリック再生成 / 干渉チェック）を流用し、
題材・データ・ロジックをアルテックの事業（建築用装飾金属の製造販売・施工）に合わせて書き換えています。

## 開き方

`index.html` をブラウザで開くだけです（Three.js r128 と Google Fonts を CDN から読み込むため、ネット接続が必要）。

## 元プロトタイプからの主な変更点

| 観点 | 元 (VolaTrap) | 改修後 (アルテック) |
| --- | --- | --- |
| 題材 | VOC サンプリング機器 (27 部品) | バルコニー手摺ユニット (18 品番・4 サブAssy) |
| サブAssy | ヘッド / ハウジング / 内部 / ベース | 支柱・基礎 / 笠木・下桟 / 手摺子・ユニットパネル / 花台 |
| 材質 | ABS・PC・SUS・ガラス等 | ADC12 ダイカスト・AC4C 鋳物・6063S-T5 形材・SUS304・SS400 めっき・POM |
| Make / Buy | 自製 / 購入 | 規格品 (カタログ標準品) / 特注品 (現場寸法・特別注文) |
| 分解手順 | 分解順 (取り外す順) | **施工順**（100 % → 0 % で施工順に組み上がる） |
| LED 色相 | LED 点灯・色相スライダ | **仕上げ色 (標準色 CS-1〜CS-28、アクリル焼付)** セレクタ |
| パラメータ | ノズル角度・ボディ半径… | 支柱スパン・手摺天端高さ・手摺子ピッチ・足元隙間・支柱サイズ・ユニット列数/幅・花台奥行 |

| シーン | 床グリッド | バルコニースラブ（参考表示・BOM 対象外） |

### アルテック公式サイトから反映した情報

- 標準色 8 色（一色塗装 / アクリル焼付）: CS-1 ミルキーホワイト … CS-28 ディープグリーン
- ユニットタイプ: ダイカスト製、**ステンレス スプリングピン**によるジョイント方式
- 花台 (KTA タイプ): ダイカスト製ブラケット、**SUS M8×75 コーチボルト**固定、最大積載 60 kg
- 材質表記: 6063S-T5 / A1100P-H24 / SUS304 / アルミ合金ダイカスト
- 施工例ジャンル「バルコニー手摺」「花台」を題材に採用

製品型番は「U-22 相当」「T-80 系相当」「KTA タイプ相当」と表記しています。
実寸法・実重量はカタログ値ではなく、モデル形状からの概算です。

## 主な操作

- 下部の分解バー ▶ : 分解 / 施工アニメーション（`Space`）。`←` `→` で工程送り（施工順）
- 設計タブ → パラメータ: スライダ変更で即時再生成、設計基準チェックが OK / NG 表示
- 表示タブ → 仕上げ色: 標準色を切り替えると塗装対象部品の色が一括で変わる
- 解析タブ: 断面表示、カラーコード（規格/特注・サブAssy・材質分類・質量ヒート）、干渉チェック
- 設計タブ → 書き出し: 設計データ JSON / 部品表 TSV をクリップボードへ
