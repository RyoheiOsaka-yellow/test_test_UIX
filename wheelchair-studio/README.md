# Wheelchair Assembly Studio

アクティブタイプ車椅子（リジッドフレーム・24 インチ・キャンバー付き）を CATIA 風に **順次分解・断面・カラーコード・パラメトリック設計** できる単一 HTML ダッシュボードです。`index.html` をブラウザで開くだけで動きます。

VolaTrap 版と同じコア（`../studio-core/`）から生成しており、UI・操作・折りたたみ・分解バーはすべて共通です。

## モデル（17 品番 / 28 個）

| サブAssy | 部品 |
| --- | --- |
| A1 駆動輪 | 駆動輪 リム/スポーク/ハブ ×2、タイヤ 24×1 ×2、ハンドリム ×2、クイックリリースアクスル ×2 |
| A2 フレーム | メインフレーム φ32 t1.8（リジッド）、アクスルプレート ×2、バックレストフレーム（折りたたみ）、プッシュハンドル ×2、キャスターフォーク ×2、キャスター 5" ×2、フットプレート、サイドガード ×2 |
| A3 シート | シートクッション、シートスリング、バックレスト張地 |
| A4 走行安全部品 | ホイールロック ×2、転倒防止バー ×2 |

フレームは中空チューブ（ラーテ形状）で体積を計算しているため、質量は肉厚 1.8 mm のアルミ 7005 として算出されます。

## 設計パラメータ

座幅 / 座奥行 / 前座高 / 後座高（差がシートダンプ）/ 駆動輪径 (20–26") / キャンバー角 (0–12°) / バックレスト高 / キャスター径 (3–6") / アクスル前後位置

## 目標値（JIS T 9201 手動車椅子）

| 項目 | 目標 |
| --- | --- |
| 全幅 | ≤ 700 mm |
| 全長 | ≤ 1200 mm |
| 全高 | ≤ 1200 mm |
| 回転円直径 | ≤ 1500 mm（アクスル中心から前端までの距離と全幅から算出） |
| 総質量 | ≤ 12,000 g |
| シートダンプ | ≤ 80 mm |

## 分解手順（既定）

1 クッション → 2 QR アクスル → 3 駆動輪 → 4 タイヤ → 5 ハンドリム → 6 転倒防止バー → 7 ホイールロック → 8 プッシュハンドル → 9 バックレスト張地 → 10 バックレストフレーム → 11 サイドガード → 12 シートスリング → 13 フットプレート → 14 キャスター → 15 キャスターフォーク → 16 アクスルプレート → 17 メインフレーム

工程番号と工具はプロパティパネルから編集できます。
