## 3. 1to1 レイヤー (新規・宇都宮版に無い部分)

宇都宮版の分析は**座席単位の集計**まで。1to1 基盤にするには個客IDを軸に据える。

```
fan_id ──┬─ 属性 (居住地/年代/加入日/会員ティア)
         ├─ 取引 (チケット・F&B・グッズ・駐車)
         ├─ 行動 (入場ゲート・滞在・回遊・退場)
         ├─ 露出 (どの席で・どの看板を・何インプレッション浴びたか)
         └─ 接触 (メール/アプリPush/広告・開封・CV)
```

これにより実現する分析:

1. **個客プロファイルカード** — 座席クリック → 実在ファンのRFM・LTV・来場履歴・嗜好
2. **セグメント可視化** — 3D座席をセグメント色で塗る (新規/リピーター/シーズン券/転売購入/観光客)
3. **スポンサー露出の個客帰属** — 「Sponsor X は今季、25-34歳 LA在住 高LTV層に N インプレッション」
4. **Next Best Action** — 個客別の推奨オファー (席アップグレード/F&Bクーポン/次戦送客)
5. **個客willingness-to-pay 起点の動的価格** — セクション平均でなく個客分布で価格を出す
6. **ジャーニー再生** — 特定ファンの1試合を時系列で3D再生 (到着→ゲート→売店→着席→退場)
7. **チャーン予測** — 更新確率の低いシーズン券保有者を座席上でヒートマップ表示
