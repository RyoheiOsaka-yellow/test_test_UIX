# Crypto.com Arena — 1to1 マーケティング基盤 (xStadium Digital Twin)

ブレックスアリーナ宇都宮版デジタルツインと**同一のアーキテクチャ文脈**で
Crypto.com Arena (Los Angeles) を再現し、その上に **個客 (1to1) レベルの分析基盤** を実装したもの。

**➡ [`index.html`](index.html) を開くだけで動きます**（単一ファイル・3.8MB・外部依存なし・完全オフライン）

- 所在: 1111 S Figueroa St, Los Angeles, CA / 中心 34.043018, -118.267254
- 収容: **19,079**（バスケ）/ 18,250（アイスホッケー）/ 20,000（コンサート）
- 開業 1999-10-17 / 設計 NBBJ / 建設費 $375M
- テナント: Lakers (NBA) / Kings (NHL) / Sparks (WNBA) / コンサート興行

## 2. 1to1 マーケティングレイヤー

**19,079席 = 19,079の顧客接点。** 1席1レコードで個客属性・取引・行動・媒体露出を保持する。

### 座席レイヤー（9種）
観客 / **セグメント** / **LTV** / **離反リスク** / 販売率 / 席種 / **スポンサー露出** / **視認等級** / 価格最適化

### 個客プロファイル（座席クリック）
`fan_id` ・セグメント・商圏・年代・LTV・来場回数・継続年数・今回の取引（定価/実売/入場時刻/ゲート）・
場内購買・**RFM**・**更新見込**・**この席から見える媒体と視認等級**・**Next Best Action（期待CVR上振れ・想定増分）**

### 分析モデル

| 指標 | 式 |
|---|---|
| 媒体露出重み | `w = 正対度^0.8 × 視線一致^0.5 ÷ (1 + (視距離/22)^1.35)` |
| 視認等級 | 文字視角 `arcmin = 文字高 ÷ 視距離 × 3437.75`　A≥60′ / B≥35′ / C≥18′ / D≥8′ |
| 実効露出単価 | `年間契約額 ÷ (実効露出 × 年44興行)` = 1人に1試合しっかり見られる単価 |
| 媒体デリバリー額 | `Σ (年間契約 ÷ 44) × (今回の実効露出 ÷ 満席時の実効露出)`（シーズン積算で契約総額に一致） |
| 価格最適化 | `f = 0.74 + 0.40×区画販売率 + 0.12×露出 + 0.08×需要弾性`（0.82〜1.32） |
| 離反リスク | セグメント基準離反率 × (1 − 0.34×ロイヤルティ) + 右裾ノイズ |

### ツール
- **2D席図** — 19,079席を平面展開。3Dと双方向連動、クリックで同じ個客カード
- **分析ボード** — 媒体・スポンサー / セグメント / 価格 / リテンション の4タブ
- **個客ジャーニー再生** — 高LTV×高離反リスクの個客を選び、ゲート→コンコース→ボミトリー→着席を3D再生

## 3. データ

現在の個客データは **決定的PRNGによる合成データ**（同じ席は毎回同じ人物になる再現性あり）。
GIS・アリーナ形状・区画構成・交通網は**実データ / 公式資料準拠**。

実データへの差し替えは [`docs/DATA_SPEC.md`](docs/DATA_SPEC.md) の通り。
パネルの「📥 tickets.csv を読み込む」から区画別販売率を即時上書きできる
（`game,section,sold,capacity` または `game,section,rate`）。

## 5. ビルド

```bash
python3 tools/fetch_osm.py          # OSM取得 → data/scene_data_la.json  (--from-cache で再変換のみ)
./build.sh                          # src/ + data/ + vendor/three.min.js → index.html
```

`src/` は番号順に連結される: `00_head` → `01_ui` → `10_core` → `20_site` → `30_entrance`
→ `35_layout` → `40_arena` → `50_bowl` → `60_data` → `70_analytics` → `75_level`
→ `80_panel` → `90_modules` → `99_boot`
