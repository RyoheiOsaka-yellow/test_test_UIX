# 計算ロジック解説：ecowinハイブリッド 体育館デジタルツイン

対象: `ecowin-gym-twin/`（体育館・1棟版 v9：日出町 中央体育館の設計図による建物と設備、大分の観測気象、断面図と平面図、建物の仕様の入力）

## 0. この資料について

まだ ecowinハイブリッドを設置していない体育館に設置した場合の、温度・風・電力の変化を推計して3Dで見せるデモです。

- 画面の値はすべて**簡易モデルによる推計値**で、実測値ではありません。
- 気象は、「大分」を選ぶと日出町に最も近い大分地方気象台の**2025年の観測値**です（1.1節）。「東京都練馬区」も観測値で、ほかの地域は平年値から合成した**ダミー**です。
- 係数は【出典】【推計】【仮定】のいずれかです。住宅版（mock-v1）で使った係数は同じ値を引き継いでいます。

## 1. 全体像

```
気象（1時間値・1年分）＋建物＋使い方
 └─ 年間計算（5分刻み）… 2章
      空気温度・構造体温度・屋根や壁の表面温度・空調出力・消費電力 を
      空調なし／エアコンのみ／ecowinハイブリッド の3方式で求める
          ├─ 年間の電力量・料金・CO2・暑さ指数の時間数 … 5章
          └─ ある時刻の館内分布（0.5m格子）… 3・4章
               放射温度 → 体感温度・暑さ指数、風速
```

時刻を動かすと1時間値のあいだを補間し、分布はなめらかに追従します。

### 1.1 気象データ（2025年1月1日〜12月31日の1時間値）

| 項目 | 出典 |
|---|---|
| 大分：気温・湿度・風速・全天日射量 | 気象庁「過去の気象データ」大分地方気象台の1時間値を加工（欠測は前後の値で補間）。日射量も観測値 |
| 練馬：気温・湿度・風速 | 気象庁「過去の気象データ」アメダス練馬の1時間値を加工 |
| 天気の区分 | 同じ観測値から、日降水量 1mm 以上を雨、日照 6時間以上を晴れ、それ以外をくもりとした（画面表示用） |
| 練馬：日射量 | アメダス練馬は日射量を観測していないため、Open-Meteo Historical Weather API（ERA5 再解析、CC BY 4.0）の値 |

年間の最高気温は 38.5℃、最低気温は −3.5℃ です。データは `data/nerima2025.js` にあります。

### 1.2 パネルの配置・左右比較・保存・画像出力

- 3D の中でパネルをドラッグすると 0.1m 単位で移動し、ダブルクリックで向きが 90° 変わります。動かしている間は、そのパネルが各地点から見える大きさだけを差し替えて分布を更新し、離したときに年間計算をやり直します。
- 「左右で比較」では、同じ視点・同じ時刻・同じ色の尺度で、左にエアコンのみ（または空調なし）、右に ecowinハイブリッドを並べます。断面表示のときは上下に並びます。
- 「配置を保存」「読込」は、条件とパネルの位置をそのブラウザの中に保存します。「画像にする」は、いまの3D表示に日時・条件・凡例を添えた1枚の画像を作ります。
- 「床の色分布」を外すと、色を重ねない体育館の内部を見られます。
- 「空気の層」は、館内の空気温度を 約 1m × 1m × 0.5m の立体格子に入れ、視線に沿って重ねて描きます。腰の高さの空気温度との差が大きいほど濃く、暖かい空気が赤、冷たい空気が青です。気流は流れの向きを示す短い線と、吹出しの空気の広がりを示す煙で表します。人の色は、立っている場所の床の色と同じ値です。
- 「断面図」は、エアコンを通る A−A 断面の空気温度（建物の輪郭つき）、選んだ高さの平面の値と9地点の数値、高さごとの館内平均の空気温度を、2つの方式で並べた2Dの図面です。「画像にする」でそのまま画像にできます。
- 再生速度は 1秒＝3分（初期値）・5分・10分・30分・1時間・6時間から選べます。
- 画面は、左に「見どころ・条件」「いまの値」「年間の効果」のパネルをまとめ、中央の3D表示を広く取っています。「パネルを閉じる」で3D表示だけにできます。
- 「見どころ」の5つのボタンは、日時・方式・色で見るもの・視点をまとめて切り替えます（真夏の午後の空調なし／夏の左右比較／真冬の朝の断面／風の比較／年間の電気代）。
- 3D表示を大きく取るため、上の切り替えは1段（画面・方式・色で見るもの・「表示」）、下の時間の操作は1行（再生・日付・時刻のつまみ・速さ・グラフ）にまとめています。重ねて表示するものと色を見る高さは「表示」、日付の指定と最も暑い日・寒い日は日付のボタン、再生の速さは「速さ」のボタンから開きます。「大きく表示」で3Dだけを画面いっぱいにできます。年間マップと1日の推移は「グラフ」を入れたときだけ出ます。
- 操作部品は役割で形を分けています。1つだけ選ぶものはつながったボタン、入・切はチェック印つきの丸いチップ、数値は増減ボタン、断熱性能とパネルの置き方は説明や図のついた選択肢です。

#### 2.1.1 建物の仕様の入力（図面・仕様書から）

屋根と外壁は、材料と厚さの層を並べて熱の通しやすさを求めます。

```
U ＝ 1 ÷（表面の熱抵抗 ＋ Σ 厚さ ÷ 熱伝導率）     表面の熱抵抗：屋根 0.13、外壁 0.15 ㎡K/W
```

材料の熱伝導率（W/mK）：鋼板 55、コンクリート 1.6、ALC 0.19、石こうボード 0.22、合板 0.16、木毛セメント板 0.13、グラスウール16K 0.045、同24K 0.038、ロックウール 0.038、押出法ポリスチレンフォーム 0.028、硬質ウレタンフォーム 0.024、吹付け硬質ウレタン 0.034。空気層は 0.09、遮熱シート＋空気層は 0.3 ㎡K/W の熱抵抗として扱います。窓は 単板 U6.0／単板＋遮熱フィルム U5.8／複層 U3.5／Low-E複層 U2.3。屋根の遮熱は、日射を吸収する割合を なし 0.7、遮熱塗装 0.4、遮熱シート 0.25 とします。いずれも一般的な目安の値です。仕様は JSON で書き出し・読み込みでき、図面の画像を控えとして添えられます。

| 断熱性能 | 屋根 U | 壁 U | 窓 U | すきま風 | 日射取得率 |
|---|---|---|---|---|---|
| 低（既存・無断熱） | 2.5 | 2.0 | 6.0 | 1.0 回/h | 0.75 |
| 中（一部改修） | 1.0 | 1.0 | 4.0 | 0.6 回/h | 0.65 |
| 高（新築・改修済み） | 0.4 | 0.5 | 2.3 | 0.3 回/h | 0.45 |

U の単位は W/㎡K。いずれも【推計】です。

### 2.2 熱のつり合い

空気と、床・壁の構造体の2つの温度を持ちます。

```
空気：   屋根からの熱 ＋ 窓からの熱 ＋ すきま風・換気 ＋ 構造体との熱交換 ＋ 人と照明の半分 ＋ 空調
構造体： 空気との熱交換 ＋ 人と照明の半分 ＋ 窓から入る日射 ＋ 壁・床から逃げる熱 ＋ パネルの輻射
```

- 屋根の外側は、日射で外気より熱くなる分を加えた温度（外気温 ＋ 0.7×日射÷23）で計算します。
- 人は1人あたり顕熱 150W（運動）または 75W（観覧）、照明は 8W/㎡、換気は1人 20m³/h【推計】。
- 熱容量は、空気が体積分の3倍、構造体が 290MJ/K【推計】。

### 2.3 上下の温度差

```
勾配 G [℃/m] ＝ 0.04 ×（屋根の内側の表面温度 − 空気温度）   … 屋根が熱いとき
             ＋ g ×（空気温度 − 外気温）×（0.4 ＋ 0.6×暖房出力の割合） … 暖房中のみ
```

g はエアコンのみ 0.03、ecowinハイブリッド 0.01（住宅版と同じ値【推計】）。天井付近の空気温度は「腰の高さの空気温度 ＋ G × 高さの差」で、屋根から逃げる熱はこの温度で計算します。暖房で天井付近が熱くなるほど損失が増える、という大空間の性質を表しています。

### 2.4 空調

| 項目 | エアコンのみ | ecowinハイブリッド | 区分 |
|---|---|---|---|
| 冷房能力 | 左の値 ÷ 0.7 ＝ 約229kW【仮定】 | 160kW（20.0kW × 8系統） | 設計図（機器表）／補正係数 0.7 は熱負荷計算書 |
| 暖房能力 | 左の値 ÷ 0.7 ＝ 256kW【仮定】 | 179.2kW（22.4kW × 8系統） | 同上 |
| 吹出し風速 | 4.3 m/s（壁掛形の強風） | 2.2 m/s（弱風運転） | 推計 |
| 送風機の電力 | 3.4 kW | 1.2 kW | 推計 |

- 運転は設定した時間帯のみ。11〜4月は暖房、5〜10月は冷房です。
- **予熱運転**：ecowinハイブリッドだけ、運転開始を 0〜2時間早められます（初期値は「なし」）。早めた分の電力は消費電力量に含まれます。
- エアコンのみは空気温度が設定温度になるよう出力を決めます（能力が上限）。
- **同じ体感で比べる**：ecowinハイブリッドは、「この部屋をエアコンだけで設定温度にしたときの館内平均の体感温度」を目標に運転します。パネルの輻射（放射温度の変化）と風の弱さ（体感温度の式の重み）を織り込んで必要な空気温度を求め、設定温度からの調整幅は最大 2.5℃ とします【推計】。年間を通じた運転時間中の体感温度の差は 0.1℃ 以内です。
- パネル表面は暖房 45℃（S4 の下限）、冷房 15℃【仮定】。放熱量は 11W/㎡K × 両面の面積 × 温度差で、55% を輻射（構造体へ）、45% を対流（空気へ）とします【推計】。
- 消費電力 ＝ 出力 ÷ COP ＋ 送風機。COP は機器表の消費電力から、冷房 3.08（外気 35℃）、暖房 3.41（外気 7℃）を基準に外気温で変えます。冷房は潜熱分として 1.25 倍します【推計】。
- 輻射パネルの放熱面積は、正面の面積（両面）にフィンの分として 3倍を掛けます【仮定】。

## 3. 放射温度・体感温度・暑さ指数

### 3.1 放射温度（MRT）

評価点から床・屋根・壁・窓・パネルが見える大きさ（立体角）で、各面の温度を平均します。面はすべて長方形なので、立体角は近似ではなく厳密な式で求めています。

```
MRT ＝ Σ（面 i が見える割合 × 面 i の表面温度）
```

パネルは正面に近いほど大きく見えます。設計図どおり2階ギャラリーに置いた場合、人の高さからパネルが見える割合は館内平均で 0.5% ほどで、放射温度への影響は小さくなります。同じパネルを1階の壁際に下ろした場合と比べられます。

### 3.2 体感温度

```
体感温度 ＝ A × 空気温度 ＋（1 − A）× MRT      A は風速 0.2m/s 以下で 0.5、1.0m/s 以上で 0.7
```

### 3.3 暑さ指数（WBGT）

```
WBGT ＝ 0.7 × 湿球温度 ＋ 0.3 × 黒球温度   （屋内の式）
```

湿球温度は空気温度と湿度から（Stull の式）、黒球温度は空気温度・MRT・風速から求めます。区分は日本スポーツ協会の熱中症予防運動指針（25以上 警戒、28以上 厳重警戒、31以上 危険）です。冷房中の湿度は 60% を上限とします【推計】。

## 4. 風と空気温度の分布

吹出し口からの噴流として近似します（数値流体解析ではありません）。

```
相対風速 ＝ min(1, 3.5 ÷ 距離) × exp(−（軸からのずれ ÷ 幅）²)     幅 ＝ 0.35 ＋ 0.11 × 距離
```

壁掛形の室内機は、ギャラリーの高さ（約 4.9m）からアリーナ中央へ吹き出します。風速は吹出し口から 1.8m までは一定、その先は距離に反比例して弱まるとしています。暖房の温風は中央付近で人の高さに届いたあと浮き上がり、冷房の冷風は床に届いて床に沿って流れます。

### 4.1 流れの表示（3Dの流線）

3Dの中の流線は、見た目のための流れの場に粒を乗せて描いています。床の色（風速）や年間計算には使っていません。

| 成分 | 内容 |
|---|---|
| 噴流 | 4章の式と同じ形。軸の向きに沿って流れ、軸がゆっくり左右にゆらぐ |
| 巻き込み | 噴流のまわりの空気が、軸へ向かって引き寄せられる弱い流れ |
| 循環 | 低いところを中央へ、中央で上がり、天井に沿って外へ、壁際で下りる2つの渦。強さは吹出し風速と上下の温度差に比例 |
| パネルまわり | 暖かいパネルの前は上昇流、冷たいパネルの前は下降流（ecowinハイブリッドのみ） |
| 乱れ | 場所と時刻でなめらかに変わるゆらぎ。流れが速いところほど大きい |

粒は吹出し口・パネルの前・館内のあちこちから生まれ、通った跡を尾として描きます。色は、吹出しやパネルの熱を帯びた空気が暖色・寒色で、まわりと混ざるにつれて無彩色に近づきます。輻射は、パネルの面からまっすぐ進む短い光の筋で表します（冷房時はパネルへ向かう向き）。係数はいずれも表示用の【仮定】です。

## 5. 年間の集計

| 項目 | 計算 |
|---|---|
| 消費電力量 | 1時間ごとの消費電力の合計 |
| 削減率 | 1 − ecowin ÷ エアコンのみ。**メーカー公表の最大値 34% を上限**とし、超える場合は上限で表示してその旨を示す |
| 最大需要電力 | 1時間平均の消費電力の最大値 |
| 電気代 | 電力量 × 単価（初期値 22円/kWh【仮定】）＋ 最大需要電力 × 基本料金（初期値 1,100円/kW月【仮定】）× 12 |
| CO2 | 電力量 × 0.423 kg-CO2/kWh |

初期条件（大分の2025年観測気象・断熱「低」・80人・パネル16台・予熱なし）の結果：エアコンのみ 89.1MWh、ecowin 87.3MWh、削減率 2.0%。最大需要電力 97kW → 67kW、電気代 324万円 → 281万円。空調なしで暑さ指数が「厳重警戒」以上になるのは、利用時間のうち年間 969 時間です。断熱「中」では削減率 5.1%、「高」では 12.1% です。

### 5.1 節約額シミュレーション

| 項目 | 計算 |
|---|---|
| 削減率 | 「この計算の値」「メーカー公表の最大値 34%」「1〜34% の任意の値」から選ぶ |
| 電力量料金の節約 | エアコンのみの消費電力量 × 削減率 × 単価 |
| 基本料金の節約 | 計算上の最大需要電力の差 × 基本料金 × 12（削減率の選び方によらない） |
| 1年間の節約額 | 上の2つ ＋ 保守費の差 |
| 回収年数 | 導入費用の差額 ÷ 1年間の節約額 |
| CO2・杉の木 | 削減電力量 × 0.423kg-CO2/kWh、杉1本あたり年 14kg で換算（ランニングコスト試算表と同じ換算） |

導入費用の差額（初期値 1,500万円）と保守費の差（初期値 0円）は仮の値です。

### 5.2 ecowinの強み（いまの時刻の比較）

風の強さ（評価面の最大風速）、場所による温度のムラ（体感温度の標準偏差）、天井付近にたまる熱（腰の高さとの空気温度の差）、消費電力、体感温度を、エアコンのみと並べて示します。ecowin が 3% 以上小さい項目に印を付け、差が無い項目は「ほぼ同じ」と表示します。

## 6. 確かめ方

`node tests/model.test.cjs` で、気象の再現性、立体角の合計、設定温度の維持、上下温度差の大小、削減率の上限などを確認します。

## 7. 前提と限界

- 気流は傾向を示す近似で、障害物・扉の開閉・自然換気は扱っていません。
- 屋根は平らな面、室内は観覧席の段やトラスの無い箱として放射を計算しています。
- 窓の大きさ、ギャラリーの奥行、断熱の仕様は設計図に記載がなく、目安の値です。エアコンのみの能力は、補正係数 0.7 で割り戻した仮の値です。
- 設計図の配置では、パネルが人から遠く小さく見えるため、放射による体感の変化は小さく出ます。年間の消費電力量の差も小さく、主な差は最大需要電力（基本料金）と風の弱さに出ます。
- ecowinハイブリッドは能力が 70% のため、冬の朝の立ち上がりはエアコンのみより遅く出ます。実際の運用では運転開始を早める想定です（画面の「空調開始」で確認できます）。
- 冷房時のパネル表面温度、電力単価、基本料金は仮の値です。

## 8. 実物件に合わせるために必要な情報

| 分類 | 必要な情報 | 使い道 |
|---|---|---|
| 建物 | 所在地、平面寸法、天井高（軒・棟）、屋根と壁の仕様、窓の位置と大きさ、図面 | 形と断熱の設定 |
| 使い方 | 利用時間帯、人数、用途（授業・部活・大会・避難所）、冷暖房したい範囲 | 人の発熱、運転時間 |
| 既存設備 | 空調の有無・機種・能力、契約電力、電気料金の明細（12か月分） | 比較対象と料金の設定 |
| 提案内容 | パネルの機種・台数・置ける場所、組み合わせる空調機の能力と位置 | パネルと吹出し口の配置 |
| 製品データ | 冷房時のパネル表面温度、パネル1台あたりの能力、実測の温度分布 | 仮定の置き換えと校正 |
