# ALDREX デモ（株式会社アルテック / ALUTECK 仕様）

`anglex_demo`（トンネル照明器具 取付金具・落下防止材）の HTML を、**株式会社アルテック（ALUTECK CO.,LTD.）**（https://www.aldrex.jp/）向けに作り替えた単一ファイルのデモです。

- 実体： `index.html` 1ファイル（外部依存は three.js / pdf.js / Google Fonts の CDN のみ）
- ブラウザで直接開けます。サーバ不要。

## 1. 題材のとらえ方

公開情報から読み取った同社の姿：

- 事業内容は **建築用装飾金属販売、家具製品製造販売** ＋ 国土交通大臣許可の **とび・土工／板金／建具／内装仕上工事業**
  → 製品を売るだけでなく、**取付工事まで請け負う**
- 製品ブランドは **ALDREX**（アルミドレイン／改修用ストレーナーキャップ／オーバーフロー管カバー／オプション）と **ALPHASE**（物干金物）
- 関連会社 **(株)東京ダイカスト・茅野工場** がグループの生産拠点
- 特需営業部という窓口があり、日本・国際特許／実用新案／意匠権を保有

**主力の「改修用ストレーナーキャップ」は大規模修繕の現場に入る商品**です。そこで本デモは、
マンション・ビルの屋上／ベランダ防水改修を舞台に、この商品カテゴリ特有のボトルネックを題材にしました。

> **改修現場には既存図面がない、あっても古い。**
> 型番は「防水種別・設置部位・引き方・適用管径・数量」の5つが決まって初めて確定するのに、
> 改修図にはそのうち何項目かが描かれていない。だから現場実測と電話確認で型番を決めている。

これを AI が図面・仕様書・現場写真から補完する、という筋立てです。

## 2. 何を作ったか

### ① 現場管理（工程管理・図面共有）— 今回の主役

現場単位で、製品供給から取付工事までを1画面に集約するモジュールです。

- **現場ダッシュボード** — 進行中の現場、遅延している工程、承認待ち・差戻しの提出図、未回答の質疑を横断で集計
- **工程表（ガント）** — 現場調査・実測 → 拾い出し・型番選定 → 提出図承認 → 受注・生産手配 → ダイカスト生産（茅野工場）→ 表面処理 → 出荷・搬入 → 取付工事 → 通水・散水試験 → 引渡。
  基準日（2026/08/18）を軸に遅延／遅延リスクを色分け
- **提出図・図面共有** — 図面番号・Rev・状態（承認済／承認待ち／差戻し／作成中）・更新日・**既読者数**・滞留日数。
  その場で「承認する」「改訂を上げる」が動作します
- **質疑・是正（RFI）** — 宛先・期限・現場写真つき。期限超過を赤で強調。回答を記録すると関連図面に紐づきます
- **品目・生産進捗** — 品目ごとに（受注 → 金型段取り → 鋳造 → 機械加工 → 表面処理 → 組立 → 検品 → 搬入 → 取付）のどこで止まっているか
- **検査記録** — 既存管内径の実測記録、出荷検査、通水試験、耐風圧仕様の適合確認など引渡書類になるものを集約

デモの現場は3件：

| 現場 | 内容 |
|---|---|
| 星和第2マンション 大規模修繕（168戸） | 屋上 RD-1〜48（DSR-22）／ベランダ BV-1〜120（TR-15HK）／新設24 |
| 品川フロントビル 屋上防水改修（軒高42m） | 屋上26か所（耐風圧仕様）／オーバーフロー管カバー40型 12 |
| 市営桜台住宅 外壁・防水改修（184戸） | ベランダドレン184／アルフェーズ PHJS-660 184セット |

### ② かんたん見積（チャットでの型番選定）

品目 → 設置部位 → 数量 → 表面処理 → **既存パイプ内径** を順に答えると、
型番候補・概算・確認が要る項目（黄＝推論／赤＝要判断）がその場で出ます。

選択肢は実際の製品体系に合わせてあります（φ40〜60／φ60〜100／φ95〜115／φ115〜140、呼び径50φ、
PHJS-660／PHJ-650／PHM-550 など）。

### ③ 改修図から型番選定（3D）

屋上伏図・詳細図をドロップ（サンプル同梱）→ 解析 → 品目選択 → 3Dで納まりを確定。
3Dアセンブリは **屋上ドレン改修の実物の納まり** を組み直しました。

- RCスラブを前後2枚の帯にして断面として見せ、中央の隙間に納まりが見える
- 既存たて引管＋既存つば（撤去せず活かす）／ラバーベンダー（ゴム圧着）／立上り筒／つば／ストレーナーのカゴ
- よこ引・角度自在型（TR-15HK）は腰壁を貫通し、調整角 θ で既存管の勾配に追従
- アルミドレイン（新設部）はシート張り掛け代つき
- 分解表示・画層ON/OFF・要判断ハイライトはそのまま動作

**整合チェック**は「穴芯ズレ」から **「既存管との芯ズレ・適用レンジ判定」** に作り替えました。

```
既存管内径 実測φ118 ⇔ ラバーベンダーL 適用φ115〜140   +3.0mm   許容内
既存つば変形 ⇔ キャップ密着面（BV-14）                3.4mm    要修正
```

**要判断（3Dの赤ハイライト）**：

- RD-2 ほか6か所が実測 φ112 → DSR-22 ラバーベンダーL（φ115〜140）は適用範囲外、S（φ95〜115）へ型番変更が必要
- BV-14 の既存ドレンつばが変形 → 密着面が確保できない恐れ

### ④ 発注時確認①〜⑤

「注文時確認」の中身を、この商材で本当に必要な5項目に置き換えました。

1. 防水種別（DR＝塩ビシート防水用／DF＝一般防水用）
2. 設置部位（屋上／ベランダ／中継／側溝）
3. 引き方・角度（たて引／よこ引・角度固定／よこ引・角度自在）
4. 適用管径・実測内径
5. 数量・耐風圧仕様

各品目について、AIが図面・仕様書・現場写真から自動充填した項目を明示します。

### ⑤ 既存機能との接続

- 図面共有の **「3Dで型番選定」** → その図面を納まりモードで開く
- 品目・生産進捗の **「3Dで見る」** → その品目の3Dディテールを直接開く
- 案件・見積カードの **「🏗 現場」** → 紐づく現場台帳へ移動
- 3D画面右下の **「現場台帳」** ボタン → 現場一覧へ戻る

### ⑥ 見た目

`ALDREX` ブランドに合わせ、配色を紺・グレー基調へ全面調整しました（元は暖色のテラコッタ基調）。

## 3. 画面の流れ

```
サインイン（ダミー認証・任意の入力でOK）
  └ 今日はどの入口から？
       ├ 🏗 現場管理（工程・図面共有）  ← 現場一覧 → 現場詳細（5タブ）
       ├ 💬 かんたん見積（チャット）    ← 会話で型番を絞って概算 → 見積書発行
       └ 📐 改修図から型番選定（3D）    ← 図面D&D → 解析 → 品目選択 → 納まり3D → 概算見積
```

## 5. データの差し替え箇所

すべて `index.html` 内のインメモリ定数です。

| 内容 | 定数 |
|---|---|
| 現場・工程・図面・質疑・生産進捗・検査 | `SITES` |
| 案件と見積バージョン履歴 | `PROJECTS` |
| 品目（3D・積算の対象） | `MEMBERS` |
| 発注時確認①〜⑤の自動充填内容 | `SPEC_CAT` / `ORDER_FIELDS` |
| チャットの選択肢（品目・部位・数量・仕上げ・管径） | `PARTS` / `CHAT_TUNNELS` / `CHAT_QTYS` / `FINISH_OPTIONS` |
| 適用管径レンジ ⇔ 型番の対応表 | `PIPE_TABLE` |
| 単価・歩掛り | `STEEL_UNIT` / `PROC` / `RATES` ほか |
| 3D 納まりモデル | `buildAssembly()` / `buildOverlays()` |
| 基準日（ガントの「今日」線） | `TODAY` |

金額・数量・現場名・取引先名（新光建設、東和建設工業 等）はすべて説明用のサンプルで、実在の案件ではありません。
製品名・型番・適用管径は公開されているカタログ情報に合わせていますが、細部は要確認です。
