# とちぎ観光インテリジェンス（栃木県観光分析ダッシュボード）

`index.html` 単体で動作する栃木県の観光分析ダッシュボード。
ブレックスアリーナ宇都宮デジタルツイン(XBUILD)のデザイン言語を踏襲し、
Three.js による県全域の「点描(ポイントクラウド)3D地形」を中心に、
観光を9つのビューで分析できる。

### 3Dシーンの構成 — すべて実データ(国土地理院)

| レイヤー | データ源と内容 |
|---|---|
| 地形 | **標高タイル(DEM10B)** を 420×460 グリッドに再標本化した実標高(最高2,578m=日光白根山)。PNGのR,Gチャンネルに16bitで格納しHTMLに同梱。等高線・点群・写真地形の変位はすべてこの実標高から生成 |
| 航空写真 | **シームレス空中写真(z11)** を実標高で変位。県外はトーンを落として県域を際立たせる |
| 県境 | 地理院ベクトルタイルの境界線をラスタ化・フラッドフィルして復元した実形状(面積6,357km² / 実際6,408km²、誤差0.8%) |
| 建物 | **ベクトルタイルの建物ポリゴン** を z13(県全域)+z14(市街地)+z15(主要都市・観光地) で取得し、最小外接矩形(中心・幅・奥行・方位)へ変換。120mグリッドで密度上限をかけ **45,624棟** を格納。※高さのみ実測値がないため床規模から推定 |
| 道路 | 高速自動車国道・国道・都道府県道を `rdCtg`/`motorway` で分類し **2,266区間** |
| 鉄道 | **462区間**。路線コード(`rtCode1`)でまとめ、路線名ラベルとの最短距離で命名 → 新幹線/JR在来/東武/第三セクターに分類 |
| 河川・湖沼 | 河川 118 本、湖沼 43(中禅寺湖・渡良瀬遊水地ほか) |
| 地点 | 山頂 44(標高付・山名ラベル対応)、鉄道駅 103、IC・JCT 39 |
| 観光・分析 | 観光地点ビーコン、市町バブル、導線/来訪圏の3Dアーク+流動パーティクル |

- ヘッダーの「◆ 点群ビュー」で実標高の点群＋ワイヤーフレーム地形に切替
- 左パネルの「地物レイヤー」チップで各レイヤーを個別にON/OFF
- 左コントロールパネル・右分析パネル・タイムラインはすべて折りたたみ可能
- ドラッグ回転/Shift+ドラッグ移動/ホイールズーム、エリア・地点へのカメラフライト
- 山頂・駅・IC・観光地点はホバーで情報表示、クリックで詳細＋フライト
- 航空写真タイルを取得できない環境では自動で点群・ワイヤー地形に切替(標高・地物は実データのまま動作)

## ビュー構成

| ビュー | 内容 |
|---|---|
| L0 概況 | 県全体KPI、コロナ回復トレンド(2019=100指数)、月別入込、分類別、国籍別 |
| L1 観光マップ | 主要観光地点56件+市町バブルの2レイヤーSVGマップ(カテゴリ/エリア絞り込み) |
| L2 エリア分析 | 市町別ランキング(年切替)、エリア別シェア、宿泊構造、市町データテーブル |
| L3 導線設計 | 広域ゲートウェイ7系統、周遊モデルコース7本のマップ表示、導線設計の論点 |
| L4 行政計画 | とちぎ観光立県戦略2026-2030のKGI/KPI進捗、3基本戦略×16主要施策、年表 |
| L5 AI分析 | 格納データから自動算出するインサイト、2030目標ギャップ、JSON/AIプロンプト書き出し |
| L6 来訪圏 | 発地→エリアの推計来訪流をグラデーション帯アーク+KDE風ヒートで可視化(人口×距離グラビティ仮説モデル、エリア切替) |
| L7 経済効果 | 観光消費額(KGI 9,656億円)の市町按分推計。総消費額/宿泊寄与/インバウンドの指標チップ切替、2030試算カード |
| L8 シームレス | 実座標の連続マップビューア。国土地理院航空写真がズームでz8→z16に高精細化、県全域⇄各エリアのフライト移動(取得不可環境はベクター表示) |

下部のイヤースライダーで2019〜2024年を切替(KPI・マップ・ランキングが連動)。

## データ

すべて `index.html` 内の `TOCHIGI_DB` オブジェクトに格納。
「L5 AI分析 → 全データをJSONでコピー」で生成AI等に持ち出して追加分析できる。

- 県計 年次系列(入込・宿泊・外国人宿泊) 2019-2024
- 月別入込 2023/2024
- 市町別入込 25市町×6年、外国人宿泊(2024)
- 国・地域別外国人宿泊(2024)、分類別入込(2024)
- 観光地点56件(位置・カテゴリ・集客規模の推定指数)
- 広域アクセス導線7系統・周遊モデルコース7本
- とちぎ観光立県戦略2026-2030(KGI/KPI・基本戦略・主要施策・関連計画)

### 地理データの出典

国土地理院
- 標高タイル(DEM10B) https://maps.gsi.go.jp/development/ichiran.html
- 地理院ベクトルタイル(experimental_bvmap)
- 全国最新写真(シームレス)

※ 県境・道路・鉄道・河川の形状は表示用にDouglas-Peuckerで簡略化(約7m量子化)。
※ 建物は最小外接矩形で近似し、平面を一律3.2倍に拡大して県域スケールで視認できるようにしている(縦横比は保持)。高さのみ床規模からの推定値。
※ 標高は地形表現のため4.2倍に強調。
