# とちぎ観光インテリジェンス（栃木県観光分析ダッシュボード）

`index.html` 単体で動作する栃木県の観光分析ダッシュボード。
ブレックスアリーナ宇都宮デジタルツイン(XBUILD)のデザイン言語を踏襲し、
県全体の観光を6つのビューで分析できる。

## ビュー構成

| ビュー | 内容 |
|---|---|
| L0 概況 | 県全体KPI、コロナ回復トレンド(2019=100指数)、月別入込、分類別、国籍別 |
| L1 観光マップ | 主要観光地点56件+市町バブルの2レイヤーSVGマップ(カテゴリ/エリア絞り込み) |
| L2 エリア分析 | 市町別ランキング(年切替)、エリア別シェア、宿泊構造、市町データテーブル |
| L3 導線設計 | 広域ゲートウェイ7系統、周遊モデルコース7本のマップ表示、導線設計の論点 |
| L4 行政計画 | とちぎ観光立県戦略2026-2030のKGI/KPI進捗、3基本戦略×16主要施策、年表 |
| L5 AI分析 | 格納データから自動算出するインサイト、2030目標ギャップ、JSON/AIプロンプト書き出し |
| L6 来訪圏 | 発地→エリアの推計来訪流をグラデーション帯アーク+KDE風ヒートで可視化(人口×距離グラビティ仮説モデル、エリア切替) |
| L7 経済効果 | 観光消費額(KGI 9,656億円)の市町按分推計。総消費額/宿泊寄与/インバウンドの指標チップ切替、2030試算カード |
| L8 シームレス | 実座標の連続マップビューア。国土地理院航空写真がズームでz8→z16に高精細化、県全域⇄各エリアのフライト移動(取得不可環境はベクター表示) |

下部のイヤースライダーで2019〜2024年を切替(KPI・マップ・ランキングが連動)。

## データ

すべて `index.html` 内の `TOCHIGI_DB` オブジェクトに格納。
「L5 AI分析 → 全データをJSONでコピー」で生成AI等に持ち出して追加分析できる。

- 県計 年次系列(入込・宿泊・外国人宿泊) 2019-2024
- 月別入込 2023/2024
- 市町別入込 25市町×6年、外国人宿泊(2024)
- 国・地域別外国人宿泊(2024)、分類別入込(2024)
- 観光地点56件(位置・カテゴリ・集客規模の推定指数)
- 広域アクセス導線7系統・周遊モデルコース7本
- とちぎ観光立県戦略2026-2030(KGI/KPI・基本戦略・主要施策・関連計画)
