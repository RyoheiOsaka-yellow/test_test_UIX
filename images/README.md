# images フォルダ

このフォルダに以下のファイル名で画像を置くと、サイトに自動で表示されます。

| ファイル名 | 使われる場所 |
| --- | --- |
| `storefront.jpg` | TOPビュー（ヒーロー全画面の店構え画像） |
| `menu-food.jpg` | メニュー表「お品書き」 |
| `menu-drink.jpg` | メニュー表「お飲みもの」 |
| `menu-kaiseki.jpg` | メニュー表「火曜限定 特別会席」 |

- `storefront.jpg` が無い間は、提灯の灯りを模したフォールバック背景が表示されます。
- 横長（3:2 程度）・幅 1600px 以上の画像を推奨します。
