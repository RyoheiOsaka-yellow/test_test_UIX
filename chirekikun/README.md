# ちれきくん

指定調査機関向けの、地歴調査報告書の作成支援。資料（登記簿謄本・公図・住宅地図・空中写真・聴取記録・過去の報告書）を共有すると、エコ・テック様の報告書と同じ章立てで下書きを組み、根拠ページと公式出典を付けて出力します。

`index.html` を開くだけで動きます（1ファイル。ビルド済み）。

## デモ

入力せずに一連の流れを見せるための仕組みが2つあります。

- **デモを再生する**（ログイン画面、案件一覧）：ログイン → 新しい調査 → 対象地・目的・資料の入力 → 作成 → レポート → 確認・判断・出典 までを、字幕つきで自動で進めます。約70秒。途中で「停止」できます。`index.html#demo` で開くと最初から再生します。
- **入力例を入れる**（新しい調査の画面）：対象地・要望・資料9点をまとめて入れます。あとは「レポートを作成する」を押すだけです。

デモ用の資料は、川崎市川崎区貝塚一丁目の既往報告書を資料の種類ごと（登記簿、法人登記、公図、地図、空中写真、聴取記録、踏査写真、行政回答、調査メモ）に分けたものです。AIの読み取り結果に当たる部分だけ記録済みのデータを使い、結合・判定・所見・描画は本番と同じ処理を通します（`src/demo.js`）。

## 画面

| 画面 | 役割 |
|---|---|
| ログイン | メールアドレスとパスワード。試作版は認証サーバー未接続で、「デモ用アカウントで入る」でも入れます |
| 案件 | 案件ごとに、自治体・照合する条例・所見・確認が必要な件数を一覧 |
| 新しい調査を始める | ①対象地（所在・地番・面積、地図でピンを動かして番地に合わせる）②目的と条件（自由記入）③資料を共有 → 「レポートを作成する」 |
| レポート | 左＝目次、中央＝紙面（直接編集可）、右＝確認／判断／出典／資料。PDF出力・Word保存 |
| 法令・条例 | 国の法令と地域の条例の登録内容。条文の原文引用・出典URL・確認日つき |
| 設定 | 調査機関の情報、資料読み取り（AI）の接続 |

## レポートの中身

章立てと紙面の体裁は、既往報告書8通（Drive「エコテック地歴調査報告書」）に合わせています。

- 表紙、目次（点線とページ番号、【添付資料】の表）
- 1 調査概要（1.1〜1.7）
- 2 履歴調査（2.1 地形・地質・地下水／2.2 登記簿：土地・地番の変遷図・建物・法人／2.3 地図・空中写真／2.4 ヒアリング・現地踏査・公的機関の環境情報）
- 3 結果まとめ（所見）
- 所見が「否定できない」のとき：4 試料採取等対象物質の選定（表4 指定基準つき）／5 汚染のおそれの由来に応じた区分／6 土壌汚染のおそれの区分の分類
- 付録（原本にない、本システムの部分）：適用条項の判定（法3条・4条・5条・14条・6/11条と、地域の条例の各条が該当するか）／対象物質の選定根拠／出典一覧
- 添付資料の扉

紙面の体裁（原本の実測に合わせたもの）

- A4のページ単位。余白は上17mm・左30mm・右20mm、本文はゴシック10.5pt、表は8pt。右下にページ番号、ページ下に脚注（「添付資料(一般)A「登記簿謄本」を参照。」の書き方）
- 見出しは太字にせず字下げで階層を示す。1.1 の表、筆の一覧（合計欄の斜線）、登記簿の表（地積の結合、分筆行の横結合、現状地番の切り替え）、2.3 の年次表、所見の枠、表4（調査対象物質の○、含有量基準なしの斜線）を原本の罫線で組む
- 1ページに収まらない内容は、表や段落の切れ目で次のページへ送り、ページ番号と目次を振り直す（`paginate`）。「PDFで出力」は画面と同じページ割りで出る
- 書体は BIZ UDゴシック（Webフォント）を先頭に、MS ゴシックを次に指定。Word保存は MS ゴシック指定

見出しや脚注の横に「原本 p.7」「p.22–85」のような小さな札が付きます（画面のみ。印刷・Wordには出ません）。原本PDFを「資料」タブに入れると、札を押してそのページを表示できます。

## 人が見るのは「確認」だけ

右の「確認」には、次のものだけを出します。

- 判読が不明瞭な名義人、筆によって食い違う日付
- 資料どうしの矛盾（例：ヒアリングと地図・登記が合わない）
- 原本との差（誤記と判断して直した箇所、古い法令の引用）
- 未記入の項目（行政照会、条例の台帳確認、ヒアリング）
- 公式資料・社内実績の登録がなく、物質を自動で選べなかった業種

「判断」では、懸念として扱う利用履歴・対象物質・筆ごとの区分・条例の確認結果を切り替えると、所見と4〜6章を組み直します。

## 出典の扱い

- 法令・条例は **公式サイトで条文を確認できたものだけ**「公式出典で確認」と表示します（e-Gov法令検索、環境省、自治体の例規集・公式ページ）。確認できていない条項は判定表に「出典未確認」と出ます。
- 調査結果の原本は `registry/research/*.json`（URL・ページ題名・確認日・原文引用つき）。`tools/make_registry.py` がアプリ用の `registry/{laws,ordinances,industry}.json` に変換し、`build.py` が `index.html` に埋め込みます。
- 業種→特定有害物質は2種類の根拠を区別します：**社内実績**（既往報告書での選定）と **環境省の公表統計**（「土壌汚染対策法の施行状況及び土壌汚染調査・対策事例等に関する調査結果」表3-3・表3-13）。どちらも無い業種は自動選定しません。

## 資料の読み取り（AI）

資料1点ごとに Claude API を呼び、「案件データの部分」を同じJSON形で返させて結合します（`src/ai.js`）。各行にページ番号を付けさせ、判読に自信がない名義人は `unclear` で返させます。

接続は2通りです。

1. **サーバー経由**（本番向け）：`netlify/functions/claude.mjs` が中継。APIキーは Netlify の環境変数 `ANTHROPIC_API_KEY`。利用者の画面にキーは出ません。
2. **設定画面でキーを登録**（試用向け）：ブラウザから直接呼びます。

未接続でも、サンプル4件の表示、章立ての作成、法令・条例の判定、地下水流向の推定（標高）は動きます。

## 開発

```
python3 tools/make_registry.py   # registry/research → registry/*.json
python3 build.py                 # src/ + registry/ → index.html
```

- `src/data.js` 26物質と指定基準、業種→物質、目的
- `src/samples.js` サンプル4件（葛飾区金町・川崎市貝塚・東住吉区駒川・渋谷区西原）
- `src/engine.js` 適用条項の判定、懸念の抽出、所見、確認項目、出典一覧
- `src/report.js` 紙面の描画
- `src/ai.js` 読み取り・結合・地下水流向の推定
- `src/demo.js` デモの台本と入力例
- `src/ui.js` 画面
- `tests/` 再現テスト（`node tests/demo.js index.html`、`node tests/review-regression.js index.html`）、紙面の確認（`node tests/paper.js index.html s-kanamachi <出力先>`：各ページの画像と印刷用PDFを出し、はみ出しとページ数を表示）
- `screening.html` 以前の地図・年代別空中写真・CSV取込の試作（単体で動作）

## 未対応・制約

- AI読み取りは、この環境にAPIキーが無く実PDFでは未実走です。結合〜所見の組み立ては模擬データで確認済み。
- 地下水流向は標高からの方向推定のみ。到達距離の計算（物質・地層・透水係数）は、計算ツールの資料を受領後に組み込みます。
- 地番図（図1.7-2）と区分図（図6.3.x）は公図が元のため差し込み枠のみ。位置図は地理院地図（原本はゼンリン地図）、図2.1 は治水地形分類図のみで凡例は付けていません。表紙のロゴは未掲載。
- 行の結合がある表（登記簿）が1ページを超える場合は、表の途中では分けず、そのページが長くなります。
- Netlify Functions は要求本文6MBまで。大きなスキャンPDFは、Files API を使うサーバー構成に変える必要があります。
- 認証・案件の保存はブラウザ内のみ（基幹システム連携は案件JSONの入出力を足場にする想定）。
