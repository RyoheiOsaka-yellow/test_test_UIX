# XANTALOS ロゴ

YELLOW ロゴと同じ組み（**Raleway Light 300 / 字間 .42em**）で、文字ではなく
図形（アウトライン）に変換したものです。フォントが入っていない環境でも同じ形で出ます。
生成は `Raleway-Light`（Google Fonts の静的 TTF）から opentype.js でアウトラインを取り、
YELLOW ロゴと同じ座標系（大文字の高さ 710 / 字送り = 字幅 + 420）で並べています。

## ファイル

| ファイル | 用途 |
|---|---|
| `XANTALOS_logo.svg` | **推奨。** 色は使う側で指定（`currentColor`）。どんな大きさでも劣化しません |
| `XANTALOS_logo_white.svg` / `_black.svg` | 色が固定されたSVG |
| `XANTALOS_logo_black_16000w.png` ほか | 背景透過PNG（黒）。16000 / 12000 / 8000 / 4000 / 2000 / 1000px幅 |
| `XANTALOS_logo_white_8000w.png` ほか | 背景透過PNG（白）。8000 / 4000 / 2000 / 1000px幅 |

比率は **11.36 : 1**（横 : 縦）。余白なしの断ち落としなので、置くときに周囲を空けてください。

## 余白の目安

ロゴの高さ（文字の高さ）の **0.5倍以上**を上下左右に空けると、YELLOW ロゴと揃います。
YELLOW と並べるときは、文字の高さを同じにすると字間・太さが揃います（横幅は XANTALOS の方が約 1.3 倍長くなります）。

## 印刷で使うとき

- SVG をそのまま入稿してください（Illustrator でそのまま開けます）
- PNG しか使えない場合の原寸目安（@300dpi）: 8000px幅 = 約68cm / 12000px幅 = 約102cm / 16000px幅 = 約135cm
- 白版は背景が濃い色のときだけ。薄い背景には黒版を使ってください
