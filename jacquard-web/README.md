Jacquard (Web)
==============

[keijiro/Jacquard](https://github.com/keijiro/Jacquard) — Unity 6.5 製のグリッドシーケンサ
— を、依存パッケージなしの Web アプリとして再現したものです。譜面モデル・シリアライズ・
シーケンサ・ライブエフェクト・2 オペレータ FM 音源・センドエフェクト・リミッターまで、
`Assets/Core` と `Assets/Jacquard/Audio` の振る舞いをそのまま移植しています。

動かす
------

ES モジュールと AudioWorklet を使うため、`file://` ではなく HTTP で開く必要があります。

```
node serve.mjs        # http://localhost:8080
```

ブラウザで開き、**Play** を押すと `scores/startup.js` の譜面（オリジナルの
`Assets/Jacquard/Scores/Startup.jacquard.txt` と同一）が鳴ります。音は最初のクリックで
AudioContext が開いてから出ます。

セルフテスト
------------

オリジナルの *Jacquard > Run Self Test* に対応する検査を Node で走らせます。ファイル
形式のラウンドトリップ、ゲート／ロック／ジャンプ／ミュートの振る舞い、ライブエフェクトの
12 種、オシレータとリバーブ・ディレイ・リミッターの実測まで、同じ項目を同じ判定値で
確認します。

```
node tests/selftest.mjs
```

操作
----

| 操作 | 意味 |
| --- | --- |
| クリック | カーソル移動。パネルはカーソルが乗っているセルを表示する |
| ダブルクリック | ノートを置く（置けるセルのみ） |
| タイルをドラッグ | タイルを運ぶ。別ステップへ運ぶと下にぶら下がるタイルも一緒に動く |
| 先頭セルをドラッグ | レーンごと運ぶ。`CHAN` の縦位置が Runner の実行順を決める |
| 何もないところをドラッグ | 平面をパンする |
| ホイール / トラックパッド | 2 軸スクロール |
| 矢印 | カーソル移動 |
| Shift + ↑ / ↓ | 半音移調（Cmd/Ctrl 併用でオクターブ） |
| Delete / Backspace | タイル削除。先頭セルならレーン削除 |
| Space | 再生 / 停止 |

数値はすべてバーで、ドラッグでスクラブ、ダブルクリックで直接入力します。ロックパネルでは
バーを動かせばそのパラメータを掴んだことになり、名前をタップすると手を放します。

Live FX の 12 ボタンは押している間だけ効きます（Reverb / Delay / Stab / Sustain /
オクターブ上下 / Rise / Fall / 4 種のロール）。ロールだけは重ならず、最後に押したものが
譜面の代わりに鳴ります。

保存は `localStorage`（**Save** / **Load**）と、オリジナルと同じテキスト形式のファイル
書き出し・読み込み（**Export** / **Import**）です。

構成
----

| | |
| --- | --- |
| `src/core` | 譜面モデル、タイル、テキスト形式、シーケンサ、ライブエフェクト、パッチとロック対象 |
| `src/audio` | FM ボイスと 3 つのバス（`dsp.js`）、それを回す AudioWorklet、アプリ側のハンドル |
| `src/ui` | 平面の描画、セルのアイコン、パネル、編集操作 |
| `scores` | 起動時に開く譜面 |
| `tests` | セルフテスト |

`src/core` と `src/audio/dsp.js` はブラウザ API に一切触れません。オリジナルで
`Assets/Core` の asmdef が `noEngineReferences` によって強制していた分離を、そのまま
保っています（だから同じコードが Node のセルフテストでも動きます）。

オリジナルとの違い
------------------

- **出力ドライバ**。オリジナルはネイティブでは Scriptable Audio Pipeline、Web では
  `Update` からブロックを描画して Web Audio へ押し込む方式で、後者は約 110ms の遅延を
  伴います。こちらは AudioWorklet なので、性格としては前者に近く、レンダー量子と
  メッセージの往復ぶん（20ms）だけを `minimumLead` として見込んでいます。シーケンサの
  先読み 120ms、ハンドオーバー 30ms はオリジナルのままです。
- **UI Toolkit ではなく DOM**。セルのピッチ（30x32、間隔 4px）、アイコンの 15x15
  ビューボックス、レールの点線、ジャンプ線の 7.5px オフセットは `mockup.html` と
  `Style.cs` の値をそのまま使っています。
- **保存先**。`Application.persistentDataPath` の代わりに `localStorage` とファイル
  ダウンロードです。形式は同じ `jacquard 11` で、オリジナルの譜面をそのまま読めます。
- **DSP の三角関数**。Burst 対策の `FastMath` は要らないので、標準の `Math.sin` /
  `Math.exp` を使っています（精度は上がる方向で、波形の定義は同じです）。
- **ビジュアライザ**。URP のメッシュではなく Canvas ですが、描いているものは同じ
  ——出力のトリガ付きトレースと、ボイスプールのレベルです。
