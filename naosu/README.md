# ナオス 修繕リレー（プロトタイプ）

スマホ向けの修繕報告・差配プロトタイプです。`index.html` をブラウザで開くだけで動きます（ビルド不要）。

- 写真2枚（全体・アップ）で報告 → 優先度判定 → 近くの対応者または管理へ差配
- 完了写真1枚で完了、管理・営業・オーナーへ自動共有（Before / After）
- 管理 ⇄ 営業チャット、オーナーの声 → 案件化
- 完了・対応不要はボタンで記録、別途対応が必要な場合は専用ページで依頼
- 位置情報が取れれば自動、取れない場合は住所または物件名を入力

撮影は実カメラを使わず、シャッターを押すと決まったダミー写真（描画）が入ります。データは再読み込みで初期化されます。
