# BBB 修繕リレー（プロトタイプ）

スマホ向けの修繕報告・差配プロトタイプです。`index.html` をブラウザで開くだけで動きます（ビルド不要）。

- 写真2枚（全体・アップ）で報告 → 優先度判定 → 近くの対応者または管理へ差配
- 完了写真1枚で完了、管理・営業・オーナーへ自動共有（Before / After）
- 役割別ホーム（現地スタッフ／管理／営業／オーナー）、滞留の表示、到着で自動的に「対応中」へ
- 近くで手の空いている人へのオファー（送る側）と、依頼の受諾・見送り（受ける側、30秒カウントダウン）
- 管理 ⇄ 営業チャット、オーナーの声 → 案件化
- 完了・対応不要はボタンで記録、別途対応が必要な場合は専用ページで依頼
- 位置情報が取れれば自動、取れない場合は住所または物件名を入力

撮影は実際のカメラを起動します（映像を表示できる環境ではその場でプレビュー、できない環境ではシャッターで端末のカメラが開きます）。撮った写真は画面表示にだけ使い、判定内容は固定のサンプルシナリオです。「サンプル写真で進める」でカメラなしでも進められます。データは再読み込みで初期化されます。
