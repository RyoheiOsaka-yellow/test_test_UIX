# Virtual Studio — 仮想撮影スタジオ / 撮影指示書ジェネレーター

オンライン上の「仮想撮影スタジオ」で、動画・スチール・屋外/ドローン撮影の
**技法・機材・ライティング・カット割り**を設計し、**撮影指示書 (PDF/画像) と
Seedance 等の AI 動画生成向け詳細プロンプト**を自動生成するプロトタイプです。

ビルド不要・依存ライブラリなし。`index.html` をブラウザで開くだけで動作します。

```bash
# ローカルで開く
open virtual-studio/index.html          # macOS
# または任意の静的サーバー
cd virtual-studio && python3 -m http.server 8080
```

## できること (プロトタイプ v0.2)

### 1. 仮想スタジオ (俯瞰配置図・白基調UI)
- ライト (キー/フィル/バック/リム/トップ/背景/HMI/プラクティカル)、レフ板、
  フラッグ、ディフューザー、ドローン、太陽などを**ドラッグで自由配置**
- **特効機材**: 送風機 / スモーク / レインマシン / スノーマシン /
  紙吹雪キャノン / 爆発ポイント / スパークマシン
- **車両・ロジスティクス**: 機材車 / 発電車 / ロケバス / クレーン車 /
  モニター(ビデオビレッジ) / 音声(ブームポジション)
- グリッドは 1マス = 50cm。各機材に高さ・出力・色温度・モディファイア
  (ソフトボックス、グリッド、パラボリック、ライトテント等25種) を設定可能

### 2. 撮影技法プリセットライブラリ (約50種)
選ぶだけで機材が自動配置され、想定カットが生成されます。

- **人物ライティング (基本)**: 三点照明 / ループ / レンブラント / バタフライ /
  スプリット / ブロード / ショート
- **人物ライティング (応用)**: クラムシェル / 逆光シルエット / ハイキー /
  ローキー(ノワール) / アンダーライト(ホラー) / インタビュー(窓光風)
- **シーン再現 (動画)**: デイ窓光 / ムーンライト / キャンドル / モニター光 /
  尋問トップ単灯 / ステージライブ / ネオンデュオトーン / 回想ハレーション /
  グリーンバック(クロマキー)
- **商品・テーブル動画**: ターンテーブル / 料理真俯瞰 / 手元・開封動画
- **人物スチール**: 白ホリ全身ファッション / カラージェルポートレート /
  ハードライト単灯 / サンドイッチリム
- **商品撮影**: グラデーション / 透過光 / シズル(雫・スプラッシュ) / EC白抜き /
  コスメ / 香水ジェル背景 / ビール / フード半逆光 / フラットレイ / 自動車
- **特殊素材**: ガラスのブライトフィールド/ダークフィールド / ジュエリー /
  金属テント / ガジェットのスペキュラー制御
- **屋外撮影**: ゴールデンアワー / ブルーアワー / 真昼シルク / 日中逆光+HMI /
  曇天 / ナイトネオン / ロケ基地レイアウト(機材車・ベース設営)
- **ドローン基本**: オービット / リビール / 真俯瞰 / 並走 / プルバック / ドローニー
- **ドローン応用**: FPV追跡 / ダイブ / スパイラル上昇 / ローパス / 空撮ドリーズーム
- **特殊効果 (SFX)**: 雨(レインメイキング) / 風(ストームウィンド) / 雪 /
  爆発(パイロ) / 火花(スパークシャワー) / 紙吹雪 / スモーク光条

### 3. 想定カットの自動生成 + かんたん解説
配置したライトの**方位・出力・色温度・モディファイア**を解析し、
カットサイズ・アングルを反映した想定フレームを自動描画します。
併せて**「この配置だとこう写る」を誰でも分かる言葉で自動解説**します
(光の方向 → 影の出方 / 柔らかい・硬い / 輪郭光 / 背景の明るさ / 色味 / カメラの効果)。
「**雫 / 光沢 / 湯気 / ヘイズ / 風 / 雨 / 雪 / 爆発 / 火花 / 紙吹雪 / シルエット**」等の
演出・特効オプションはプレビューと指示書・プロンプトすべてに反映されます。

### 4. カット割り (ストーリーボード)
複数カットを追加・複製・並べて、作品全体のカット割りとして管理できます。

### 5. 書き出し
| 出力 | 内容 |
|---|---|
| **撮影指示書 (PDF/印刷)** | カット毎に配置図・想定カット・機材表 (方位/距離/高さ/出力/色温度/モディファイア)・カメラ設定・演出上の注意・技法メモ・AIプロンプトを網羅 |
| **Seedance プロンプト** | カットサイズ / アングル / カメラワーク / レンズ / ライティング解析結果を英語の詳細プロンプトに自動変換 (ワンクリックコピー) |
| **配置図 SVG** | 俯瞰図を画像として保存 |
| **JSON** | プロジェクトの保存・読み込み |

## 設計

```
virtual-studio/
├── index.html        # UI レイアウト
├── css/style.css
├── js/
│   ├── data.js       # ★ 撮影技法ナレッジベース (プリセット/機材/技法定義)
│   └── app.js        # 配置図・ライティング解析・プレビュー・書き出し
└── docs/knowledge/   # 撮影技法 md ナレッジ (取り込み形式の仕様あり)
```

**`js/data.js` がプロダクトの知識の中核**です。プリセットは
「配置座標 + 高さ + 出力 + 色温度 + モディファイア」の構造化データで、
UI・プレビュー・指示書・プロンプトのすべてがここから生成されます。

### ライティング解析の仕組み
カメラ→被写体の軸を基準に各灯の相対方位角を計算し、
- 正面〜斜め前 (|θ| ≤ 115°) → キー/フィルとして陰影の方向・コントラストに反映
- 半逆光〜真後ろ (|θ| > 115°) → リムライトとして輪郭光に反映
- 色温度の加重平均 → 画とプロンプトのカラーパレットに反映

という形で、配置図とカットイメージ・プロンプトが常に同期します。

## 撮影技法 md の取り込みについて

技法ナレッジを md で共有いただく前提で、`docs/knowledge/FORMAT.md` に
取り込み用のフロントマター形式を定義してあります。この形式に沿った md は
`data.js` のプリセットへ機械的に変換できます (サンプル: `docs/knowledge/sample-rembrandt.md`)。
