# LiDAR × BIM 都市高速 点群シミュレーション

実在の都市高速ジャンクション（OpenStreetMap の実線形）を **LiDAR 風の点群** として合成し、
**BIM / Revit 的な表現**（IFC 分類された構造要素、レベル、通り芯、断面ボックス、4D 施工順序、
Scan-to-BIM 偏差ヒートマップ、Revit 風プロパティ）を重ねて見るブラウザ 3D シミュレーションです。

- 対象地: 首都高速 **箱崎JCT**（6号向島線・7号小松川線・9号深川線・C1）、**大橋JCT**（3号渋谷線・C2）
- 技術: Three.js（WebGL2）＋ 自作 GLSL 点群シェーダ ＋ Eye-Dome Lighting、Web Worker で点群合成
- 点数: 標準 約 600 万点（密度 0.4）、最高 約 1,500 万点（密度 1.0）
- ビルド不要。静的ファイルのみ（Three.js は CDN の importmap）

## 起動

```bash
cd pointcloud-highway
python3 -m http.server 8080      # または npx serve .
# http://localhost:8080/ を開く
```

`file://` では Worker / fetch が動かないため、必ず HTTP で配信してください。

## 構成

```
pointcloud-highway/
├── index.html            UI（左: 表示/レイヤー/4D/カメラ、右: Revit 風プロパティ、左下: 凡例）
├── data/
│   ├── hakozaki.json     OSM 由来の道路線形（高さ推定済み）・建物・水面・公園
│   └── ohashi.json
├── tools/
│   ├── sites.json        対象地の中心座標・bbox・レイヤー高さ・走行ルート
│   └── build_data.mjs    OSM XML → data/<site>.json 変換（高さソルバ内蔵）
└── src/
    ├── geom.js           Catmull-Rom 再サンプル、フレーム付きパス、ポリゴン、ラスタマスク
    ├── structure.js      ★ パラメトリック構造モデル（床版・主桁・壁高欄・橋脚・横梁・基礎・照明柱・門型標識柱・建物）
    ├── synth.js          ★ LiDAR 点群合成（反射強度・分類・偏差・要素 ID を各点に付与）
    ├── synth.worker.js   Worker ラッパ
    ├── bim.js            構造モデル → BIM メッシュ（面 + エッジ、要素 ID → 面範囲）
    ├── shaders.js        点群シェーダ（6 着色モード・選択強調・分類マスク・クリッピング）、BIM 面/線シェーダ
    ├── edl.js            Eye-Dome Lighting ポストプロセス
    ├── colormaps.js      viridis / magma / inferno / plasma / turbo / 偏差 / 分類 LUT
    ├── annotations.js    レベル（▽ Deck L2 +11.200）、通り芯バブル（P-012）、断面ボックス
    ├── camera.js         走行ルート連結、ランプ走行 / フライオーバー / ビュー遷移
    ├── measure.js        2 点計測（Revit 風寸法線、mm 表示）
    └── main.js           アプリ本体
```

`structure.js` が **点群と BIM の両方の唯一の真実源** です。点群は各構造要素の表面からサンプリングされ、
各点が要素 ID を持つため、「点群をクリック → BIM 要素を選択」「要素ごとの点数・偏差・被覆率」が成立します。

## データパイプライン（実在線形）

```bash
node tools/build_data.mjs hakozaki            # OSM map API から bbox を取得して変換
node tools/build_data.mjs hakozaki map.xml    # 取得済み XML から変換
```

1. OSM の `highway=motorway|motorway_link|...` を抽出（トンネルは除外）
2. 18 m 以下に細分化し、`layer` / `bridge` タグから目標高さ（layer × 5.6 m）を設定
3. **高さソルバ**: 一般道ノードを 0 m に固定し、縦断勾配 5.5 % 以下の制約を反復投影。
   本線は重く、ランプは軽く動くため、ランプが高低差を吸収して自然なアプローチになる
4. 建物は `height` / `building:levels` があればそれを、無ければ面積に応じた推定高さ

> 高さは OSM の layer からの推定であり実測ではありません。実測点群（LAS/LAZ）や
> 道路台帳・橋梁台帳の縦断データに差し替えれば、そのまま実スキャンの可視化基盤になります。

## 点群合成（LiDAR らしさの作り方）

| 対象 | 再現している特徴 |
| --- | --- |
| 舗装 | 低反射（I≈0.1）、車線の轍で僅かに暗い帯、区画線は高反射（I≈0.9）で破線パターン |
| 壁高欄 | 両面＋天端。天端を高反射にして参考画像の「黄色く光る縁」を再現 |
| 主桁・橋脚・横梁 | 箱桁の側面/下面、円柱/小判形橋脚、横梁。基礎は地中なので **点群なし**（BIM のみ） |
| 建物 | 床スラブ帯・方立（2.6–4.6 m モジュール）・ガラス（疎）・基壇・店舗看板帯・バルコニー（低層住宅系）・屋上パラペット・屋上設備／階段室／高置水槽・内部床スラブの透け |
| 街路 | 歩道・縁石・ガードレール（高反射）・横断歩道・停止線・信号機・街灯、裏通りの電柱＋架空線（カテナリー）＋変圧器・路上駐車・空地の駐車場 |
| 高架 | 高欄上のフェンス（支柱 2 m ピッチ・笠木）、排水側溝、伸縮装置（40 m）、進行方向矢印（80 m）、床版張出し下面 |
| 車両 | 車線上の箱、窓部は返りが少ない。トラック 18 % |
| 植生 | 公園内の樹木、幹線道路の街路樹（球殻状の点分布） |
| 水面 | 返りがほとんど無い（≈0.03 pt/m²）ため黒く抜ける |
| ノイズ | 測距ノイズ σ≈12 mm、0.25 % の浮遊点（マルチパス・鳥） |
| 偏差 | 一部要素に施工誤差を注入（橋脚の傾き、壁高欄の孕み、桁の沈下）→ Scan-to-BIM モードで赤く出る |

## BIM / Revit 的表現

- **IFC 分類**: IfcSlab / IfcBeam / IfcRailing / IfcColumn / IfcFooting / IfcMember / IfcBuilding
- **Revit 風プロパティ**: 識別情報（要素 ID・マーク・カテゴリ・ファミリ・タイプ）／拘束（レベル・路線・フェーズ）／寸法・体積／材料／点群照合（点数・平均偏差・最大偏差・被覆率・健全度 A–D）
- **レベル** `▽ Deck L1–L5` と **通り芯バブル**（橋脚 P-001…）
- **断面ボックス**（6 面クリッピング、点群と BIM に同時適用）
- **4D**: 基礎 → 橋脚 → 横梁 → 主桁 → 床版 → 高欄 → 付属物 の順に出現（点群も連動）
- **計測**: 点群上 2 点間を mm で表示（水平距離・高低差付き）
- **表示スタイル**: ワイヤーフレーム／半透明シェーディング／カテゴリ色（Revit の「カテゴリで色上書き」）

## 操作

| 操作 | 内容 |
| --- | --- |
| ドラッグ / ホイール / 右ドラッグ | 回転 / ズーム / パン |
| クリック | 点群または BIM 要素を選択（右パネルにプロパティ） |
| 計測ボタン → 2 点クリック | 距離計測。Esc で解除 |
| ランプ走行 | 首都高本線を連結した約 2.5 km を車載視点で走行 |
| 凡例の分類をクリック | 分類ごとの表示／非表示 |

## 単体 HTML（ダウンロード配布用）

```bash
node tools/build_single.mjs   # → dist/lidar-bim-highway.html（約 1.6 MB）
```

全モジュール・両対象地のデータ・Worker を 1 ファイルに埋め込んであり、ダブルクリック（`file://`）で開けます。
Three.js のみ CDN から読むため、インターネット接続は必要です。
