# ATOMIX 加須工場 デジタルツイン

塗料工場（埼玉県加須市）の設備移設を、**3Dビューア**と**分析基盤**を連動させて検討するためのプロジェクトです。
このファイルは作業のたびに更新します（最終更新: 2026-11-25 / 第4回）。

## 確認方法

`dist/index.html` をブラウザで開きます（Three.js をCDNから読むためネット接続が必要）。

1. **工場全体** … 起動直後は敷地全景。右の「分析基盤」に工場全体の生産実績が出ます。
2. **工場内部** … 建屋をダブルクリック、または分析基盤のライン行をクリック。
3. **分析基盤との連動** … 設備をクリックすると台帳・稼働実績・その設備を通る動線に切り替わります。「移動モード」で設備を動かすと距離が再計算されます。
4. **レイアウト比較** … 第二ペイント工場の内部で、分析基盤の「内部の配置」を 初期イメージ／図面 現状／図面 変更案 に切替。図面配置では「差分を3Dに重ねる」で追加（緑）・撤去（橙）を表示。「写真調の質感」で見た目も切替できます。

## 構成

```
factory-twin/
  dist/index.html            確認用の単一HTML（tools/build.py の出力）
  src/index.template.html    HTMLの骨組み・CSS
  src/js/main.js             従来3D（FLOW·LAB 3D v4.1）本体
  src/js/layouts.js          図面ベースの実配置（第二ペイント 現状／変更案）
  src/js/twin.js             分析基盤パネル（3D連動・グラフ・建屋間移動の分析）
  src/js/movers.js           稼働再生（人とフォークリフトの動き）・手前の壁/トラスの自動非表示
  src/js/shapes.js           設備形状（現地写真ベース）
  src/js/pd.js, sim.js       実測動線ダッシュボード / 実測再生（FLOW LAB 5.0・6.0）
  src/data/analytics.json    分析基盤の集計（パイプラインが生成）
  src/data/pdData.json 他    位置トラッキング・現地写真（元HTMLから分離）
  pipeline/build_analytics.py  元Excel → 正規化CSV → analytics.json
  data/processed/*.csv       正規化・匿名化済みテーブル
  data/raw/                  元資料（氏名を含むためGit管理外）
```

更新手順: `python3 pipeline/build_analytics.py` → `python3 tools/build.py`

## 第2回の変更（2026-11-25）

**前提の確定（共有コメント）**: 生産人員24名 = ワニス2・仕込み3・調合3・充填10・2B 3・調色3。ワニスと調色を第二工場へ移し2名削減する計画。フォークリフト担当2名は別枠（生産人員も必要に応じて運転）。D-108／T-101〜104 の行き先は未定。

- **稼働再生を実態ベースに作り直し**
  - 敷地: リフトは2台。リフト1＝原料・資材を倉庫→生産棟、リフト2＝製品を生産棟→出荷倉庫（塗料置き場）→トラックバース。空荷の回送も表示し、頭上に「何をどこへ」を出す。以前は搬送経路ごとに1台ずつ計14台が建屋中心間を往復していた。
  - 敷地の歩行者: 位置トラッキング実測の建屋間移動が多い上位12の組合せを、工程色で再現。
  - 内部: 作業者は工程人員の人数（第二ペイント現状3名、変更案はワニス2名・調色3名を加えた8名、第一ペイント16名）。工程順（仕込→分散→調合→充填）に設備間を歩き、設備前で作業時間ぶん止まる。以前は経路ごとに1人で第二ペイントに98人いた。
  - 内部のリフト: 搬入口→原料置場、製品仮置き→搬出口を巡回。
- **内部の質感**（現地写真に合わせた）: 緑塗装の床（摩耗・目地つき）、波板の外壁と青い腰壁、昼光の明るさ、縞鋼板色の架台と安全通路の黄線。手前の壁は視点に応じて自動で隠れ、設備名は近い設備だけ表示。
- **建屋間移動の分析**（分析基盤・全景）: 実測×人員24名で、移動時間は現状1,494分/日 → ワニス・調色を第二へ移すと1,770分/日（＋276分）。2名削減に必要な960分/日の原資にはならない。最大要因は調色⇄研究棟の往復（1人1日あたり約20往復）が遠くなること。
- **グラフ**: 月次の生産実績と計画、工程別の移動時間（現状／移設後）、ライン別月次出来高、設備別の使用バッチ。


## 第3回の変更（2026-11-25）

**確認できたこと**: 調色⇄研究棟の往復は資材を取りに行くため。フォークリフトの荷役記録・入出荷伝票は無い（リフトの便数・行き先は仮定のまま）。

- **設備形状を現地写真に寄せて作り直し**（第二ペイント工場。平面外形は図面、細部と高さは仮定）
  - 調合タンク: ステンレスの開放槽、脚・コーン底・排出バルブ、分割フタ（片側を開けた状態）、液面、塗料の垂れ。
  - ディスパー: 若草色の昇降ポスト＋旋回アーム＋モーター＋シャフトと羽根。架台上のものは最寄りのタンクへアームを向ける。床置きのものは可搬の缶釜つき。
  - 可搬タンク: キャスター付きのステンレス槽。
  - デジタル充填機: 計量台・ローラー・ノズル・操作盤・18L缶。
  - ステンレスに映り込みを追加。視点が屋根の高さに近いときはトラス・照明を、視点側の壁は自動で隠す。設備名は短縮表示（T-111 など）。
- **分析: 調色の資材置場の効果**（分析基盤・全景）

| 資材の置き方 | 移設後の移動時間 | 現状（1,494分/日）との差 |
|---|---|---|
| 今のまま研究棟へ取りに行く | 1,770分/日 | ＋276分 |
| 往復を半分に（まとめ取り） | 1,604分/日 | ＋110分 |
| 資材を移設先に置く（往復なし） | 1,438分/日 | −56分 |

  移設と同時に資材置場を調色の近くへ移せば移動時間は現状より減るが、2名削減に必要な960分/日には届かない。

- 出来高/人時は 1B 299kg、ワニス 177kg、2B 99kg。2Bは小ロット（平均747kg/バッチ）。
- 記録上の直接工数は就業時間の38〜45%。残りは記録外で、ここが動線・段取り改善の母数。
