# ATOMIX 加須工場 デジタルツイン

塗料工場（埼玉県加須市）の設備移設を、**3Dビューア**と**分析基盤**を連動させて検討するためのプロジェクトです。
このファイルは作業のたびに更新します（最終更新: 2026-11-25 / 第8回）。

**使い方・分析できること・足りないデータは [`MANUAL.md`](MANUAL.md) にまとめています。**このREADMEは変更の経緯です。

## 確認方法

`dist/index.html` をブラウザで開きます（Three.js をCDNから読むためネット接続が必要）。

1. **工場全体** … 起動直後は敷地全景。右の「分析基盤」に工場全体の生産実績が出ます。
2. **工場内部** … 建屋をダブルクリック、または分析基盤のライン行をクリック。
3. **分析基盤との連動** … 設備をクリックすると台帳・稼働実績・その設備を通る動線に切り替わります。「移動モード」で設備を動かすと距離が再計算されます。
4. **レイアウト比較** … 第二ペイント工場の内部で、分析基盤の「内部の配置」を 初期イメージ／図面 現状／図面 変更案 に切替。図面配置では「差分を3Dに重ねる」で追加（緑）・撤去（橙）を表示。「写真調の質感」で見た目も切替できます。

## 第6回の変更（2026-11-25）: 2名削減の原資の試算

分析基盤（全景）に「2名削減の原資（試算）」を追加。日報の日別出勤人数と、生産データの日別直接工数を工程ごとに突き合わせた。

**結論: 原資は移動時間ではなく、日ごとの仕事量のばらつきにある。工程をまたいで人を融通（兼務）できる範囲を広げるほど、2名削減が現実的になる。**

| 工程（単独で1名減） | 平均出勤 | 今の不足日 | −1名の不足日 |
|---|---|---|---|
| 1B仕込み・調合 | 5.8名 | 10% | 23% |
| 1B充填 | 5.0名 | 10% | 31% |
| 2B | 3.4名 | 10% | 45% |
| ワニス | 1.6名 | 11% | 19% |

| 工程をまとめて持つ（兼務） | 平均出勤 | −1名の不足日 | −2名の不足日 |
|---|---|---|---|
| 第二工場に集約（2B＋ワニス） | 5.0名 | 17% | 46% |
| 第一ペイント（仕込み・調合＋充填） | 10.9名 | 11% | 24% |
| 4工程すべて | 15.9名 | 2% | 4% |

- 不足日 = その日の直接工数を、各工程の繁忙日ペース（1人あたり直接工数の上位10%日）でこなしても人数が足りない日の割合。
- 忙しい日のペースで均せば、4工程で合計約3.2名分の余力がある。
- 2Bとワニスは忙しい日がほぼ重ならない（相関0.02）ので、第二工場への集約で融通が効く。2B単独で1名減は45%の日で不足するが、ワニスと合わせて1名減なら17%。
- 仕込み・調合と充填は連動する（相関0.60）ので、まとめる効果は小さめ。
- 同じ日に応援の出と受けが両方ある入れ替わりが218人日（1日あたり約1.5人）。ワニスは在籍2名のうち約1名がほぼ毎日ほかの工程へ出ており、兼務はすでに一部で行われている。

**前提と限界**
- 記録されている直接工数（就業時間の31〜76%）に、記録外の作業（段取り・搬送・洗浄など）が比例すると仮定している。
- 調色は日別の工数記録がないため未算入。
- 日報の在籍は合計22名（仕込み・調合6、充填6、2B 3、ワニス2、調色5）で、共有コメントの24名（充填10、調色3）と内訳が合わない。**要確認。**


## 第7回の変更（2026-11-25）: リフトと人の動きを滑らかに

**フィードバック**: リフトの動きに不自然な部分がある。人の動きもさらにスムーズに。

| 不自然さの原因 | 対応 |
|---|---|
| 区間の切り替わりで位置が飛ぶ | 前の終点から次の設備の手前までを連続した経路として引き直す |
| 格子状の経路をなぞるのでジグザグする | 見通せる区間は直線にまとめ、角は円弧でつなぐ |
| 一定速度で急に止まり、急に向きを変える | 発進・停止の加減速、旋回速度の上限、曲がるときの減速を追加 |
| リフトが走りながら急旋回する | 向きが大きく違うときは、その場で旋回してから発進 |
| 内部のリフトが人用の狭い通路を通る | リフト幅で通れる通路だけを使う（届かない所だけ人用通路で代替） |
| 敷地で約400mの遠回りをする経路があった | 経路格子を5mから2.5mに細かくし、建屋間の通路を通れるようにした。荷捌き点は4辺のうち実走距離が最短の側 |
| 人が設備の前で横を向いたまま止まる | 作業中は設備の方を向く。歩行時だけ上下動と体の揺れを付ける |

検査: 全移動体の位置を0.1秒刻みで追い、1コマの移動量が速度×時間を超える飛びがないことを確認（敷地16体、第二ペイントの初期イメージ4体・図面現状4体・図面変更案9体、第一ペイント17体で飛び0件）。
