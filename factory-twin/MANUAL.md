# 加須工場 デジタルツイン ご利用マニュアル

最終更新: 2026-11-25（第9回）
機能を追加・変更するたびに、このマニュアルも同時に更新します。

---

## 1. このツールについて

加須工場の設備移設（ワニス・調色を第二工場へ移し、生産人員を2名減らすご計画）を検討するためのツールです。
工場を3Dで再現し、ご提供いただいた生産・人員・設備・位置のデータと連動させています。
「工場全体 → 建屋の内部 → 設備1台」の順に掘り下げてご覧いただけます。

お渡しするファイルは2つです。中身は同じで、開いた直後の動きだけが違います。

| ファイル | 用途 |
|---|---|
| `index-demo.html`（自動説明版） | 開くと説明の開始画面が出ます。画面が自動で動きながら、機能と分析結果を順に説明します。初めてご覧になる方、会議での投影向けです |
| `index.html`（通常版） | そのまま自由に操作できます。上部の「▶ 自動説明」から同じ説明を始めることもできます |

## 2. 開き方

ファイルをブラウザ（Chrome または Edge を推奨）で開いてください。3D描画の部品をインターネットから読み込むため、ネット接続が必要です。
表示まで数秒かかります。20秒たっても表示されない場合は、接続をご確認のうえ再読み込みしてください。

## 3. 自動説明

開始画面で次のいずれかを選びます。

- **説明を開始（音声あり）**: 字幕に加えて、ブラウザの読み上げ機能で説明します（対応ブラウザのみ。声はお使いの端末の日本語音声です）。
- **説明を開始（音声なし・字幕のみ）**: 字幕だけで進みます。
- **説明を見ずに自分で操作する**

全18場面、約6分です（音声ありの場合は読み上げの速さによって前後します）。画面左下の説明カードで操作できます。

| ボタン | 動き |
|---|---|
| ◀ 前へ ／ 次へ ▶ | 場面を移動 |
| 一時停止 ／ 再開 | その場面で止める。止めている間は画面を自由に触れます |
| 🔊 音声 | 読み上げの入・切 |
| ✕ 終了 | 説明を終えて、通常の操作に戻る |

説明の流れ: 全景 → 人とリフトの動き → 工場全体の実績 → 2名削減の試算 → 移設による移動時間の変化 → 建屋内部 → 第二ペイント工場の3つの配置 → 設備の台帳と実績 → 変更案との比較 → 設備を動かして再計算 → 写真調の表示 → 実測の再生 → 実測ダッシュボード → 足りないデータ → まとめ。

## 4. 画面の見方

| 場所 | 内容 |
|---|---|
| 中央 | 3D表示（敷地の全景、または建屋の内部） |
| 右 | **分析基盤**。いま見ている対象に合わせて内容が変わります。上部の「分析基盤」ボタンで開閉 |
| 左 | 設備ワークスペース（外観・空間・接続と動線・設備台帳・設備詳細・配置検証） |
| 上 | 視点の切替、移動モード、混雑表示、BIM表示、図面モード、画像保存など |
| 下中央 | 「▶ 稼働再生」（人とフォークリフトの動き） |

## 5. 基本の操作

| なさりたいこと | 操作 |
|---|---|
| 視点を回す／拡大する | ドラッグ／マウスホイール |
| 建屋の内部に入る | 建屋をダブルクリック。または分析基盤の「ライン別」の行をクリック |
| 敷地に戻る | 上部の「← 敷地へ戻る」 |
| 人とリフトを動かす | 「▶ 稼働再生」 |
| 設備の情報を見る | 設備をクリック。分析基盤がその設備の内容に切り替わります |
| 設備を動かしてみる | 「移動モード」を押してから設備をドラッグ。人が歩く距離をその場で計算し直します |
| 作業者の目線で歩く | 下の「作業者視点」。W・A・S・Dキーで移動、Escキーで戻る |

### 第二ペイント工場の配置の切替（分析基盤 →「内部の配置」）

| 切替 | 内容 |
|---|---|
| 初期イメージ（仮配置） | 検討用の仮の配置です |
| 図面 現状 | いただいた現状レイアウト図面どおりの設備位置です。設備番号で設備台帳・生産実績と連動します |
| 図面 変更案 | いただいた変更レイアウト図面どおりの配置です。ワニス生産エリアと調色エリアを含みます |
| 写真調の質感 | 現地写真に合わせた見た目（緑の床、明るい照明、ステンレスのタンクなど）に切り替えます |
| 差分を3Dに重ねる | 図面配置のとき、変更案で追加される設備を緑、図面から消える設備を橙で示します |

### そのほかの画面（分析基盤の一番下のボタン）

- **実測再生（位置トラッキング）**: 位置の実測を時刻どおりに再生します。「改善案」に切り替えると、移設先をドラッグして移動時間を試算できます。右上の「仮設備を編集」で3Dに戻ります。
- **実測動線ダッシュボード**: 実測の集計（エリアごとの滞在、エリア間の移動、移設の比較、人員計画）の一覧です。右上の「従来3Dを開く」で3Dに戻ります。

## 6. 分析できること

「確からしさ」は、実データだけで出しているか、仮定を含むかの目安です。

| お知りになりたいこと | 見る場所 | 使っている資料 | 確からしさ |
|---|---|---|---|
| 月ごとの生産・出荷・在庫の計画と実績 | 全景 → 月次 計画と実績 | 生産出荷在庫トン数・売上高 | 高（実績のまま） |
| ラインごとの生産性（バッチ数、出来高、1人1時間あたりの生産量、収率） | 全景 → ライン別 | 生産データ、日報 | 高 |
| 記録されている作業時間が就業時間に占める割合 | 全景 → ライン別 | 生産データ、日報 | 中（記録の入力状況によります） |
| 部門ごとの出勤・残業・応援の出入り | 全景 → 部門別の人員 | 日報 | 高 |
| **2名削減がどの条件なら成り立つか** | 全景 → 2名削減の原資（試算） | 日報と生産データ（日別） | 中（記録外の作業が比例すると仮定。調色は未算入） |
| **ワニス・調色を第二工場へ移すと移動時間がどう変わるか** | 全景 → 建屋間の移動と移設の影響 | トラッキングNaviの位置データ、人員数 | 中（計測は工程ごとに4〜7人日。距離は建屋の代表点間） |
| 調色の資材置場を移した場合の効果 | 全景 → 調色⇄研究棟を減らせた場合 | 同上 | 中 |
| 調色の補正回数と作業時間の関係 | 全景 → 調色 色補正 | 色補正回数（7日分） | 中（期間が短い） |
| ラインごとの月次推移 | 建屋内部 → 月次推移 | 生産データ | 高 |
| よく使われている設備 | 建屋内部 → 稼働の多い設備 | 生産データ | 高 |
| 設備1台の仕様・導入年・使用バッチ数・主な製品 | 第二ペイント（図面配置）で設備をクリック | 設備台帳、生産データ | 高（台帳と照合できていない設備が約3割） |
| 設備の間を人が1日に歩く距離（現状と変更案） | 第二ペイント内部 → 図面 現状と変更案の比較 | レイアウト図面、生産データ | 中（位置は図面、回数は実績。平面で評価） |
| 設備を動かした場合の距離の変化 | 移動モードで設備をドラッグ | 同上 | 中 |
| 変更案で行き先が分からない工程 | 第二ペイント内部 → 経路化できないフロー | レイアウト図面、生産データ | 高 |
| 実測の人の動き（時刻ごと） | 実測再生 | トラッキングNaviの位置データ | 高 |

### 現時点で分かっていること

1. **移設だけでは移動時間は減りません。** 建屋間を歩く時間は現状で1日1,494分、ワニス・調色を第二工場へ移すと1,770分になります。調色の方が研究棟へ資材を取りに行かれる往復が遠くなるためです。資材の置場も一緒に移せば、1,438分まで下がります。
2. **第二工場の中の設備の並べ方は、歩く距離にほとんど影響しません。** 現状は約337m/日、変更案は約332m/日です。
3. **2名削減の原資は、工程をまたいだ人の融通にあります。** 工程ごとに1名ずつ減らすと、忙しい日に人が足りなくなります（不足する日が19〜45%）。4つの工程で人を融通できれば、2名減らしても不足する日は4%です。
4. **2Bとワニスは忙しい日が重なりません。** 第二工場への集約は、人のやりくりの面で意味があります。

## 7. ご提供をお願いしたい資料

より確かな判断のために、次の資料・情報をいただけますと幸いです。優先度は、移設と2名削減のご判断にどれだけ効くかで付けています。
形式は問いません。手書きのメモや、図面への書き込みでも結構です。

### 優先度：高

| お願いしたいもの | ご担当と思われる部署 | 理由 | いただくとできること |
|---|---|---|---|
| 生産人員の内訳の確認 | 生産管理 | 日報の在籍は合計22名（仕込み・調合6、充填6、2B 3、ワニス2、調色5）ですが、伺った人員は24名（充填10、調色3）で、内訳が合っていません | 正しい人数で工程ごとの余力を出します |
| どなたがどの工程を担当できるかの一覧 | 製造の各職場 | 「工程をまたいで融通できれば2名削減が成り立つ」という試算が、実際に組めるかを確かめるためです | 現実的な兼務の範囲で試算し直します |
| 調色工場の日ごとの作業記録（製品・数量・作業時間） | 調色工場 | 生産データに調色のシートがなく、調色を人員の試算に入れられていません | 調色を含めた6工程で試算します |
| 調色の方が研究棟から取ってこられる資材の内容・量・保管の条件 | 調色工場、研究棟 | 資材の置場を第二工場へ移せるかどうかで、移設後の移動時間が大きく変わります | 移設後の移動時間を現実的に見積もります |
| D-108 と調合タンク T-101〜104 の移設後の置き場所 | 設備・生産技術 | 2Bで最も多く使われています（7か月で69バッチ）が、変更レイアウト図面では元の場所がワニス生産エリアになっています | 置き場所の候補を3Dで並べて比べます |

### 優先度：中

| お願いしたいもの | ご担当と思われる部署 | 理由 | いただくとできること |
|---|---|---|---|
| 変更レイアウト図面が確定版かどうか | 設備・生産技術 | 現在は「未確定」として扱っています | 確定案として評価します |
| 第一ペイント工場・ワニス工場・調色工場・倉庫のレイアウト図面 | 設備・生産技術 | これらの内部は仮の配置です。設備番号での連動は第二ペイント工場だけです | 全建屋で設備ごとの分析と動線の評価をします |
| 第二ペイント工場の搬入口・搬出口、原料・製品・空缶の置場の位置 | 第二ペイント工場 | 図面に記載がなく、仮に置いています | 人とリフトの動きを実際の位置で評価します |
| フォークリフトの運搬の実態（どこからどこへ、1日に何回くらい） | 物流 | 記録がないと伺っています。現在は行き先と回数を仮定しています。数日分のメモでも結構です | リフトの動線と、必要な台数・人数を検証します |
| 記録外の時間の内訳（段取り・運搬・待ち・洗浄など） | 製造の各職場 | 記録されている作業時間は就業時間の3〜8割です。残りの中身が分かりません | どの作業を減らせば何分浮くかを示します |
| 位置データの追加計測（可能であれば、生産データと同じ時期に） | 生産管理 | 現在は工程ごとに4〜7人日分です。また、生産データ（2025年9月〜2026年3月）と位置データ（2026年7〜8月）の時期が重なっていません | 移動時間の見積もりを安定させ、製品別の動線を分析します |

### 優先度：低

| お願いしたいもの | 理由 | いただくとできること |
|---|---|---|
| 設備の高さ・外形寸法、架台の高さ | 立体の形は仮定です | 高さ方向の干渉の確認 |
| 2Bの充填の標準時間 | 2Bには記録がありません | 1Bと同じ基準での比較 |
| 設備の停止・故障・洗浄切替の記録 | 設備の稼働率を出せていません | ボトルネック設備の特定 |
| 人件費・移設費用の概算 | 効果を金額で示せていません | 投資回収の試算 |

## 8. 数値をご覧になるときの注意

- **仮定を含むもの**: フォークリフトの行き先と回数、第二ペイント工場の搬入出口と周辺物（原料・製品・空缶・ラック・配管）、設備の高さ、図面をいただいていない建屋の内部。画面左下と分析基盤の注記に、仮定の範囲を記載しています。
- **人とリフトの動き**: 人数と工程の順番は実データに基づきますが、一人ひとりの経路とタイミングは説明用です。実際の動きは「実測再生」でご確認ください。
- **不足する日の割合**: 各工程の「忙しい日のペース」（1人あたり作業時間の上位10%の日）を基準にしています。基準を変えると数字は変わります。
- **資料の時期**: 生産データ・日報は2025年9月〜2026年3月、位置データは2026年7〜8月、色補正は2026年10月です。
- **個人名**: 取り込んでいません。担当者は番号（作業者01など）に置き換えています。

## 9. 現在の制約

- 人どうし、人とリフトのすれ違いは再現していません（重なって通ることがあります）。
- リフトは前進のみで、後退しての出し入れは再現していません。
- 第二ペイント工場の動線は平面で評価しており、架台の上り下りは距離に含めていません。
- 第二ペイント工場の図面配置では、設備が密集した部分で4〜5本の経路が「到達不可」と表示されます（通路幅の判定によるものです）。
- 実測再生の画面で「直接工数」の合計は表示されません（調色の作業記録がないため）。工程ごとの負荷は表示されます。
- 音声の読み上げは、ブラウザと端末の日本語音声に依存します。環境によっては声が出ない、または読み方が不自然な場合があります。その場合は字幕でご覧ください。
