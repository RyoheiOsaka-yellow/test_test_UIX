# VolaTrap Assembly Studio

VolaTrap（呼気 VOC サンプリングデバイス）を CATIA / 3DViewStation 風に **分解・断面・カラーコード・パラメトリック設計** できる単一 HTML のダッシュボードです。

- `index.html` をブラウザで開くだけで動作します（Three.js r128 を cdnjs から読み込み）。
- 3D モデルは画像ではなく、実寸 (mm) のプリミティブからパラメトリックに生成しています。
- 質量・体積・重心はメッシュ体積 × 材質密度から算出します（単位: mm / g / cm³）。

## 主な機能

| 領域 | 内容 |
| --- | --- |
| リボン「表示」 | 等角 / 六面ビュー、全体表示、ソリッド / ワイヤ / 透過 / イラスト、輪郭線、影、グリッド、座標系、LED、ペイン表示切替 |
| 分解バー（常設） | 再生 / 工程送り / 分解率、順次（手順順）・同時、トレース線、部品ラベル、組立位置ゴースト |
| リボン「分解」 | プリセット分解率、分解方式・方向、分解距離、分離表示、非表示 |
| リボン「解析」 | X/Y/Z 断面（反転・位置）、カラーコード（実材質 / Make-Buy / サブAssy / 材質分類 / 質量ヒート）、計測 |
| リボン「設計」 | パラメータ編集（ノズル角・マウスピース長・ボディ径・奥行・カップリング幅・ベース厚・LED 色相）、質量最適化、JSON / TSV 書き出し |
| 左ドック | 構造ツリー（27 品番 / 4 サブAssy、表示切替、検索）、保存ビュー（サムネイル付き）、選択セット |
| 右ドック | プロパティ（名称・材質・Make/Buy・色・不透明度・質量特性）、パラメータと目標値の判定 |
| 下ドック | 分解手順（工程・方向・工具、現在工程ハイライト、クリックで工程ジャンプ）、部品表 (BOM)、計測（質量・重心・2 部品間距離・干渉チェック結果）、出力ログ |
| 折りたたみ | 左右ドック → 細いストリップ、下ドック → タブ列のみ、リボン → タブのみ（クリックでポップオーバー）。状態は localStorage に保存。プレゼンモード (`P`) で全パネル非表示 + ターンテーブル |

## 操作

左ドラッグ: 回転 / 右・中ドラッグ: 平行移動 / ホイール: ズーム / クリック: 選択 / Ctrl+クリック: 追加選択 / ダブルクリック: フォーカス
キー: `Space` 分解再生, `←` `→` 工程送り, `F` 全体表示, `E` 分解トグル, `I` 等角, `S` 断面, `L` ラベル, `P` プレゼン, `Esc` 選択解除, `Ctrl+A` 全選択
