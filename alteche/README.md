# ALTECHE デモ（株式会社アルテック 仕様）

`anglex_demo`（トンネル照明器具 取付金具・落下防止材）の HTML を、**株式会社アルテック**（https://alteche.jp/）向けに作り替えた単一ファイルのデモです。

- 実体： `index.html` 1ファイル（外部依存は three.js / pdf.js / Google Fonts の CDN のみ）
- ブラウザで直接開けます。サーバ不要。

---

## 1. 何を変えたか

### ① 商材・語彙の入れ替え

トンネル照明器具の取付金具 → **商業施設・公共施設向けのオーダーメイド装飾金属**へ全面的に置き換えました。

| 旧（ANGLEX） | 新（ALTECHE） |
|---|---|
| 桂町TN / 桂台TN | モール棟（商業施設）／ホール棟（公共施設） |
| 照明器具（支給品） | 意匠ルーバー本体（AL押出 50×100 t2.0） |
| 取付金具① / ② | 取付ベースプレート（躯体側）／角度調整ブラケット（ルーバー側） |
| 金具A〜F | 取付ブラケット A〜F（ホール棟・6タイプ×左右） |
| 落下防止材 | 脱落防止ワイヤ（φ4 二重措置） |
| 塗装（マンセルN7） | フッ素焼付塗装（指定色）／SUS HL／バイブレーション／アルマイト |
| トンネル断面図 | 建物立面（スラブ・躯体下地・ルーバー割付・装飾手摺） |

### ② 配色

サイトのトーン（白・紺・グレー）に合わせ、アクセントをテラコッタ `#b34a2a` → 紺 `#1f4e79`、
用紙色を暖色系 → 寒色グレーへ再調整しました。

### ③ 【新規】現場管理モジュール（工程管理・図面共有）

ご指摘いただいた「製品販売だけでなく実際の工事業も行っているので、現場単位での工程管理・図面共有が刺さるのでは」という点を、
**デモの主役として新規に作り込みました**（`sm-view-sites` / `sm-view-site`）。

- **現場ダッシュボード** — 進行中の現場、遅延している工程、承認待ち・差戻しの図面、未回答の質疑を横断で集計
- **工程表（ガント）** — 現地調査 → 施工図 → 承認 → 材料手配 → 工場製作 → 表面処理 → 搬入 → 取付工事 → 検査 → 引渡。
  基準日（2026/08/18）を軸に、遅延／遅延リスクを色分け
- **図面共有** — 図面番号・Rev・状態（承認済／承認待ち／差戻し／作成中）・更新日・**既読者数**・滞留日数。
  その場で「承認する」「改訂を上げる」が動作します
- **質疑・是正（RFI）** — 宛先・期限・現場写真つき。期限超過を赤で強調。回答を記録すると関連図面に紐づきます
- **部材・製作進捗** — 部材ごとに（材料 → レーザー → 曲げ → 塗装 → 検品 → 搬入 → 取付）のどこで止まっているか
- **検査記録** — アンカー引抜き試験・出荷検査・是正など、引渡書類になる記録を現場単位で集約

デモデータは 3 現場（商業施設の内装改修／公共ホールの大規模改修／駅前広場のサイン・手摺新設）。

### ④ 既存機能との接続

新モジュールは既存の「図面 → 加工指示 → 概算見積 → 3D」エンジンと繋いであります。

- 図面共有の **「3Dで加工指示」** → その図面を加工指示モード（穴芯・曲げ・取付角度θの確定）で開く
- 部材・製作進捗の **「3Dで見る」** → その部材の 3D ディテールを直接開く
- 案件・見積カードの **「🏗 現場」** → 紐づく現場台帳へ移動
- 3D 画面右下の **「現場台帳」** ボタン → 現場一覧へ戻る

## 2. 画面の流れ

```
サインイン（ダミー認証・任意の入力でOK）
  └ 今日はどの入口から？
       ├ 🏗 現場管理（工程・図面共有）  ← 今回の追加。現場一覧 → 現場詳細（5タブ）
       ├ 💬 かんたん見積（チャット）    ← 会話で加工指示を埋めて概算 → 見積書発行
       └ 📐 図面から加工指示（3D）      ← 図面D&D → 解析 → 部材選択 → ディテール → 概算見積
```

## 4. 元の想定と公開情報の差異について（要確認）

いただいた説明は「商業施設・公共施設向けのオーダーメイド装飾金属の設計・製造〜取付工事の一貫請負」でしたが、
alteche.jp の公開情報では次のように読めます。

- 事業の主軸は **建築リニューアル工事（マンション・オフィスビルの大規模修繕、防水・塗装・外壁補修）**
- 1977年創業（旧・株式会社總合防水）、社名は "ALL TECHNIQUE" に由来、横浜市中区新山下、従業員 53 名、年間売上 38 億円
- 2009年に **鋼構造物工事業・板金工事業** を含む13業種の許可を追加取得、2015年に一級建築士事務所登録
- 特定建設業許可（神奈川県知事許可 特-4 第26255号）

「装飾金属の製造」を前面に出したページは見当たりませんでした。金物製作は 2009 年以降に広げた領域か、
あるいは別会社（装飾手摺メーカーの aluteck.co.jp など）と混同されている可能性があります。

今回はご指示の業容（意匠金物の設計・製作・取付の一貫請負）でデモを作っていますが、
**もし主軸が大規模修繕であれば、題材を「共用部の意匠金物・手摺改修」に寄せるより、
そのまま「大規模修繕の現場単位の工程管理・図面共有」に振り切った方が刺さります。**
現場管理モジュールの構造（工程・図面版管理・RFI・検査記録）はそのまま流用でき、
工程名とデモデータ（`SITES` 定数）を差し替えるだけで対応できます。

## 5. データの差し替え箇所

すべて `index.html` 内のインメモリ定数です。

| 内容 | 定数 |
|---|---|
| 現場・工程・図面・質疑・製作進捗・検査 | `SITES` |
| 案件と見積バージョン履歴 | `PROJECTS` |
| 部材（3D・積算の対象） | `MEMBERS` |
| 見積時確認①〜⑤の自動充填内容 | `SPEC_CAT` |
| チャットの選択肢（品目・現場・数量・仕上げ） | `PARTS` / `CHAT_TUNNELS` / `CHAT_QTYS` / `FINISH_OPTIONS` |
| 単価・歩掛り | `STEEL_UNIT` / `PROC` / `RATES` ほか |
| 基準日（ガントの「今日」線） | `TODAY` |

金額・数量・会社名（KTC建設、横浜都市デザイン設計 等）はすべて説明用のサンプルで、実在の案件ではありません。
