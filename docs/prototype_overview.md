# xAD 店頭販促シミュレーション プロトタイプ — 概要説明

**コンビニ・百貨店の店頭に販促商品を置いた際の消費者行動を3Dエージェントシミュレーションでモデリングし、
xAD販促ボード仕様のダッシュボードで計測・検証・最適化まで一気通貫でデモできるプロトタイプ。**

- 配布物: `index.html` 1ファイル（約800KB・Three.js同梱・完全オフライン動作）
- 起動: ブラウザ（Chrome/Edge推奨）でダブルクリックするだけ。サーバー・ネット接続不要
- リポジトリ: `RyoheiOsaka-yellow/test_test_UIX` ブランチ `claude/retail-consumer-behavior-sim-nlfkr9`（`retail-sim/`）

## 1. 3Dビュー（01〜03, 14）

- **施設切替**: コンビニ（新宿駅前店 16×10m・14売場）⇔ 百貨店（デパ地下フロア 30×18m・16売場）。売場構成・通路・客数・単価が切り替わる
- **消費者行動モデル**: 時間帯カーブ（通勤・昼・夕ピーク）×人流×広告リフトでポアソン到着 → 通路グラフ上を買い回り → レジ→退店
- **棚ごとの視線検知**: 視野（±45°・2.9m）と棚正面の交差を常時判定。通過→視線→立寄→手取→購買のファネルを棚別に集計。**棚をクリックすると売場詳細パネル**（ファネル・視線獲得率・累計視線時間・在庫）
- **ペルソナ5種**（体色で判別）: 通勤／主婦・主夫／学生／シニア／インバウンド。時間帯で構成が変化し、動線・滞在・選好・客単価が異なる
- **レジ待ち行列**: 物理的な行列形成、混雑検知でレジ自動増設、行列5人以上で約45%が離脱（機会損失を金額換算）
- **天候シグナル**: 猛暑35℃／晴れ26℃／雨22℃で来店率・カテゴリ需要・背景トーンが変化（02）
- **競合セールイベント**: 人流-15%＋防衛CPアクション発火
- **レイヤー**: 棚別視線ヒート／床の回遊ヒートマップ／視線コーン／動線トレイル／売場ラベル
- **店内サイネージ**（FamilyMartVision型）とノベルティ配布スタンド、AIダイナミックプライシング（トライアル型）をシナリオでON/OFF

## 2. 棚割シミュレーター（04, 05）

- 4段×8列の棚正面図。**クリックで配置変更**、スロット別視線ヒート、ゴールデンゾーン帯（床上85〜150cm）表示
- POP5種（プライスカード／スイングPOP／トップボード／床置き大型／AI生成POP）、フェイス数1〜4、**ベタ付け（おまけ添付35円/個）**、客動線の向き
- 出力: 棚前通過→視線→手取→購買ファネル、販売数±CI、対基準リフト、**増分粗利−コスト**（POP費・おまけ原価・フェイス機会コスト込み）、要因分解
- **最適配置を提案**: 全組合せ探索で差引利益最大の構成をワンクリック適用
- **3Dへ反映**: 選択構成が視線・転換係数として本体シミュレーションに接続

## 3. エリア・予算（06〜08）

- **ジオリフト実験設計（AREA MAP）**: 20エリアをクリックで処置/対照/除外に塗り分け。候補自動提案、近接ペアの汚染警告、
  **検出力プレビュー**（予算の期待リフト vs 検出可能な最小効果MDE→検出可否判定）、14日間の実験モニタリング（合成対照）、
  **較正係数をモデルへ反映**→ダッシュボードの広告増分・iROASのCIが校正される
- **予算配分シミュレーション（L3-1）**: 5媒体のレスポンスカーブ＋**限界iROAS均等化**の逐次配分ソルバー。現状vs推奨、通常（±30%）／攻めモード
- **店舗別γマップ（L2)**: 人流が広告効果を増幅する度合いγを店舗別に可視化。「広告を厚くすべき店舗／立地で完結」を判定

## 4. AI STUDIO（09）

- テンプレート4種×カラースキーム4種×テキストでPOP/サイネージをCanvas生成、PNG書き出し、ギャラリー
- **勝ちそう度バッジ＋予想CTR**、**A/B自動作成**（差分チップ・勝者に👑）
- 「棚割のPOPに適用」で勝ちそう度に応じた係数のAI生成POPが棚割タブに追加（生成→売場検証→3D反映の一気通貫）

## 5. 分析ボード（10〜13）

xAD販促ボード仕様の器をすべて実装。全推計値は「点推定±95%CI＋確信度3段階ラベル（高=推奨/中=要サンプル/低=互角）」の統一表現。

- **KPIカード**: 来店・広告増分来店・視線獲得率・転換率・売上着地・iROAS（ジオリフト校正後はCIが締まる）
- **成果分解ウォーターフォール（L1）**: ベースライン＋デジタル広告＋店内サイネージ＋ノベルティ＋人流＋季節・天候 → 総売上
- **O2Oファネル二重接続**: 上段=因果推計（広告接触→増分来店→iROAS）／下段=実測（ノベルティ受取→購買→再来店）＋突合バッジ
- **クロスメディア接触×購買率**: 非接触/広告のみ/サイネージのみ/広告×サイネージの実測比較（FamilyMartVision実証の最大1.7倍と整合）
- **売上時系列**: 実績14日＋本日ライブ＋予測3日（区間バンド）、CP開始の異常検知マーカー
- **棚別テーブル**: 視線・立寄・転換ランキング（行クリックで3Dカメラ移動）
- **ノベルティRCT**: 無作為割付の処置群vs対照群、リフト±CI、z値、MDE、有意到達度
- **顧客セグメント／レジ・オペレーション**: ペルソナ別構成・購買率・客単価／待ち時間・行列・機会損失
- **消費予測・在庫**: 欠品予測時刻、機会損失（在庫内生性）、ダイナミックプライシング状態
- **AIアクション**: 優先度付き打ち手（実行→効果確認のループ）。天候・競合・行列などイベント駆動で自動追加
- **ベンチマーク較正カード**: ダミーデータの根拠（実データ⇄設定の対応表と出典）を常時表示
