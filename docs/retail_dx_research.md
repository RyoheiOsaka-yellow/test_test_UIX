# 店頭DX・リテールメディア調査と組み込みマップ（2026年8月調査）

サントリー等のメーカー、コンビニ・百貨店の最新の店頭デジタル施策を調査し、
プロトタイプへ組み込んだ内容の対応表。

## 調査結果と組み込み状況

### 1. ファミリーマート「FamilyMartVision」 — 組み込み済み ✅

- 全国約10,800店へ設置予定の国内最大級 店内リテールサイネージ網。認知率は2022年36.8%→2025年55.5%
- ジェイアール東日本企画との実証: まど上チャンネル（交通広告）× FamilyMartVision × ビーコンPush通知の
  **クロスメディア接触で商品購買伸長率が最大約1.7倍**（2025年3月リリース）
- 継続出稿で第一想起率2倍以上、店内非取扱カテゴリでも認知効果、他チャネル（スーパー等）購買リフトも確認

**組み込み**: シナリオに「店内サイネージ出稿」トグルを追加。3D店舗に入口ポールサイネージ・レジ上・販促什器横の
スクリーンを設置。店内接触率58%（認知率55.5%を丸め）で接触者を生成し、
購買率倍率を 広告のみ×1.45／サイネージのみ×1.2／**広告×サイネージ=×1.7** に設定。
分析ボードに「クロスメディア接触×販促商品購買率」カード（接触組合せ別の実測購買率とリフト）を新設。
ウォーターフォールにも「店内サイネージ」項を追加。

### 2. サントリー「AIカメラを使った売り場のDX」 — 思想を反映 ✅

- AIカメラで棚前滞在時間などのショッパー行動を可視化し、行動パターン別のプロモーションを売場で展開（MarkeZine）
- スマホ広告×売場サイネージのA/Bテストで最適なコミュニケーションを検証 — マス/Web広告の「空中戦」をリアル店頭へつなぐ
- サントリー酒類のリテールDX: 小売とデータをつないだメーカー主導の売場提案（SBビットタイムズ）

**組み込み**: 本プロトタイプの中核（棚前視線・滞在の常時計測→棚割へ反映）がまさにこの構図。
ログパネルを「AIカメラ／ビーコン LOG」に改称し、計測主体を明示。
クロスメディア分析カードはサントリーのA/Bテスト発想を xAD の確信度ラベル付きで再現。

### 3. トライアル「Retail AI」 — 組み込み済み ✅

- 店内AIカメラ約700台で棚ごとの滞在・棚前行動を分析し、レイアウト・棚割変更に活用
- AIカメラ連動の**自動値下げ（ダイナミックプライシング）**を実運用（日経ビジネス）
- スマートショッピングカート（タブレット広告・クーポン配信）、メーカー・卸とデータ共有する「リアイル」構想

**組み込み**: シナリオに「AIダイナミックプライシング」トグルを追加。
17時以降・在庫消化が遅い（残量>45%）場合に自動で-15%値下げ→転換率×1.3。
消費予測・在庫アラートカードに作動状況を表示（欠品予測と値下げが同じ在庫シグナルから出る＝在庫内生性の逆側）。

### 4. 三越伊勢丹 広告メディア事業（百貨店リテールメディア） — 表記・構造に反映 ✅

- 大型ビジョン・店内サイネージ・紙・Web・エムアイカード媒体・バーチャル新宿等を広告枠として外販
- イベント出店支援（催事・ポップアップ）、来店者データを使ったターゲティングと効果可視化
- ISETAN DOOR（デパ地下商品の定期宅配）などOMO施策

**組み込み**: 百貨店モードのO2Oファネル下段を「エムアイカード型ID-POSで実測化」表記に。
催事プロモ台（ポップアップ検証）は v2 から実装済み。ベンチマークカードに広告メディアガイドを出典として追加。

## 未組み込み（次の候補）

| 候補 | 内容 | 実装イメージ |
|---|---|---|
| スマートカート広告 | トライアル型のカート画面クーポン | エージェントにカート保持フラグ→棚前でクーポン接触→転換リフトの第3メディア |
| リテールメディア収益ビュー | 小売側の広告枠販売収益（メーカー出稿→小売のメディア収入） | xADに「媒体主モード」ボードを追加し、枠在庫×単価×稼働率を表示 |
| クリーンルーム連携表記 | ID-POS×広告IDの突合をプライバシー保護下で行う業界標準 | データ品質バッジに「クリーンルーム連携」段階を追加 |
| 他チャネル購買リフト | FamilyMartVision実証の「スーパー等 他チャネルでもリフト」 | O2Oファネルに「圏外購買（他チャネル）」推計行を追加 |
