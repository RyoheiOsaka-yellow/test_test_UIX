### 1-2. 設計資料（PDF）から読み取った要件

1. **フォント**：英字はヘルベチカ基調で統一。ロゴ・カテゴリは細めでバランスの良いフォント、ヘルベチカと相性の良いフォントを組み合わせる。
2. **カラー**：白ベース。文章の背景はサンドベージュ。各ページのポイントにビビッドカラーを差し色として使う。
3. **ロゴ**：六角形3つ（緑1＋グレー2）＋「BFSERV」ワードマーク。六角形モチーフをサイト全体に展開（「六角型にする」指示）。

6. **取引先**：「多くの企業にご利用いただいています。※50音順」。銀行／建設・不動産／ホテル・交通／企業・公共／保育・教育／文化・スポーツ／商業・飲食のロゴ約130点。取引先の呼び方：官公庁・在日大使館・病院・医療関連施設・介護関連施設・教育機関・ビル・マンション・ショップ・ショッピングモール・各ホール・駐輪場管理。

## 6. 技術構成

- **静的サイト（ビルド依存なし）**：HTML/CSS/Vanilla JS。`bfserv-site/_src/` のページ本文＋パーシャル（head/header/footer/logowall）を `build.py`（標準ライブラリのみ）で結合。
- **外部依存**：Google Fonts（Inter / Noto Sans JP）のみ。ライブラリ不使用（GSAP等なし）で軽量。
- **パス**：全リンク相対（`{{root}}` 展開）。任意のサブディレクトリ／静的ホスティング（GitHub Pages, Netlify, Xserver 等）で動作。
- **SEO**：title/description/OG、`LocalBusiness` の JSON-LD、見出し階層、alt、`aria-current`。
- **アクセシビリティ**：スキップリンク、フォーカスリング、aria-expanded/aria-selected、キーボード操作可能なリング、カラーコントラスト（黄アクセント上は黒文字）。
- **パフォーマンス**：画像は事前最適化（合計約7MB／最大1600px）、`loading="lazy"`、WebGLはDPR上限1.5＆画面外で停止。

```
bfserv-site/
├ index.html, bicycle/, wheelchair/, airstation/, plus/, company/, contact/, privacy/   ← ビルド成果物（そのまま公開可）
├ _src/pages/   ページ本文（<!-- meta --> ヘッダー付き）
├ _src/partials/ head.html / header.html / footer.html / logowall.html
├ assets/css/main.css   デザインシステム
```

### 公開手順
