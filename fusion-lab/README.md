# ANGLEX FUSION — Technology Fusion Lab（コンセプトデモ）

複数の工場が持つ技術を組み合わせて新しい技術・製品を構想する **技術融合シミュレーター** のコンセプトデモです。
ANGLEX（Fabrication Intelligence）と同じデザイン言語で、兄弟プロダクトとして構成しています。

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド不要・サーバ不要・依存は Google Fonts のみ）。

1. **技術ベース** — 12 工場・72 技術（架空）から 2〜6 件を選ぶ。工場・役割・産業・キーワードで絞り込み。
2. **仮説・アイデア** — 作りたいもの、課題、仮説を自由文で入力。規模（部品／装置／大型／ノベルティ）、数量、重視点を指定。6 つのデモシナリオをワンクリックで読込可能。
3. **AI 合成** — 役割カバレッジ、相乗効果（38 ルール）、スケール・材料・ロットの整合性、産業適合度を評価し、結合マップと要約を生成。足りない役割は AI が技術ベースから補完。
4. **デザイン** — 規模の異なる 3 案を展開。概念図面（パラメトリック自動生成・技術の引出線付き）、実現性レーダー、工場をまたぐ工程フロー、リスク、次のアクション、仮説と検証プラン。保存・JSON 出力に対応。

## AI 推論モード

- **ローカル推論（既定）** — ブラウザ内のルールベース合成器。オフラインで即時に動作。クライアント訪問時のデモに安全。
- **Claude API** — 右上の ⚙ から API キーを設定すると、相乗効果・コンセプト・仮説の文章を Claude（`claude-opus-5-5`）が構造化出力（JSON Schema）で生成。補完・工程・図面はローカルで計算。拒否応答や通信失敗時はローカル推論に自動フォールバック。
  - ブラウザから直接 API を呼ぶ構成のため、本番ではサーバ経由（キーを秘匿）にしてください。

## ファイル構成

```
fusion-lab/
  index.html        配布用（結合済み・単一ファイル）
  part1_head.html   スタイル（デザイントークン / レイアウト）
  part2_body.html   マークアップ（4 ステップ + ライブラリ）
  part3_data.js     技術ベース・相乗効果ルール・キーワード辞書・シナリオ
  part4_engine.js   合成エンジン・図面/レーダー/結合マップ SVG・Claude API
  part5_ui.js       UI 状態管理
```

編集後は次のコマンドで結合します。

```bash
cat part1_head.html part2_body.html part3_data.js part4_engine.js part5_ui.js > index.html
```

## 技術ベースの拡張

`part3_data.js` の `RAW` 配列に 1 行追加するだけで技術が増えます（id / 工場 / 名称 / 役割 / タグ / 材料 / スケール / 精度 / ロット / リード / TRL / 産業 / 説明）。
相乗効果は `SYNERGY` にタグの組（`pairs`）として追加します。実運用では各工場の登録フォーム → DB → 本 UI という構成を想定しています。
