# ANGLEX FUSION — Technology Fusion Lab（コンセプトデモ）

複数の工場が持つ技術を組み合わせて新しい技術・製品を構想する **技術融合シミュレーター** のコンセプトデモです。
ANGLEX（Fabrication Intelligence）と同じデザイン言語で、兄弟プロダクトとして構成しています。

## 使い方

`index.html` をブラウザで開くだけで動きます（サーバ不要・オフライン可。Google Fonts が読めない場合はシステムフォントで表示）。

1. **技術ベース** — 12 工場・72 技術（架空）から 2〜6 件を選ぶ。工場・役割・産業・キーワードで絞り込み。
2. **仮説・アイデア** — 作りたいもの、課題、仮説を自由文で入力。規模（部品／装置／大型／ノベルティ）、数量、重視点を指定。6 つのデモシナリオをワンクリックで読込可能。
3. **AI 合成** — 役割カバレッジ、相乗効果（38 ルール）、スケール・材料・ロットの整合性、産業適合度を評価し、結合マップと要約を生成。足りない役割は AI が技術ベースから補完。
4. **デザイン** — 規模の異なる 3 案を展開。**3D モデル**と概念図面（どちらもパラメトリック自動生成）、実現性レーダー、工場をまたぐ工程フロー、リスク、次のアクション、仮説と検証プラン。保存・JSON 出力に対応。

## 3D モデル

合成結果（規模・寸法・技術の割当）から、部品構成を three.js で自動的に組み立てます。

- **7 種のテンプレート** — 部品・モジュール／アーム（ラティス）／装置・機器（ソフトハンド・カメラ付き含む）／大型・門型自動化機／大型・膜構造／ノベルティ・プレート／ノベルティ・ヘラ絞りカップ。名称と技術タグから自動選択。
- **技術 → 部位の割当** — 各技術を役割とタグで部位（本体・カバー・基板・流路・シール・締結・計測…）に割り当て、材質も技術の材料から推定（SUS 鏡面、アルマイト、CFRP、シリコーン、セラミック、ガラス等）。
- **操作** — 回転・拡大・移動、分解スライダー（組立アニメーション付き）、役割カラー、断面表示、ラベル表示切替、視点リセット。部品にカーソルで「技術・工場・働き」を表示、表や部位マップと相互ハイライト。
- **書き出し** — GLB（m 単位）、STL（mm 単位）、PNG。CAD・ANGLEX 3D 詳細モードへの受け渡しを想定。
- **寸法の一貫性** — 3D モデルの実寸を正とし、仕様表・概念図面・説明文の外形を自動で揃えます。
- **オフライン動作** — three.js（r180, MIT）をバンドルして HTML に同梱。WebGL が使えない環境では概念図面に自動で切り替わります。

自動生成されるのは「技術がどこに効くかを示す概念形状」です。強度・公差・意匠の作り込みは CAD での設計工程で行います。

## AI 推論モード

- **ローカル推論（既定）** — ブラウザ内のルールベース合成器。オフラインで即時に動作。クライアント訪問時のデモに安全。
- **Claude API** — 右上の ⚙ から API キーを設定すると、相乗効果・コンセプト・仮説の文章を Claude（`claude-opus-5-5`）が構造化出力（JSON Schema）で生成。補完・工程・図面はローカルで計算。拒否応答や通信失敗時はローカル推論に自動フォールバック。
  - ブラウザから直接 API を呼ぶ構成のため、本番ではサーバ経由（キーを秘匿）にしてください。

## ファイル構成

```
fusion-lab/
  index.html          配布用（結合済み・単一ファイル）
  part1_head.html     スタイル（デザイントークン / レイアウト）
  part2_body.html     マークアップ（4 ステップ + ライブラリ）
  part3_data.js       技術ベース・相乗効果ルール・キーワード辞書・シナリオ
  part4_engine.js     合成エンジン・図面/レーダー/結合マップ SVG・Claude API
  src/viewer3d.js     3D ビューア（テンプレート・材質・分解・断面・書き出し）
  part5_ui.js         UI 状態管理
  build.sh            3D ビューアを three.js ごとバンドルし、全体を結合
```

編集後は次のコマンドでビルドします（初回のみ `npm install`）。

```bash
npm install
```

```bash
npm run build
```

## 技術ベースの拡張

`part3_data.js` の `RAW` 配列に 1 行追加するだけで技術が増えます（id / 工場 / 名称 / 役割 / タグ / 材料 / スケール / 精度 / ロット / リード / TRL / 産業 / 説明）。
相乗効果は `SYNERGY` にタグの組（`pairs`）として追加します。実運用では各工場の登録フォーム → DB → 本 UI という構成を想定しています。
