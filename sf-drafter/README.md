# SF 手描きドラフター / Hand-drawn Speculative Drafter

架空のSF建築・ロボット・航空機・艦船を、**手描きの鉛筆・色鉛筆で描いた等角投影(アイソメ)図面**として
生成するエディターです。
`index.html` の1ファイルだけで動きます(外部CDN・ライブラリ・フォント一切なし、`file://` で直接開けます)。

## 使い方

`sf-drafter/index.html` をブラウザで開くだけです。ビルド不要・通信不要。

## 何ができるか

| 領域 | 内容 |
| --- | --- |
| ジャンル | 建築 / ロボット / 航空機 / 艦船。選ぶと様式タブと左パネルの項目が丸ごと入れ替わります |
| 上部タブ | 各ジャンルの様式(下表) |
| 左パネル | 構成(規模・機数・形式)、構造/装備、情景、画材(色鉛筆パレット・用紙・線の太さ・方眼・着彩量・線の荒さ)、図面(名称・シード) |
| 中央 | 図面シート。ドラッグで移動、ホイールでズーム、`R`キーで再抽選、`←/→`で方位変更 |
| 右パネル | 図面情報(ISOMETRIC STRATA)、自動生成された凡例(LEGEND)、作図記録 |
| 下部ツールバー | 方位切替 / ズーム / **塗り絵(線画)** / 描画アニメON・OFF / 引き直す / PNG保存 / 高解像度PNG |

### 様式

| ジャンル | 様式 | 形式 | 情景 |
| --- | --- | --- | --- |
| 建築 | シンシェル / モデルニスモ / ジオデシック / プレーリー / メタボリズム / アーコロジー / オービタル / ブルータリズム | 平面形7種 | 工業地・丘陵・森林・海岸・市街・荒野 |
| ロボット | 労働機 / 戦術機 / 重砲機 / 巨神 | 二脚・四脚・ホバー・履帯 | 格納庫・整備場・荒野・市街 |
| 航空機 | 迎撃機 / 攻撃機 / 輸送機 / 偵察機 | デルタ翼・後退翼・前進翼・可変翼 | 滑走路・飛行甲板・格納庫・飛行中 |
| 艦船 | 駆逐艦 / 空母 / 潜航艇 / 軌道艦 | 単胴・凌波型・三胴・箱型 | 洋上・乾ドック・港湾・軌道上 |

ロボット・航空機・艦船では武装量(非武装/軽装/重装)も選べ、機数を増やすと編隊・僚艦として
背景に並びます。図面の名称・形式番号(MK-VII、F-62、DD-114 など)もジャンルに応じて自動生成されます。

生成される図面には、参照した製図シートと同じ構成要素が入ります —
タイトルブロック、DWG番号、VIEW/DETAIL/DENSITY/SITE、色見本、方位記号、
左端の基準線マーカー(建築 F1…/ロボット S1…/航空機 WL1…/艦船 DK1…)、LEGEND、PROJECT番号、
1:100のスケールバー、ISOMETRIC STRATA仕様表。

## 塗り絵

**線画モード** に切り替えると自動彩色が止まり、面が紙色で塗りつぶされて前後関係の閉じた
線画になります。用紙に「白紙」を選べばそのまま印刷できる塗り絵の下絵です。

**図面の面をクリックすると、その部材が色鉛筆で塗られます。** 左パネルの鉛筆トレイから色を選び、
柱・主翼・砲塔・床など塗りたい面をクリックするだけ。消しゴムで戻せます。ドラッグは図面の移動なので、
塗りと移動は取り違えません(移動量4px以内のクリックだけを塗りとみなします)。

彩色ずみモードのままでも塗れるので、自動彩色の上から塗り重ねることもできます。

- 塗った色は部材番号で保持し、クリックのたびに**同じ手順をもう一度なぞって**描き直します
  (乱数を描画前に播き直すので、塗った所以外は1本の線までまったく同じに再現されます)
- 形が変わる操作(様式・階数・シードなど)をすると塗りはリセットされます
- 塗れる範囲は色鉛筆のハッチが乗る面。線だけで描かれた樹木の幹やラチス架構は塗り分けの対象外です

## 手描きに見せている仕組み

すべて Canvas 2D 上で手続き的に描いています。3Dライブラリは使っていません。

- **鉛筆ストローク** — 直線を10〜15分割し、両端がすぼまる弓なりの偏差＋点ごとのジッタを与えた上で、
  太さ・濃さ・オフセットを変えて2回重ね描きします。線端は少し描き越します(`wob()` / `stroke()`)。
- **色鉛筆の塗り** — 多角形をクリップし、乗算合成で角度付きのハッチングを引きます。
  1本ごとに濃さ・太さ・長さを乱数で変え、ときどき途切れさせて画材のムラを出します(`hatch2()`)。
  この関数が塗り分け領域の登録・手塗りの色の上書き・線画モードの判定も兼ねています。
- **紙** — 用紙5種を粒子ノイズ・繊維・にじみ・折り目からその場で生成し、
  最後に粒子オーバーレイと周辺の陰りを重ねます(`makePaper()` / `finishSheet()`)。
- **手書きレタリング** — シート内の文字は1文字ずつ位置と角度をずらして描画します(`tech()`)。
- **UI** — パネル・ボタン・チップ・スライダーの枠線はすべて SVG の `feTurbulence` + `feDisplacementMap` で
  歪ませた手描き罫です。背景は生成した紙テクスチャ、カーソルは鉛筆。

## 構造(図面の作り方)

1. シードから乱数を初期化 → 様式ジェネレータが**描画オペレーション**(奥行きキー付きのクロージャ)を積む
2. 実際に描かれる範囲を**採寸パス**で計測(`MEASURE` フラグ。この間は描画関数を空振りさせる)
3. 図面枠いっぱいに収まる縮尺と原点を決定
4. 奥→手前に並べ替え、`requestAnimationFrame` で1フレーム10msずつ消化
   → 鉛筆で描き進んでいくように図面が現れます

同じシード・同じ設定なら、何度描いても完全に同じ図面になります(`mulberry32` の固定シード)。

## 立体のプリミティブ

**軸に沿う建築系** — `prism`(直方体・立面割付・窓割)、`column`(テーパー付きの柱)、
`lattice`(4本組のラチス架構)、`revolve`(ドーム・球・トーラス、ジオデシック分割)、
`shellField`(うねる薄殻キャノピー)、`parasol`、`spire`、`gable`、`quadGrid`、`plate`。

**任意の向きの機械系** — `ebox`(向きが自由な直方体)、`limb`(2点を結ぶ部材)、
`tube`(円筒・円錐・ノズル)、`plate3`(平面形を厚みづけした主翼・甲板・装甲板)、
`loft`(断面列をつないだ胴体・船体)、`meshQuads`(自由曲面)。
面の向きは視線との内積で判定し、手前の面だけを塗ります。

**共通** — `tree` / `scrub` / `figure`(スケール表現)。

機械ジャンルでは、色鉛筆ハッチの下に紙色の下地(`SOL`)を敷いて前後関係を出しています。
建築は下地なしの透過線画のままです。

各ジェネレータはこれらを組み合わせるだけなので、`MODES` に1行と `BUILD` に関数を足せば様式を追加できます。
配置変換 `TR` を使えば、同じジェネレータを縮小・回転して2機目以降として並べられます。
