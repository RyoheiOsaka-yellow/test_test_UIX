# SF建築 手描きドラフター / Hand-drawn Speculative Architecture Drafter

架空のSF建築を、**手描きの鉛筆・色鉛筆で描いた等角投影(アイソメ)図面**として生成するエディターです。
`index.html` の1ファイルだけで動きます(外部CDN・ライブラリ・フォント一切なし、`file://` で直接開けます)。

## 使い方

`sf-drafter/index.html` をブラウザで開くだけです。ビルド不要・通信不要。

## 何ができるか

| 領域 | 内容 |
| --- | --- |
| 上部タブ | 8つの建築様式(シンシェル / モデルニスモ / ジオデシック / プレーリー / メタボリズム / アーコロジー / オービタル / ブルータリズム) |
| 左パネル | 構成(階数・棟数・平面形)、構造(構造密度・ディテール)、敷地(敷地種別・周辺密度)、画材(色鉛筆パレット・用紙・線の太さ・方眼・着彩量・線の荒さ)、図面(建物名・シード) |
| 中央 | 図面シート。ドラッグで移動、ホイールでズーム、`R`キーで再抽選、`←/→`で方位変更 |
| 右パネル | 図面情報(ISOMETRIC STRATA)、自動生成された凡例(LEGEND)、作図記録 |
| 下部ツールバー | 方位切替 / ズーム / 描画アニメON・OFF / 引き直す / PNG保存 / 高解像度PNG |

生成される図面には、参照した製図シートと同じ構成要素が入ります —
タイトルブロック、DWG番号、VIEW/DETAIL/DENSITY/SITE、色見本、方位記号、
左端の階高マーカー(F1…Fn)、LEGEND、PROJECT番号、1:100のスケールバー、ISOMETRIC STRATA仕様表。

## 手描きに見せている仕組み

すべて Canvas 2D 上で手続き的に描いています。3Dライブラリは使っていません。

- **鉛筆ストローク** — 直線を10〜15分割し、両端がすぼまる弓なりの偏差＋点ごとのジッタを与えた上で、
  太さ・濃さ・オフセットを変えて2回重ね描きします。線端は少し描き越します(`wob()` / `stroke()`)。
- **色鉛筆の塗り** — 多角形をクリップし、乗算合成で角度付きのハッチングを引きます。
  1本ごとに濃さ・太さ・長さを乱数で変え、ときどき途切れさせて画材のムラを出します(`hatch2()`)。
- **紙** — 用紙4種を粒子ノイズ・繊維・にじみ・折り目からその場で生成し、
  最後に粒子オーバーレイと周辺の陰りを重ねます(`makePaper()` / `finishSheet()`)。
- **手書きレタリング** — シート内の文字は1文字ずつ位置と角度をずらして描画します(`tech()`)。
- **UI** — パネル・ボタン・チップ・スライダーの枠線はすべて SVG の `feTurbulence` + `feDisplacementMap` で
  歪ませた手描き罫です。背景は生成した紙テクスチャ、カーソルは鉛筆。

## 構造(図面の作り方)

1. シードから乱数を初期化 → 様式ジェネレータが**描画オペレーション**(奥行きキー付きのクロージャ)を積む
2. 実際に描かれる範囲を**採寸パス**で計測(`MEASURE` フラグ。この間は描画関数を空振りさせる)
3. 図面枠いっぱいに収まる縮尺と原点を決定
4. 奥→手前に並べ替え、`requestAnimationFrame` で1フレーム10msずつ消化
   → 鉛筆で描き進んでいくように図面が現れます

同じシード・同じ設定なら、何度描いても完全に同じ図面になります(`mulberry32` の固定シード)。

## 立体のプリミティブ

`prism`(直方体・立面割付・窓割)、`column`(テーパー付きの柱)、`lattice`(4本組のラチス架構)、
`revolve`(ドーム・球・トーラス、ジオデシック分割)、`shellField`(うねる薄殻キャノピー)、
`parasol`、`spire`、`gable`、`quadGrid`、`plate`、`tree` / `scrub` / `figure`(スケール表現)。

各様式ジェネレータはこれらを組み合わせるだけなので、`BUILD` に関数を1つ足せば様式を追加できます。
