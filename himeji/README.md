# 姫路城・姫路市 観光人流デジタルツイン（提案用プロトタイプ）

世界遺産 姫路城〜姫路市全域の「観光DB」アウトプットイメージを、単一HTMLのダッシュボードとして表現したものです。
**誰が（来訪元）・どこから来て（入域手段）・どこに滞留し（地点×時間）・どこへ帰ったか（帰路先・宿泊）** を、
国土地理院（国土交通省）の地図・航空写真・標高タイルの上で、1日の時間軸に沿って可視化します。

- 実行: `index.html` をブラウザで開くだけ（Three.js のみ cdnjs から読み込み。地図・標高は埋め込み済み）
- 用途: 10月初旬提案の提案書向け「イメージ先行」の図版・デモ。実データ未接続の**合成シミュレーション**です

## 画面構成（土台テンプレートの構造を踏襲）

| 領域 | 内容 |
| --- | --- |
| ヘッダー | 日タイプ切替（平日 / 休日 / ピーク日）、視点（全体・姫路城・大手前通り・姫路駅・好古園・書写山・真上・広域(関西)）、ツアー、PNG保存、ヘルプ |
| モードタブ | 👥人流 / 🌏来訪元 / 🚉アクセス / ⏱滞留 / 🏨宿泊・帰路 / 💴消費 / 🗄DB構成 / 📊統計 / 🧪シナリオ |
| 表示トグル | 地図（淡色地図・航空写真・無地）、密度ヒートマップ、ラベル、OD弧線、3D建物、乗り物、地形×2 |
| 左パネル | モード別のKPI・時系列チャート・ランキング・ODマトリクス・インサイト |
| 右カード | 施設・駐車場・ホテル・センサー・広域ノード・来訪者（人）をクリックした詳細。航空写真サムネイル付き |
| タイムライン | 06:00→24:00 の再生（×3〜×30）、開城・最終入城・閉門などのフェーズ表示 |

## データ基盤（国土交通省系）

- 国土地理院 地理院タイル: 淡色地図（z15 市域 9 km四方 / z17 城〜駅）、全国最新写真（同）、標高タイル DEM10B（192×192 グリッド）
- 座標系: 1 unit = 1 m、原点 = 大天守。`LL(lat, lon)` で緯度経度→ワールド座標変換
- 将来接続候補: 国土数値情報、PLATEAU 姫路市 3D都市モデル（2023年度整備済）、全国都市交通特性調査

## シミュレーションの校正元（統計モードに出典付きで収録）

- 姫路城入城者数 FY2025 1,567,674人（外国人 547,426人・34.9%）— 姫路市 報道発表
- 外国人 国・地域別（台湾 13.6% / 米国 12.8% / 豪州 11.7% / 中国 11.1% / 仏 約9.5%…）、日本人 居住地（近畿 34.4% / 関東 22.8% / 東海 15.2%…）— 令和6年度 姫路市観光動向調査（姫路城地点）
- 宿泊: 外国人の市内宿泊 13.9%、日本人（城）日帰り 37.1% / 宿泊 62.9%（市内 48.5%）— 同調査
- 交通手段、1人あたり市内消費、帰路先（大阪が最多）— 同調査
- 縦覧料 2026.3.1〜 市民以外 2,500円 / 市民 1,000円 — 姫路市

数値は上記に合わせて校正した**合成値**です。DB構築後に携帯位置情報・入城券販売（デジタルチケット）・宿泊統計・決済データ等へ置換する想定で、
DB構成モードにデータ層構成・ODレコードのスキーマ・CSV出力（ODレコード / 地点×時間）を用意しています。

## 構成・再生成

```
himeji/
├─ index.html          # 配布用（単一ファイル、約5.8 MB）
├─ src/                # head.html / base.css / extra.css / js1_core.js / js2_scene.js / js3_sim.js / js4_ui.js
├─ assets/             # 地理院タイルのモザイク(webp) と標高グリッド(dem192.b64)
└─ tools/
   ├─ fetch_tiles.py   # 地理院タイル取得 → assets/ 生成（pip install pillow numpy）
   └─ assemble.py      # src + assets → index.html
```

```bash
cd himeji
python3 tools/fetch_tiles.py   # 地図・標高を再取得する場合のみ
python3 tools/assemble.py      # index.html を再生成
```

主な調整箇所（`src/js1_core.js`）: `SEG`（来訪元セグメントの構成比・宿泊率・手段）、`SPOTS`（滞留地点・滞留時間・料金）、
`GATES`（駐車場容量など）、`HOTELS`、`REG`/`ABROAD`（広域ノード）、`DAYS`（日タイプ別の想定人数）。
