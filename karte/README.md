# AAA(修繕データ一元管理)デモ

賃貸物件の点検・指摘・修繕履歴を一元化して可視化する、社内提案用のプロトタイプです。
データはすべて架空で、`src/data.ts` で固定シードから生成しています(バックエンドなし)。

```bash
npm install
npm run dev     # http://localhost:5173
npm run build        # dist/ に静的ファイルを出力
npm run build:html   # tatemono-karte.html(1ファイルで動くHTML)を出力
```

## 画面

- ダッシュボード: 早急対応・未提案・点検期限・修繕推奨額、対応の進み具合、優先案件
- 物件を探す: キーワード(物件名・住所・オーナー名カナ・担当・ID)と条件での絞り込み、並べ替え
- 物件詳細: コンディション、要修繕箇所(配置図ピン)、将来修繕シミュレーション、点検・修繕履歴、
  指摘の対応状況、連携記録。「オーナー向け表示」で社内情報を隠した説明用画面に切り替え
- 指摘・修繕データ: 全物件横断の検索とCSV出力
- AAA(説明用・社員向け): 社員がオーナーに説明するときに使う画面。スライドの4ブロック(状態・修繕箇所・修繕の理由・履歴)を、ブラウザ(2×2)／iPad(ページ送り・情報量多め)／スマホ(スワイプ・大きな文字)で切り替え。写真の拡大表示、修繕前後の比較つき
- お客様向けレポート: A4で印刷・PDF保存できる報告書(要点→状態→修繕時期→箇所→理由→計画→履歴→進め方)。サンプルは `docs/sample-customer-karte.pdf`
- データ分析: 築年数×評価の散布図、築年帯×部位のヒートマップ、年別修繕費、担当者別・支店別の状況
- 修繕の課題と狙い: 公的資料で確認した課題と対応画面

シミュレーションの初期値(工事費上昇率・補修範囲拡大率)はデモ用の仮定です(`src/sim.ts`)。
