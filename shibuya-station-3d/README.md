# 渋谷駅 構内図 3D

新宿駅 構内図 3D(参考実装)と同じビューアエンジンを用いて、渋谷駅を 9 フロア
(B5〜4F)で立体再現したシングルファイルの Web アプリです。
`index.html` をブラウザで開くだけで動作します(データ・ライブラリすべて埋め込み済み)。

## フロア構成

| 階層 | 主な内容 |
|------|----------|
| 4F   | 銀座線 アベニュー改札まわり |
| 3F   | 東京メトロ銀座線ホーム・JR 跨線通路 |
| 2F   | JR 山手線・埼京線ホーム、京王井の頭線ホーム、中央改札 |
| 1F   | 地上改札(南改札・西改札ほか)、ハチ公広場周辺 |
| B1〜B2 | 地下コンコース・東口地下広場 |
| B3   | 東急田園都市線・東京メトロ半蔵門線ホーム |
| B4   | 東急・メトロ乗換コンコース |
| B5   | 東急東横線・東京メトロ副都心線ホーム |

## 機能

- フロア別表示切替・フロア展開(高さ方向の分解表示)
- 歩行者ネットワーク表示と人流シミュレーション(朝/昼/夕/夜)
- 経路検索(フロア間の階段・エスカレーター・EV 経由、段差回避オプション)
- 図面モード(真上からの 2D 表示)・自動回転・ツールチップ(施設名)

## データ出典

- 歩行空間ネットワークデータ(東京都 渋谷南部)
  — [国土交通省](https://www.geospatial.jp/ckan/dataset/0401) を加工して作成
- 駅構内(ホーム・通路・改札等)・周辺建物・鉄道路線・道路
  — © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors
  (渋谷駅は国土交通省の屋内地図オープンデータ未整備のため、構内形状は OSM の
  屋内マッピングから生成。地下通路は線データをバッファして面化、
  京王井の頭線ホームは線路データから合成)

## 生成方法(参考)

`tools/` 以下は作業時に使用したデータ生成スクリプトです(パスは作業環境依存)。

1. `build_data.py` — Overpass API / G空間情報センターから取得した生データを
   EPSG:6677(平面直角座標系IX系)へ変換し、フロア別 Space/Floor/Fixture、
   歩行者ネットワーク、周辺建物・鉄道・道路の埋め込み JSON を生成
2. `assemble.py` — 参考実装 HTML のビューアエンジンに対し、データ・フロア定義・
   座標原点・表示文言を渋谷駅版へ差し替えて `index.html` を出力
