# 静岡市中央体育館 デジタルツイン — ベルテックス静岡

Three.js 製シングルファイルの Web アプリです。ベルテックス静岡の現ホームアリーナ **静岡市中央体育館**（葵区駿府町・駿府城公園隣接）を中心に、周辺 3D 都市モデル・人流・広域ネットワークを可視化します。

- **ファイル**: `index.html`（約 5MB・単一ファイル）
- **動作方法**: ブラウザで開くだけ（地図タイル・フォント・three.js は CDN / 国土地理院タイルを参照）

---

## ビュー構成

| ビュー | 内容 |
|--------|------|
| **L0 俯瞰** | 中央体育館・駿府城エリアの 3D 都市モデル（建物約 36,000 棟・道路・鉄道・河川・土地利用） |
| **L1 広場** | エントランス広場（キッチンカー・売店配置の編集） |
| **L2 内部** | アリーナ内部（座席マーケティング・観客描画 ※レイアウトは仮説モデル） |
| **🏟 県域** | パートナータウン網 16 自治体＋県内アリーナ 6 館＋広域動線＋経済波及効果 |

## 機能

- **🏟 県域ビュー — 16 自治体パートナータウン網プラットフォーム**
  - アリーナ 6 館（静岡市中央体育館 HOME・このはなアリーナ・北里アリーナ富士・香陵アリーナ・静岡県武道館・浜松アリーナ）を**黄色**マーカーで実位置表示
  - パートナータウン協定自治体をオレンジで表示（協定名つき・判明 13 自治体、全 16）
  - 広域動線: 東海道新幹線・JR東海道本線・東名・新東名・国道1号（OSM 実形状）
  - 経済波及効果カード（試合日直接消費・年間換算のモデル値＋新アリーナ構想 30 年 5,000 億円超〔静岡市試算〕）
- **🚶 デッキ・歩行者動線** — 駅・駐車場→アリーナのアプローチ経路（実道路ネットワークの A* 探索）、歩行者専用道・歩道のグロー表示、流動シェブロン、ネットワーク統計（ノード約 12,400・リンク約 10,900）
- **🚗 周辺渋滞** — タイムライン連動（夕ラッシュ＋来場/退場サージ）の渋滞シミュレーション（仮説モデル・順調/混雑/渋滞の 3 段階＋駐車場入口滞留）
- **🆘 避難シミュレーション** — 満員 2,600 人がアリーナから駿府城公園（**広域避難地**）・静岡浅間神社（避難場所）・城北公園・常磐公園へ避難する様子を 24 倍速で再生。完了率・平均避難時間を表示
- **人流・OD 分析** — 試合日タイムライン（開場→TIP OFF→退場）に連動した来場・回遊・直帰フロー、ガウス KDE サーフェス
- **観光導線・クロス分析・VPS・点群ビュー・UNITE パネル**

## データ出典

| データ | 出典 |
|--------|------|
| 建物・道路・鉄道・河川・土地利用・駅・バス停・宿泊・地名 | © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors（Overpass API, 2026-08 取得） |
| 航空写真タイル | [国土地理院 全国最新写真（シームレス）](https://maps.gsi.go.jp/development/ichiran.html) |
| アリーナ・自治体・避難地の位置 | OSM / Nominatim 実測（アリーナ中心のローカル座標に変換） |
| 静岡市中央体育館 収容（固定席 984・試合日約 2,600 人） | B.LEAGUE 公式アリーナ情報ほか |
| 駿府城公園＝広域避難地・浅間神社＝避難場所 | 静岡市 広域避難地・一時避難地一覧 |
| 新アリーナ構想 30 年経済波及 5,000 億円超 | 静岡市試算（公表値） |
| パートナータウン協定（16 自治体） | ベルテックス静岡公式ニュース等（判明 13 自治体を表示） |

> **補足**: 回遊消費・渋滞・避難の各シミュレーションは実データ接続を想定した**仮説モデル**です。座標系はアリーナ中心のローカル m（Web メルカトル × cos 補正）。

## 検証結果

Playwright + Chromium によるヘッドレス検証済み: 読み込み・全 13 モード切替でコンソールエラーなし。県域・動線・渋滞・避難・L2 のスクリーンショット確認済み。

## 生成パイプライン（参考）

1. Overpass API / Nominatim から取得した生データをアリーナ中心ローカル座標へ変換し、`SCENE_DATA`（建物・道路・鉄道・河川ほか）を再生成
2. 県域動線はウェイ端点の一致でチェーン連結後、Douglas-Peucker 簡略化（東海道本線 169km 連続ラインなど）
3. ビューアエンジンへデータ・文言・拡張モジュール（県域 / 動線 / 渋滞 / 避難）を差し替え・追加して `index.html` を出力
