# 静岡市中央体育館 デジタルツイン — ベルテックス静岡

Three.js 製シングルファイルの Web アプリです。ベルテックス静岡の現ホームアリーナ **静岡市中央体育館**（葵区駿府町・駿府城公園隣接）を中心に、周辺 3D 都市モデル・人流・広域ネットワークを可視化します。

- **動作方法**: ブラウザで開くだけ（地図タイル・フォント・three.js は CDN / 国土地理院タイルを参照）
- **アリーナ切替**: ヘッダーのセレクタ（または県域パネルのリンク）で 6 アリーナのツインを相互に切替
- **統合ビュー**: `all.html` を開くと 6 アリーナをタブで切り替えられる統合シェル（1ブラウザで全アリーナ）

## 機能

- **🏟 県域ビュー — 16 自治体パートナータウン網プラットフォーム（動的・指標駆動）**
  - アリーナ 6 館（静岡市中央体育館 HOME ほか）を**黄色**マーカーで実位置表示
  - パートナータウン協定自治体をオレンジで表示（協定名つき・判明 13 自治体、全 16）
  - **指標チップでネットワークの意味を切替**: ネットワーク（協定接続）／来場圏 推計（人口×距離グラビティ）／経済効果 推計（来場圏×平均消費）。アークの太さ・粒子量・リング径・自治体リストの数値バーが連動
  - **動的表現（OD 分析と同系）**: アークは粒子ではなく**ゆっくり流れるグラデーション帯**（帯の流れ＝向き。オレンジ=連携先→ホーム、黄=ホーム→開催アリーナ）＋指標値に応じた**KDE 風の面的ヒート**、都市リングの静かなパルス、モード ON 時の段階的リビール
  - 広域動線: 東海道新幹線・JR東海道本線・東名・新東名・国道1号（OSM 実形状）
  - 経済波及効果カード（試合日直接消費・年間換算のモデル値＋新アリーナ構想 30 年 5,000 億円超〔静岡市試算〕）
- **🚶 デッキ・歩行者動線** — 駅・駐車場→アリーナのアプローチ経路（実道路ネットワークの A* 探索）、歩行者専用道・歩道のグロー表示、流動シェブロン、ネットワーク統計（ノード約 12,400・リンク約 10,900）
- **🚗 周辺渋滞** — タイムライン連動（夕ラッシュ＋来場/退場サージ）の渋滞シミュレーション（仮説モデル・順調/混雑/渋滞の 3 段階＋駐車場入口滞留）
- **🆘 避難シミュレーション** — 満員 2,600 人がアリーナから駿府城公園（**広域避難地**）・静岡浅間神社（避難場所）・城北公園・常磐公園へ避難する様子を 24 倍速で再生。完了率・平均避難時間を表示
- **人流・OD 分析** — 試合日タイムライン（開場→TIP OFF→退場）に連動した来場・回遊・直帰フロー、ガウス KDE サーフェス
- **観光導線・クロス分析・VPS・点群ビュー・UNITE パネル**

## 検証結果

Playwright + Chromium によるヘッドレス検証済み: 全 6 ページの読み込み・モード切替でコンソールエラーなし。県域・動線・渋滞・避難・L2 のスクリーンショット確認済み。

## 生成パイプライン（参考）

1. Overpass API / Nominatim から取得した生データをアリーナ中心ローカル座標へ変換し、`SCENE_DATA`（建物・道路・鉄道・河川ほか）を再生成
2. 県域動線はウェイ端点の一致でチェーン連結後、Douglas-Peucker 簡略化（東海道本線 169km 連続ラインなど）
3. ビューアエンジンへデータ・文言・拡張モジュール（県域 / 動線 / 渋滞 / 避難）を差し替え・追加して `index.html` を出力
