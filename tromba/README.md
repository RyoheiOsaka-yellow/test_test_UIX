# TROMBA — アガベ平原の竜巻

メキシコ・ハリスコ高原のアガベ農園を、竜巻の側から歩くブラウザゲーム。
`tromba/index.html` を開くだけで動く。エンジンもビルド手順も依存も外部
アセットも無い、WebGL2 の一枚 HTML（約 270 KB）。`file://` からでも動く。

## 遊び方

| 操作 | |
| --- | --- |
| `W A S D` / 左スティック | 移動（視点に対して） |
| マウス / 右スティック | 見回す・ホイールで寄り引き |
| `Space` | 突進。水分を燃やして走る |
| `E` / 左クリック | 落雷。電荷が満ちているときだけ（EF3 以上） |
| `C` | 視点（追走 / 旋回 / 地上 / 自由） |
| `P` 写真モード · `H` HUD · `Tab` 記録帳 · `Esc` 設定 | |

畑を薙ぎ、サボテンを倒し、赤い土を吸い上げるほど渦は育つ。段が上がるごとに
半径・丈・旋回が連続に伸び、**雲が付き、雨が降り、雷を持ち、赤くなる**。
抜けた株も、柵も、トラックも、牛も、実体のまま渦に絡まって螺旋を描いて上がり、
やがてどこかに落ちる。

| 段 | | 必要な点 | 付いてくるもの |
| --- | --- | --- | --- |
| EF0 | 塵旋風 | 0 | 乾いた土だけの細い柱 |
| EF1 | 旋風 | 40 | 雲底が下がってくる。柱サボテン・納屋・トラックを噛める |
| EF2 | 嵐 | 140 | 壁雲と雨。給水塔と風車が折れる |
| EF3 | 雷 | 360 | 落雷。母屋に歯が立つ |
| EF4 | 紅蓮 | 800 | 赤い土が柱と雲底を染める |
| EF5 | 終焉 | 1,500 | くさび形。畑の幅を丸ごと持っていく |

得点は右上に出る。壊した瞬間に渦の頭の上へ「+30」のように浮き、次の段まで
あと何点かも数字で出る。

| 何を | 点 |
| --- | --- |
| アガベ・灌木 | 1 |
| 柵 | 2 |
| 人 | 10 |
| サボテン | 10 |
| ピニャの山・ロバ | 15 |
| 牛 | 20 |
| トラック | 30 |
| 納屋 | 40 |
| 給水塔・風車 | 60 |
| 母屋 | 200 |

渦は消えない。水分は突進の燃料と噛む速さを決めるだけで、尽きても段は落ちない。

農園には人と家畜がいる。ヒマドール（刈り取り人）、牛の群れ、ロバ、犬。渦が近づけば
斜めに走って逃げ、捕まれば回りながら飛び、落ちて、数秒後に起き上がってまた走る。
誰も死なない。

## 中身

`aee225c3-regolith.html`（月面ローバーの単一ファイル WebGL2 ゲーム）の
構造をそのまま借りて、舞台と遊びを差し替えたもの。`core/*`（GL 層、HDR と
ブルーム、行列、入力、手続き的メッシュ、決定的ノイズ）は元のまま使い、
世界とゲームは書き直した。

| モジュール | |
| --- | --- |
| `world/terrain.js` | 高原の地形。畑の段は数式の側で平らにしてある。クリップマップと日射マスクの焼き込みは元のまま |
| `world/sky.js` | 空。雲は水平な板一枚で、太陽方向へ二回引いて自分の影を作る。嵐が育つと雲底が漏斗の上端まで下りてくる |
| `world/props.js` | 畝に沿った約 5,200 株のアガベ、柱サボテン、灌木、柵、ハシエンダ。倒れた株は静止側のインスタンスを潰して「飛んでいる側」へ移り、渦の速度場に引きずられて回りながら上がる |
| `world/actors.js` | ヒマドール、牛、ロバ、犬。脚は頂点シェーダの歩容変形で振るので、一体につき描画は一回 |
| `world/debris.js` | 破片。抗力で渦の速度場に引きずられる。月と違って空気があるので放物線は描かない |
| `game/tornado.js` | 渦本体。ランキン渦の速度場、EF0〜EF5 の連続補間、殻二枚の漏斗、中点変位で作る稲妻 |
| `game/gameplay.js` | 目標十一段、記録帳の開封、被害の帳簿 |
| `ui/hud.js` | 計器一式。シミュレーションを直接読まない |

地形も畑も種一つの純関数なので、保存ファイルに入っているのは「何が消えたか」
の番号だけ。

## 開発用の口

```js
TROMBA.debug = 1   // 1 影 / 2 法線 / 3 N·L / 4 畑・抉り・雨 / 5 LOD / 6 アルベド
TROMBA.pause(true)
TROMBA.tick(1/60)  // 一フレームだけ手で進める
TROMBA.tornado.energy = 1200   // 段を飛ばして見る
```
