# TROMBA — 竜巻の側から歩く

メキシコを舞台に、竜巻の側から土地を歩くブラウザゲーム。
`tromba/index.html` を開くだけで動く。エンジンもビルド手順も依存も外部
アセットも無い、WebGL2 の一枚 HTML（約 340 KB）。`file://` からでも動く。

## 舞台

起動して最初に選ぶ。地形の焼き込みは選んでから始まる。

| | | |
| --- | --- | --- |
| **アガベ農園** | HACIENDA SAN ROMÁN | 高原の赤い土、四十年ぶんの畝、母屋と風車、牛の群れ |
| **街** | CIUDAD DE ÁLAMOS | 62 m 角の街区、日干し煉瓦の家、電柱と街路樹、教会の塔 |
| **湾岸** | PUERTO SALINA | 海、埠頭、積み上がったコンテナ、クレーン、ヤシ、灯台 |

湾岸には海面がある。渦が海へ出ると足元に環が走り、吸い上げるのは水になる。

## 遊び方

| 操作 | |
| --- | --- |
| `W A S D` / 左スティック | 移動（視点に対して） |
| マウス / 右スティック | 見回す・ホイールで寄り引き |
| `Space` | 突進。水分を燃やして走る |
| `E` / 左クリック | 落雷。電荷が満ちているときだけ（EF3 以上） |
| `C` | 視点（追走 / 旋回 / 地上 / 自由） |
| `P` 写真モード · `H` HUD · `Tab` 記録帳 · `Esc` 設定 | |

壊すほど渦は育つ。段は十段あり、境目で数字が飛ぶのではなく、半径・丈・旋回・
うねりが連続に伸びる。抜けた株も、柵も、トラックも、牛も、実体のまま渦に
絡まって螺旋を描いて上がり、やがてどこかに落ちる。

| 段 | | 必要な点 | 付いてくるもの |
| --- | --- | --- | --- |
| L1 | 塵旋風 | 0 | 乾いた土だけの細い柱。よくうねる |
| L2 | 旋風 | 40 | 雲底が下がる。中くらいのものを噛める |
| L3 | 嵐 | 140 | 壁雲と雨 |
| L4 | 雷 | 360 | 落雷。ランドマークに歯が立つ |
| L5 | 双子 | 700 | **衛星渦が一本**。親の周りを公転する |
| L6 | 紅蓮 | 1,200 | 赤い土が柱と雲底を染める |
| L7 | 三つ子 | 2,000 | **衛星渦が二本** |
| L8 | 大渦 | 3,200 | くさび形。うねりは浅く、幅で押す |
| L9 | 黒 | 4,800 | **衛星渦が三本** |
| L10 | 終焉 | 7,000 | 半径 36 m、丈 366 m |

衛星渦は本体より小さく、それぞれ自分の足元を削る。被害の跡が一本の帯では
なく何本もの筋になるのはそのため。

得点は右上に出る。壊した瞬間に渦の頭の上へ「+30」のように浮き、次の段まで
あと何点かも数字で出る。

| 何を | 点 |
| --- | --- |
| アガベ・灌木 | 1 |
| 柵 | 2 |
| 人 | 10 |
| サボテン | 10 |
| ピニャの山・ロバ | 15 |
| 牛 | 20 |
| トラック | 30 |
| 納屋 | 40 |
| 給水塔・風車 | 60 |
| 母屋 | 200 |

渦は消えない。水分は突進の燃料と噛む速さを決めるだけで、尽きても段は落ちない。

農園には人と家畜がいる。ヒマドール（刈り取り人）、牛の群れ、ロバ、犬。渦が近づけば
斜めに走って逃げ、捕まれば回りながら飛び、落ちて、数秒後に起き上がってまた走る。
誰も死なない。

## 中身

`aee225c3-regolith.html`（月面ローバーの単一ファイル WebGL2 ゲーム）の
構造をそのまま借りて、舞台と遊びを差し替えたもの。`core/*`（GL 層、HDR と
ブルーム、行列、入力、手続き的メッシュ、決定的ノイズ）は元のまま使い、
世界とゲームは書き直した。

| モジュール | |
| --- | --- |
| `game/stages.js` | 三つの土地の定義。高さ関数、地面の描き方、区画、太陽、呼び名 |
| `world/terrain.js` | 渡された高さ関数を標本化してGPUに載せる。クリップマップと日射マスクの焼き込みは元のまま |
| `world/water.js` | 湾岸の海。カメラ中心の円盤で、水深は地形の場から読む。汀線は二つの面が交わる線として自動的に出る |
| `world/sky.js` | 空。雲は水平な板一枚で、太陽方向へ二回引いて自分の影を作る。嵐が育つと雲底が漏斗の上端まで下りてくる |
| `world/props.js` | 三つの土地のプロップ。小さいもの・中くらいのものは四つの枠にインスタンス描画、建物は模型行列。倒れた株は静止側のインスタンスを潰して「飛んでいる側」へ移り、渦の速度場に引きずられて回りながら上がる |
| `world/actors.js` | ヒマドール、牛、ロバ、犬。脚は頂点シェーダの歩容変形で振るので、一体につき描画は一回 |
| `world/debris.js` | 破片。抗力で渦の速度場に引きずられる。月と違って空気があるので放物線は描かない |
| `game/tornado.js` | 渦本体。ランキン渦の速度場と浅い流入層、L1〜L10 の連続補間、殻二枚の漏斗、衛星渦、中点変位で作る稲妻 |
| `game/gameplay.js` | 目標十二段（骨格は土地共通、呼び名だけ差し替え）、記録帳の開封、被害の帳簿 |
| `ui/hud.js` | 計器一式。シミュレーションを直接読まない |

地形もプロップも種一つの純関数なので、保存ファイルに入っているのは「何が
消えたか」の番号だけ。保存は舞台ごとに別の枠を持つ。

## 開発用の口

```js
TROMBA.debug = 1   // 1 影 / 2 法線 / 3 N·L / 4 畑・抉り・雨 / 5 LOD / 6 アルベド
TROMBA.pause(true)
TROMBA.tick(1/60)  // 一フレームだけ手で進める
TROMBA.tornado.energy = 2000; TROMBA.tornado._applyParams()   // 段を飛ばす
TROMBA.stage.id                // いまの舞台
```
