octopus_ 八本の腕

タコです。8 本の腕はそれぞれ 11 節の距離拘束チェーンで、 体の動きに引きずられて自然にたなびきます。カーソルを近づけると いちばん近い腕がするりと伸びてきます。危険を感じれば墨を吐き、 ジェット噴射で逃げて背景の色に擬態します。

60 fps state 漂遊中 0 ジェット 0 墨 0 kernel alloc / frame

カーソル / 指を近づける: 腕が伸びてくる · クリック / タップ: その場所へジェット噴射 · ダブルクリック / 素早いフリック: 墨を吐いて逃げ、擬態する

インタラクション

  • 腕のリーチ — カーソルに最も近い腕の先端を目標へ引き、FABRIK 的な往復拘束で 腕全体が滑らかに追従します(興味津々)。残りの 7 本は漂いのまま。
  • ジェット噴射 — クリック地点へ外套膜を縮めて噴射(ジェット!)。 腕は慣性で後ろにたなびきます。
  • 墨と擬態 — ダブルクリックで墨の煙幕を残して反対方向へ噴射。 その後数秒、体色が背景色へ color.lerp して溶け込みます(擬態中)。
  • 吸盤 — 腕の内側に並ぶ吸盤は 1 節おきの円。腕の曲率に沿って向きが変わります。
