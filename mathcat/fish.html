mathcat demo · boids

fish_ 群れを泳がせる

mathcat カーネルだけで魚の群れを表現したデモです。各個体は結束・整列・分離の 3つの操舵力で泳ぎ(Boids)、体は距離拘束で頭を追いかける 8 節のセグメント。 すべて事前確保した配列の上で動き、フレーム中のアロケーションはゼロです。

60 fps 0 fish 0 allocations / frame
ドラッグで回転 · クリックで餌

仕組み

1 フレームの流れ。すべて op(out, a, b) 規約のカーネル呼び出しです。

// 操舵: 近傍の平均へ (結束) / 平均速度へ (整列) / 距離の逆二乗で反発 (分離)
vec3.subtract(desired, target, pos[i])
vec3.normalize(desired, desired)
vec3.scaleAndAdd(force, desired, vel[i], -1)   // desired*maxSpeed - vel

// 積分: 加速度 → 速度 → 位置。すべて setup で確保した subarray view 上
vec3.scaleAndAdd(vel[i], vel[i], acc, dt)
vec3.scaleAndAdd(pos[i], pos[i], vel[i], dt)

// 体: 各節が前の節を一定間隔で追いかける距離拘束
vec3.subtract(dir, seg[s], seg[s - 1])
vec3.normalize(dir, dir)
vec3.scaleAndAdd(seg[s], seg[s - 1], dir, spacing)

使っているカーネル関数

  • vec3 — subtract / normalize / scaleAndAdd / distance / cross / lerp / transformMat4。操舵・積分・体の追従・投影のすべて。
  • mat4 — perspective / lookAt / multiply / invert。カメラと、クリック位置を水槽内の一点に戻す逆射影。
  • random — createRng / inSphere。シード付きなのでリロードしても同じ群れが生まれます。
  • easing — smoothstep。水槽の壁に近づくほど滑らかに強くなる境界力。
  • color — fromHsl。個体ごとの色相のゆらぎと、まれに混ざる緋色の一匹。
