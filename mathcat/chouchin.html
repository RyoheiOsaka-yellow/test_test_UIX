anglerfish_ 深海の提灯

チョウチンアンコウです。額から伸びる誘引突起(イリシウム)の先で 発光器(エスカ)が光り、小魚が吸い寄せられます。射程に入った瞬間、 大口を開けて吸い込みます。光は加算合成の同心円、 動きはすべて mathcat の演算です。

60 fps state 待ち伏せ 0 捕食 52% 光量 0 kernel alloc / frame

カーソル / 指でなぞる: ゆっくり付いてくる · クリック / タップ: 発光を強める(小魚が寄る) · ダブルクリック / 素早いフリック: 灯りを消して潜伏

インタラクション

  • 誘引 — クリックでエスカが強く明滅し(誘引中)、小魚が光へ引き寄せられます。 引力は光量に比例 — vec3.scaleAndAdd の操舵力です。
  • 吸い込み捕食 — 小魚が口の射程に入ると大口を開け、吸引で丸呑みします(捕食!)。 食べられた小魚はしばらくして暗闇の外から補充されます。
  • 潜伏 — ダブルクリックで発光器を消し、後ずさりして闇に溶けます(潜伏)。小魚は散り散りに。
  • マリンスノー — 深海の降雪。プールされたパーティクルが漂い、光の近くでだけ見えます。
