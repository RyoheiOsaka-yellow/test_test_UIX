king crab_ 海底の横歩き

タラバガニです。6 本の歩脚はそれぞれ 2 関節の逆運動学(IK)で足先を海底に接地させ、 体の移動に合わせて交互にステップします。すべて mathcat の演算、 フレーム中のカーネルアロケーションはゼロです。

60 fps state 歩行中 0 摂食 0 kernel alloc / frame

カーソル / 指でなぞる: 追わせる · クリック / タップ: 餌を沈める · ダブルクリック / 素早いフリック: 威嚇させる

インタラクション

  • 横歩き追尾 — カニは前に歩けません。カーソルの真下へ、6 本の脚を交互に運びながら横歩きで近づきます(接近中)。
  • 給餌 — クリックで餌が海底に沈みます。駆け寄ってハサミで拾い、口に運びます(摂食!)。
  • 威嚇 — ダブルクリックやカーソルの素早い動きに、両のハサミを大きく振り上げて応えます(威嚇!)。
  • 脚の IK — 肩と足先から膝の位置を余弦定理で解き、体が進むと踏み替えます。 easing.smoothstep がステップの持ち上げを、vec3 が体の操舵を担当。
