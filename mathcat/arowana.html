arowana_ 水面の捕食者

今度は群れではなく一匹の大型淡水魚、アロワナです。リボンのような長い体は 20 節の距離拘束チェーン、大きな鱗・長い臀びれ・2 本のヒゲも すべて mathcat の演算から描いています。アロワナは水面に落ちた虫を ジャンプで捕らえる魚 — その習性がこのデモのインタラクションです。

60 fps state 回遊中 0 捕食 0 kernel alloc / frame
カーソル: 追わせる · クリック: 虫を落とす · ダブルクリック: 驚かす

インタラクション

  • カーソル追尾 — 水槽の上でカーソルを動かすと、本物のアロワナが飼い主の指を追うように近づいてきます(state: 接近中)。
  • 給餌ジャンプ — クリックで水面に虫が落ちます。アロワナは真下に回り込み(狙っている)、角度が合うと水面を割ってジャンプ。着水で飛沫と波紋が広がります。
  • 驚愕反応 — ダブルクリック、またはカーソルを素早く振ると、ガラスを叩かれた魚のように反転して逃げます(警戒!)。
  • 品種切り替え — シルバー / 過背金龍 / 紅龍。color.fromHex と color.lerp のパレット差し替えだけなので、フレーム中のアロケーションはゼロのままです。

さらに広げるなら

  • 音 — WebAudio で着水音とヒレの水流音。飛沫の強さ(着水速度)をそのままゲインに接続できます。
  • モバイルのジャイロ — 端末を傾けると水槽が傾き、水面が vec2.rotate で追従。魚は流れに逆らって定位します。
  • 成長 — 捕食のたびに easing.smoothstep で体節間隔をわずかに伸ばし、稚魚から 60cm 級へ育てる。
  • 2 匹目と縄張り — アロワナは混泳が難しい魚。分離ステアリングを攻撃的な突進に変えるだけで縄張り争いになります。
  • WebGPU 化 — 体のリボンをインスタンス描画へ。カーネルは列優先の Float32Array なのでバッファをそのまま渡せます。
