porcupinefish_ 怒らせないで

ハリセンボンです。ふだんは棘を寝かせてのんびり泳いでいますが、 本体をクリックすると怒って水を飲み込み、まん丸に膨らんで 全身の棘を立てます。膨張は easing.smoothstep、 棘の起き上がりは接線→法線方向への lerp です。

60 fps state 遊泳中 0 膨張 0 kernel alloc / frame

カーソル / 指でなぞる: 近寄ってくる · 魚をクリック / タップ: 怒って膨らむ · 離れた場所をクリック: 見に行く

インタラクション

  • 膨張 — 本体クリックで体積が約 5 倍に。26 本の棘が寝た状態(接線方向)から 立った状態(法線方向)へ起き上がり、目つきも変わります(怒った!)。
  • 浮上 — 膨らむと泳げません。ぷかぷかと水面へ浮かび、泡を吐きながら漂います。
  • 沈静化 — 4 秒ほどで機嫌を直し、泡と一緒に空気を吐いてしぼみます(しぼみ中)。
  • 好奇心 — カーソルには興味津々。離れた場所をクリックすると様子を見に行きます(接近中)。
