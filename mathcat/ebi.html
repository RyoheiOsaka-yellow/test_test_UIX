shrimp_ 後ろへ跳ぶ

エビです。ふだんは海底をちょこちょこ歩き、長い触角を揺らしています。 驚かせると尾を強く打ち付けて後方へ弾丸のように跳びます — 甲殻類の「カリドイド逃避反応」。体の丸まりが推進のパルスです。

60 fps state 歩行中 0 逃避 0 摂食 0 kernel alloc / frame

カーソル / 指でなぞる: 興味を引く · エビをクリック / 素早いフリック: 驚かせる(後方エスケープ) · 離れた場所をクリック: 餌を沈める

インタラクション

  • カリドイド逃避 — 本体クリックで腹部を瞬間的に丸め、3 連続の尾打ちで後方へ跳びます(エスケープ!)。 体の曲率パルスがそのまま推進力になっています。
  • 着底 — 跳んだあとはゆっくり沈み、脚を広げて着地(着底)、また歩き始めます。
  • 採餌 — 離れた場所をクリックすると餌が沈み、歩いて向かい、小さな前脚でついばみます(摂食)。
  • 触角 — 2 本の長い触角が常に水流を探っています。逃避の瞬間は後方へなびきます。
