harp seal_ 流氷のうたた寝

白いアザラシの赤ちゃんです。流氷の上をもぞもぞ這ってカーソルを追いかけますが、 しばらく放っておくとその場でぺたんと平たくなり、目を閉じて眠ってしまいます。 呼吸のふくらみ、まばたき、Zzz — ぜんぶ mathcat の演算です。

60 fps state のんびり 0 おさかな 0 うたた寝 0 kernel alloc / frame

カーソル / 指でなぞる: ついてくる · クリック / タップ: 魚をあげる · ダブルクリック: ころころ転がる(寝ていたら起きる) · 7 秒放置: 眠る

インタラクション

  • うたた寝 — 7 秒かまってもらえないと体を平たくして眠ります(睡眠中)。 呼吸で体がゆっくり膨らみ、Zzz が浮かびます。カーソルを近づけるかクリックで起床 — 驚かせるとぴょんと跳ねます(びっくり!)。
  • もぞもぞ這い — アザラシは腕立てができません。体を縮めて伸ばす尺取り虫の ギャロップでカーソルへ向かいます(接近中)。体の伸縮は easing.smoothstep。
  • おさかな — クリックで魚が氷に落ちます。急いで(アザラシなりに)駆け寄って、 ひげを揺らしながらもぐもぐ(もぐもぐ!)。
  • ころころ — ダブルクリックで横にごろんと一回転(ころころ!)。転がりは 回転行列ではなくカンバス変換に流し込んだ quat 由来の角度です。
  • 雪 — プールされた雪片がゆっくり降り続けます。氷の上に小さな吹きだまりも。
