Spirula Studio のしくみ

オープンソースの3D再構成アプリ Spirula Studio が、写真や動画から3Dモデルを作るまでの7つの工程を、ブラウザで動く小さな3Dシーンで順番にたどります。題材は、砂の上に置いた巻き貝（名前の由来のトグロコウイカ＝Spirula の殻）です。

  • GitHub リポジトリ
  • ダウンロード（Releases）
  • 公式 Web ビューア

このブラウザでは WebGL2 が使えないため、3D表示を省略しています。右側の説明はそのまま読めます。

ほかのツールと比べたときの強み

インストールが軽い
Python・PyTorch・COLMAP が要らず、アプリ1つで最後まで完結。Windows・Linux・macOS 版を配布。
GPU を選ばない
Vulkan で NVIDIA・AMD・Intel・Apple Silicon に対応。NVIDIA 向けの CUDA 版もあり。
8 GB → 1,000万個VRAM を節約
量子化して学習し、8GB の VRAM で最大約1,000万個の Gaussian（SH3）を扱える。
360°・魚眼
正距円筒（エクイレクタングラー）や魚眼の素材を、歪み補正なしでそのまま学習。
色むらに強い
バイラテラルグリッドと PPISP で、写真ごとの露出やホワイトバランスの差を吸収。
実寸スケール
撮影時の IMU・GPS の記録から、モデルの大きさと向きを実寸で復元。
リモート学習
クラウドの GPU で CLI 学習し、進み具合は SSH 越しにブラウザで確認。
13 言語日本語 UI
GUI と CLI の両方が日本語を含む13言語に対応。

使う前に確認したいこと

  • ライセンス GPLv3改変して配布するとソースの公開義務が生じます。業務で使ったり自社製品に組み込んだりする場合は、先に確認が必要です。
  • 動画の GPU デコードビルド時に SS_ENABLE_PATENTED=ON を付けた場合だけ有効です。H.264 / HEVC の特許への対応は利用者の責任で、OFF のときは外部の ffmpeg を使います。
  • SAM のモデルアプリには同梱されず、初回に規約を表示してからダウンロードします。SAM 2.1 は Apache-2.0、SAM 3 は Meta 独自のライセンスです。
  • 開発体制ほぼ1人で開発・保守されています。Issue や PR は歓迎されていますが、返信が遅れることもあります。

はじめ方

GUI で使ういちばん簡単

  1. Releases から自分の OS 用をダウンロード
  2. 解凍してダブルクリックで起動
  3. 「写真や動画からデータセットを作成…」で素材を選び、「学習を開始」

CLI で使うクラウド GPU など画面のない環境向け

my_scene/images/ に写真を置いた場合の例
spirula sfm auto my_scene/ -o my_scene/   # 撮影位置を求める
spirula geometry my_scene/                 # 深度・法線（任意）
spirula train --data my_scene/             # 学習（ブラウザで :7007 を開くと進捗が見える）
spirula mesh <checkpoint> --format glb     # メッシュ化（任意）

このページの3D表示は、しくみを説明するための模式図です。Spirula Studio 本体が出力したものではありません。学習のアニメーションも、実際の最適化を簡略化しています。
