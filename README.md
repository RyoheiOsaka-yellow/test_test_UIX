# かえるのうたのもり (Kaeru no Utanomori)

[mesqme/utanomori](https://github.com/mesqme/utanomori) へのオマージュ。
夜の森を歩いて三体の精霊を見つけ、そのうたを覚え直す — という遊びを、
**主人公をカエルにして**、**HTML 1ファイル**で作り直したものです。

`index.html` をブラウザで開くだけで遊べます。ビルド不要・依存ゼロ・アセットゼロ。

## あそびかた

| そうさ | |
|---|---|
| `WASD` / `↑←↓→` | はねる（カエルなので跳ねて進みます） |
| `Shift` | おおきくはねる |
| `Space` | したをのばす（ホタルをとる） |
| `C` | ケロと鳴く（のどぶくろがふくらみます） |
| `E` | 近くの精霊のうたをきく |
| クリック / `1`–`5` | うたいしをたたく |
| スマホ | 左半分をドラッグでジョイスティック、右下の「ペロ」「ケロ」ボタン |

画面の矢印が次の精霊の方角を、右上の表示が距離を示します。
精霊に近づいて `E` を押すと、うたいしが地面から立ち上がり、精霊がメロディを歌います。
それを同じ順番でたたき返す — これを 3 ラウンド。間違えても同じラウンドをやり直すだけです。
三体すべてのうたを覚えると夜が明け、エンディングになります。

## 元作品との対応

| utanomori | このカエル版 |
|---|---|
| React Three Fiber / three.js の 3D 夜の森 | Canvas 2D の疑似3D（Y ソート＋高さ方向オフセット） |
| チャンク単位のプロシージャル地形・草・小物 | 9 単位のチャンクを座標ハッシュで決定論的に生成（草・木・きのこ・岩・池・ハスの葉） |
| 三体の精霊とうたいし、3 ラウンドのメロディ再現 | 同じ（5 つのうたいし、3→4→5 音） |
| 6 レイヤーの BGM を鳴らしっぱなしで音量ミックス | WebAudio で合成した 3 つのペンタトニック・レイヤー＋ドローンを常時再生し、距離と進行で音量だけを変化 |
| loading → GO → intro → play → finale → credits | 同じフェーズ構成（テーマは夜→夜明けへ補間） |
| 歩く／走る、方向インジケータ | 跳ねる／大きく跳ねる、方向インジケータ |

## カエルらしさ

- 移動は連続歩行ではなく**ホップ**（助走・滞空・着地でスカッシュ＆ストレッチ）
- 池に入ると**キック＆グライドの泳ぎ**に変わり、波紋が広がる
- `C` で**のどぶくろ**がふくらみ、二段アタックの「ケロ」が鳴る
- `Space` で**舌**が伸びてホタルを捕まえる
- 精霊もカエル型（浮かぶ提灯ガエル）、うたいしの音は喉の震えを模した軽いピッチ・ワブル入り

## しくみ

- 描画: Canvas 2D。世界座標 → 画面は `SQUASH` による縦圧縮＋高さ分の持ち上げで擬似3D、Y ソートで前後関係を解決
- 生成: `mulberry32` と座標ハッシュで、同じ場所には常に同じ森が生える（チャンクはキャッシュ、上限超過で古い順に破棄）
- 音: すべて WebAudio で合成（オシレータ＋ノイズ＋生成インパルスのリバーブ）。音源ファイルは 0 バイト
- 性能: FPS を監視して遠景の草の密度を自動で落とす。`#debug` を URL に付けると FPS・チャンク数・状態を表示
