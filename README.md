# MORPHOSIS — インタラクティブ点群プロトタイプ

砂のように微細な点群(パーティクル)がさまざまな形にモーフィングし、形が変わるたびに
配色もランダムに変化する WebGL2 プロトタイプです。依存ライブラリなしの
単一 HTML(`index.html`)で動きます。

## 動かし方

`index.html` をブラウザで開くだけです。ローカルサーバも不要です。

```
open index.html          # macOS
# または
python3 -m http.server   # → http://localhost:8000
```

スマホ/タブレットのタッチ操作・ノッチ(セーフエリア)・縦長画面に対応しています。

## 形状サイクル(16種・ランダム巡回)

結び目トーラス / 球 / 銀河 / 折れ曲がる面 / 二重らせん / ハート / メビウスの帯 /
薔薇(花弁数ランダム) / 蝶の曲線 / 波紋ディスク / 巻貝の対数螺旋 / リサージュ軌道 /
スーパーシェイプ(数式パラメータを毎回ランダム化) / 環付き惑星 / 立方格子 /
多面体クリスタル(8・12・14・16・20・24面をランダム、面ごとに色分け)

約7.5秒ごとに自動でモーフィングします。変形はランダムな方向から波が走るように
順に始まり、各粒子は弧を描く曲線軌道で移動します。配色は変形のたびに
類似色・三色配色・補色スキームからランダム生成されます。

## インタラクション(タッチごとにランダム発動)

| 効果 | 内容 |
|---|---|
| ばらける | 触れた場所の粒子がランダムに飛散し、ゆっくり戻る |
| ついてくる | 押している間、粒子が指に吸い付いて追従 |
| ぐるぐる | 指の周りを渦巻き状に回転 |
| 波紋 | 触れた点から輪が広がり粒子を押しのける |

どの効果が出たかは画面下に一瞬表示されます。
**ダブルタップ**でいつでも次の形へモーフィングします。

## AIRモード(カメラで非接触操作)

右下の **📷 AIR** ボタンでフロントカメラの動き検出が有効になります。
画面に触れずに、カメラに向かって手を振るとその位置がポインタとなり、
タッチと同じランダムエフェクトが発動します(タッチとの併用も可能)。
フレーム差分による純JS実装で、外部ライブラリやモデルのダウンロードは不要です。
右下の小窓に動き検出のプレビュー(緑のモーションマスク)が表示されます。

カメラ利用にはブラウザの許可が必要です(HTTPS または手元で開いた
ローカルファイルで動作します)。

## パフォーマンス

FPS を常時計測し、フレームレートが落ちる端末では描画粒子数を自動で間引いて
滑らかさを維持します(余裕があれば自動で戻します)。

## チューニング

- 粒子数: `index.html?n=400000`(デフォルト: PC 28万 / モバイル 15万)
- 開始形状: `index.html?f=3`(0〜15)
- 乱数シード: `index.html?seed=42`(同じシードなら形・色の抽選を再現できます)
- 形状・色の定義: `index.html` 内の `SHAPES` 配列に生成関数を追加するだけで拡張可能

## 使用ライブラリ

数学カーネルとして [mathcat](src/vendor/mathcat.global.js)(アロケーションフリーの
vec/quat/mat4/easing/random モジュール)をインラインで同梱しています。
回転はクォータニオン slerp によるオーガニックなタンブリング、モーフ進行は
easing カーネル、乱数はシード付き mulberry32 を使用しています。

`src/inner.html` が本体(タイトル/スタイル/マークアップ/スクリプト)で、
`index.html` はそれをフルドキュメントに包んだものです。
