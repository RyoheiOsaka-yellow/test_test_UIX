# GLITCH FIELD — グリッチノイズ・インスタレーション制御プロトタイプ

縦ストリークのグレースケール平面に、白の階段状ブロック・黒の繊維バースト・
行ズレ・飛沫を重ねるジェネラティブビジュアルと、その制御盤のプロトタイプです。
依存ライブラリなしの単一 HTML(`index.html`)で、ブラウザで開くだけで動きます。

## 起動

```sh
# そのまま開くだけでも動く
open index.html

# もしくは簡易サーバ
python3 -m http.server 8000
# → http://localhost:8000
```

## 操作

- 右の制御盤でパラメータをリアルタイム操作(時間 / 質感 / 構造 / 破壊)
- プリセット: 標準 / 静寂 / 嵐 / 崩壊 / 白昼(反転)
- シード決定的 — 同じシード・同じパラメータなら同じ絵が再現される
- キー: `H` パネル表示 / `F` 全画面 / `R` ランダム / `Space` 停止 / `S` PNG 保存
- 「更新間隔」を上げるとコマ落ちしたようなスタッター表現になる

## 展示モード

URL パラメータで無人運転を想定した起動ができます。

```
index.html?preset=storm&seed=1024&hideui=1
```

## 外部制御(操作卓・OSC 連携の足場)

インスタレーション本番では別端末や OSC から叩く想定で、4 系統の入口があります。

1. **JS API** — `window.installation.set('burst', 0.9)` / `.preset('storm')` / `.randomize()` / `.seed(123)`
2. **postMessage** — iframe 埋め込み時に `{type:'set', id:'displace', value:0.8}` を送る
3. **WebSocket** — `?ws=ws://localhost:8080` で接続し、同形式の JSON を受信
   (OSC → WebSocket ブリッジを別途立てる想定)
4. **Web MIDI** — CC1 以降がパラメータ定義順に自動マッピングされる
   (CC1=速度, CC2=更新間隔, CC3=縦ストリーク, …)

## パラメータ一覧

| id | ラベル | 範囲 |
|---|---|---|
| `speed` | 速度 | 0–3 |
| `hold` | 更新間隔(フレーム) | 1–30 |
| `streaks` | 縦ストリーク | 0–1 |
| `grain` | 粒子 | 0–1 |
| `bright` | 明るさ | 0.2–0.9 |
| `contrast` | コントラスト | 0.5–2 |
| `levels` | 階調(ソリッド) | 0–16(量子化する階調数。0/1 で無効) |
| `burst` | 黒バースト | 0–1 |
| `spread` | バースト拡がり | 0–1 |
| `blocks` | 白ブロック | 0–1 |
| `bars` | 黒バー | 0–1 |
| `splatter` | 飛沫 | 0–1 |
| `displace` | 行ズレ量 | 0–1 |
| `slices` | 行ズレ回数 | 0–40 |
