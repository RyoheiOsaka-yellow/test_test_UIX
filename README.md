# GLITCH FIELD — グリッチノイズ・インスタレーション プロトタイプ

全画面のグリッチノイズが、フレームを消さずにとろけ続けるインスタレーションの
プロトタイプです。画面のどこに触れても作品が反応します。
依存ライブラリなしの単一 HTML(`index.html`)で、ブラウザで開くだけで動きます。

## 触れ方

- **タップ** — 突然変異。触れた場所に黒いバーストの芯が移り、構図・シード・質感が組み替わる(ときどきネガのフラッシュ)
- **ドラッグ** — 引き裂きと滲み。ポインタの高さで画面が水平に裂け、周辺が強く垂れる
- **放置** — 自動ドリフト。ゆっくり呼吸しながら、まれに自発的な突然変異を起こす

## 仕組み(とろけの核)

毎フレーム、画面を消さずに縦ストリップごとにノイズ量だけ下へずらす
「メルトパス」を通し、その上に FBM+ドメインワープの縦ストリーク・
繊維バースト・引き裂き・矩形シャッフルを低アルファで注ぎ続けます。
絵は常に流動し、二度と同じ状態に戻りません。

## 起動

```sh
open index.html
# もしくは
python3 -m http.server 8000
```

展示用の起動例(嵐プリセット・シード固定):

```
index.html?preset=storm&seed=1024
```

調整パネルは既定で隠れています。`H` キーか右上の ≡ で開閉。
`?hideui=0` で最初から開いた状態にできます。

キー: `H` パネル / `F` 全画面 / `R` ランダム / `Space` 停止 / `S` PNG 保存

## 外部制御(操作卓・OSC 連携の足場)

1. **JS API** — `window.installation.set('melt', 0.9)` / `.preset('storm')` /
   `.mutate(0.5, 0.3)`(0–1 正規化座標で突然変異)/ `.randomize()` / `.seed(123)`
2. **postMessage** — `{type:'set', id:'tear', value:0.8}` / `{type:'mutate', x:0.5, y:0.3}`
3. **WebSocket** — `?ws=ws://localhost:8080` で接続し、同形式の JSON を受信
   (OSC → WebSocket ブリッジを別途立てる想定)
4. **Web MIDI** — CC1 以降がパラメータ定義順に自動マッピング

## パラメータ一覧

| id | ラベル | 範囲 | 説明 |
|---|---|---|---|
| `speed` | 速度 | 0–3 | 時間の流れ |
| `melt` | とろけ | 0–1 | 下方向へ溶け落ちる量 |
| `viscosity` | 粘性 | 0–1 | 溶けた尾の伸び方 |
| `streaks` | 縦ストリーク | 0–1 | 縦の細線の量 |
| `complexity` | 複雑さ | 0–1 | FBM オクターブ数とドメインワープ |
| `grain` | 粒子 | 0–1 | フィルムグレイン |
| `bright` | 明るさ | 0.2–0.9 | ベースの明度 |
| `contrast` | コントラスト | 0.5–2 | 表示時のコントラスト |
| `levels` | 階調(ソリッド) | 0–16 | グレーの量子化段数 |
| `burst` | 黒バースト | 0–1 | 繊維状の黒の注入量 |
| `blocks` | 白ブロック | 0–1 | 階段状の白い構造 |
| `bars` | 黒バー | 0–1 | 黒い縦バー |
| `tear` | 引き裂き | 0–1 | 行スライスの水平ずれ |
| `shuffle` | シャッフル | 0–1 | 矩形転写(データモッシュ) |
| `touch` | タッチ強度 | 0–1 | 接触への反応の強さ |

プリセット: 標準 / 静寂 / 嵐 / 崩壊 / 白昼(反転)
