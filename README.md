# 縄文 — JOMON PATTERN DIVE

縄文土器の紋様（渦巻文・同心円文・縄目・波状沈線）の内側を、終わりなく遊覧するフルスクリーン WebGL 体験。

`index.html` をブラウザで開くだけで動作します（ビルド不要・依存なし）。

## 特徴

- レイマーチングによる無限トンネル。中心線は複数の正弦波で永遠に曲がり続け、同じ景色は二度と現れません
- 壁面の紋様はハッシュベースで手続き生成。3 スケールの区画に渦巻・同心円・縄目・波状文を敷き詰め、進むほど新しい紋様が現れます
- 距離に応じた LOD で微細な紋様は近づくと浮かび上がります
- テーマ切替: **火焔**（橙×青）／ **蒼冥**（青×白）／ **幽玄**（墨色の線刻）
- 端末負荷に応じて解像度を自動調整

## 操作

| 操作 | 効果 |
| --- | --- |
| ドラッグ | 視点を動かす（離すと正面へ戻る） |
| ホイール / ↑↓ / スライダー | 前進速度 |
| 右下ボタン | テーマ切替 |
