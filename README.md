# JOMON PATTERN DRIFT / NEURON DRIFT

## NEURON DRIFT（`neuro.html`）

脳神経の中に入り込み、ニューロンの森を彷徨うフルスクリーン WebGL 体験。

- mathcat のシード付き乱数で、細胞体・軸索・樹状突起・シナプスの粒を無限のチャンク空間に手続き生成
- 繊維はカメラ正対の発光リボン（ハロー + 芯）、細胞体は明滅し時折強く発火する光球
- 信号パルスが軸索の上を走って伝播する
- テーマ: 電脳（青×金）／ 蒼紅（シアン×赤）／ 紫宮（紫）
- カメラは mathcat の力学モデルで漂流（ドラッグで 360 度自由視点）

# JOMON PATTERN DRIFT

縄文土器の紋様に覆われた無限空間を、360 度見回しながら終わりなく漂うフルスクリーン WebGL 体験。

- `index.html` — カラー版（火焔 / 蒼冥 / 幽玄 のテーマ切替付き）
- `jomon-mono.html` — 白黒（墨色の線刻）版

どちらもブラウザで開くだけで動作します（ビルド不要・依存なし）。

## 特徴

- ジャイロイド曲面による全方位に無限に続く空間。別スケールの曲面で壁に窓を開け、奥の紋様層が何枚も透けて見える
- 紋様はハッシュベースの手続き生成。渦巻文・S 字連結渦巻文・同心円文・縄目・波状沈線・刺突文・条線を、向きも大きさも線幅も自由にばらつかせて敷き詰める
- 線は丸断面の隆線としてモデル化し、法線バンプ + 鏡面ハイライトで粘土紐の立体感を表現。ネオン状の発光と両立
- 手びねりのゆらぎ：紋様全体の歪み、線幅の揺れ、線の途切れ、壁面自体の低周波のうねり
- カメラの運動は同梱の数理カーネル mathcat による力学モデル：なめらかに変化するランダム加速度の二階積分で並進し、姿勢はクォータニオンで管理して角速度自体もゆっくり揺れ動く。シード付き乱数で訪れるたびに違う場所から違う漂い方をする。壁を抜ける際も暗転しない
- 端末負荷に応じて解像度を自動調整。`?rs=0.5` で解像度倍率を固定可能

## 操作

| 操作 | 効果 |
| --- | --- |
| ドラッグ | 視点を動かす（360 度自由） |
| ホイール / ↑↓ / スライダー | 漂う速さ |
| 右下ボタン（カラー版のみ） | テーマ切替 |
