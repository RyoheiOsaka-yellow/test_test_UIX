# MORPHOSIS — インタラクティブ点群プロトタイプ

微細な点群(パーティクル)がさまざまな形にモーフィングし、形ごとに色も変化する
WebGL2 プロトタイプです。依存ライブラリなしの単一 HTML(`index.html`)で動きます。

## 動かし方

`index.html` をブラウザで開くだけです。ローカルサーバも不要です。

```
open index.html          # macOS
# または
python3 -m http.server   # → http://localhost:8000
```

スマホ/タブレットのタッチ操作に対応しています(GitHub Pages 等に置くと実機で試せます)。

## 形状サイクル

結び目トーラス → 球 → 銀河 → 折れ曲がる面 → 二重らせん → ハート を約8.5秒ごとに
自動でモーフィングします。変形中は乱流で激しく崩れてから再構成され、
パレット(色)も形ごとに切り替わります。

## インタラクション

| 操作 | 効果 |
|---|---|
| **ばらける** モードでタッチ/ドラッグ | 触れた場所の粒子がランダムに飛散し、ゆっくり戻る |
| **ついてくる** モードで押しっぱなし | 粒子が指に吸い付いて追従する |
| **ぐるぐる** モードで押しっぱなし | 指の周りを渦巻き状に回転する |
| ダブルタップ / ⟳ 変形ボタン | 次の形へ即座にモーフィング |

## チューニング

- 粒子数: URL パラメータで変更 `index.html?n=400000`(デフォルト: PC 24万 / モバイル 12万)
- 形状・色の定義: `index.html` 内の `SHAPES` 配列(生成関数 + パレット)に追加するだけで拡張可能

`src/inner.html` が本体(タイトル/スタイル/マークアップ/スクリプト)で、
`index.html` はそれをフルドキュメントに包んだものです。
