# 羽田イノベーションシティ 3Dダッシュボード

`index.html` をブラウザで開くだけで動作する、単一ファイルの3Dインタラクティブダッシュボードです(Three.js同梱・データ埋め込み済み・オフライン動作可)。

## index.html — 3D 人流・図面ダッシュボード

IFC図面(HIC_Building A–E)から抽出したフロアプランを3D空間に積層し、K-field人流データと2026年推計を重ねて確認できます。

- **フロア表示切替** — B1F/1F/2F/3F/RF をチェックボックスで表示・非表示、フロア展開スライダーで階層を引き伸ばし
- **図面レイヤー** — 壁・カーテンウォール・階段のアウトライン(IFCから抽出した実図面)、フロア面の塗り
- **滞留ヒートマップ** — 5日間(2020/9/18–22)の位置ログを2mメッシュ×フロア別に集計。カーソルを当てると延べ滞在時間を表示
- **人流リプレイ** — 2020/9/18(金)の実測軌跡を時刻スライダー+再生速度(×60/×240/×900)でリプレイ。スタッフ/ビジター/ロボット/モビリティ別の粒子表示と稼働数カウント
- **2026年シナリオ** — 低位/中位/高位の推計シナリオに切り替えると、ビジター粒子が推計倍率で複製表示され、右下カードに来訪指数・平均滞在・年間来訪・経済波及(総合)の推計値を表示
- **周辺コンテキスト** — 京急空港線・東京モノレール・バス経路と天空橋駅ほか駅位置(模式表示)
- **図面モード / 自動回転 / 視点リセット**

## report.html — 2D 統計レポート

集計チャート版。時間帯別稼働、ゾーン別滞留、ビジター滞在時間分布(平均42.4分)、2020→2026推計の前提表、周辺エリア概略マップ、経済波及効果の感度分析(スライダー)、月次電力使用量。

## データ出所

- K-field 位置情報ログ CSV 5日分(2020/9/18–9/22、1秒間隔、約280万レコード、Shift_JIS)
- HIC_Building_1〜5.ifc(棟A/B/C/D(5)/E、ARCHICAD出力のBIMモデル)
- 月次電力使用量 CSV(2021/2/25更新)

## 注意事項

- K-fieldデータは**タグ装着者(実証実験の参加者・スタッフ・ロボット)のみ**の計測であり、施設全体の来訪者数ではありません。
- 2026年シナリオ・経済波及効果はページ内に明記した前提に基づく**試算**です。
- IFC座標とK-field座標(WGS84)の位置合わせは自動フィット(回転38°+並進、内包率78%)による近似です。周辺の鉄道・駅位置は模式表示です。

## 再ビルド

```bash
cd tools
# 1) 元CSVを data/kf_*.csv、IFCを data/b1..b5.ifc に配置
pip install ifcopenshell shapely
python3 extract_ifc.py     # -> plans.json (フロアプラン抽出)
python3 aggregate3d.py     # -> heat3d.json, traj.json (要 fit.json)
# 2) three.js をバンドルし、template3d.html の __DATA__ / __APP__ に注入
npm i three esbuild
npx esbuild app3d.js --bundle --minify --format=iife --outfile=app3d.bundle.js
```
