# 羽田イノベーションシティ 人流・地域効果ダッシュボード

`index.html` をブラウザで開くだけで動作する、依存ライブラリなしの単一ファイル可視化ページです(集計済みデータを埋め込み済み・オフライン動作可)。

## 内容

1. **施設内ヒートマップ** — K-field位置ログを約1mメッシュに集計した滞留マップ(スタッフ/ビジター/ロボット/モビリティ切替)
2. **時間帯別の動き** — 1時間ごとの稼働タグ数(日付切替)
3. **ゾーン別滞留・ビジター滞在時間分布** — マップレイヤー別の延べ滞在時間、滞在時間ヒストグラム(平均42.4分)
4. **2020→2026 変化推計** — 来訪指数と平均滞在時間の3シナリオ推計(前提係数をページ内に明記)
5. **周辺エリアマップ** — 鉄道(京急空港線・東京モノレール)・バスの経路と、経済波及効果の周辺エリア配分を重ねた概略図
6. **経済波及効果モデル** — 年間来訪者数・消費単価・産業連関乗数をスライダーで変えられる感度分析つき試算
7. **施設エネルギー** — 月次電力使用量(実測、2020/7–2021/1)

## データ出所

- K-field 位置情報ログ CSV 5日分(2020/9/18–9/22、1秒間隔、約280万レコード、Shift_JIS)
  - 列: `user_id, user_name, assigned_company, tag_id, tag_name, map_layer_id, map_layer_name, x(経度), y(緯度), created_at`
- 月次電力使用量 CSV(2021/2/25更新)

## 注意事項

- K-fieldデータは**タグ装着者(実証実験の参加者・スタッフ・ロボット)のみ**の計測であり、施設全体の来訪者数ではありません。
- 「2026年推計」「経済波及効果」はページ内に明記した前提に基づく**試算**であり、実測・公式値ではありません。
- 周辺マップは位置・線形を簡略化した**模式図**です。

## 再集計の方法

元CSVを `data/` ディレクトリに `kf_*.csv` として置き、次を実行すると `agg.json` / `grids.json` が生成されます:

```bash
python3 tools/aggregate.py
```

`index.html` 内の `const AGG = ...` / `const GRIDS = ...` を生成物で置き換えれば更新できます。
