羽田イノベーションシティ デジタルツイン — Navara × PLATEAU 版
====================================================================

■ これは何か
  Re:Earth のオープンソース3D地図エンジン「Navara」(Rust/WebAssembly + Three.js)を
  採用したバージョンです。地球規模の地形の上に、国土交通省 Project PLATEAU の
  3D都市モデル(大田区 2025年度・LOD2テクスチャ付き)をストリーミング表示し、
  その上に HICity の設計図面・人流・駅構造・新空港線(構想)を重ねています。

■ 起動方法（重要）
  このバージョンは WebAssembly と Web Worker を使うため、HTMLファイルの
  ダブルクリック（file://）では動作しません。付属のランチャーから起動してください。

    Windows … 「起動_Windows.bat」をダブルクリック
    Mac ……… 「起動_Mac.command」をダブルクリック
              （初回は右クリック →「開く」を選択してください）

  ブラウザで http://localhost:4173/ が開きます。終了はコンソール画面を閉じるか Ctrl+C。
  ※ Python 3 が必要です（Macは標準搭載、WindowsはMicrosoft Storeから無料で入手可）。
  ※ Node.js をお使いの場合は、このフォルダで `npx serve -l 4173` でも起動できます。

■ インターネット接続が必要です
  地形・航空写真（地理院タイル）と PLATEAU 3D都市モデルをネットワークから
  ストリーミングします。オフラインで使う場合は、従来版の
  「HICity_3Dダッシュボード.html」（単一ファイル・ダブルクリックで起動）をご利用ください。

■ 主な操作
  ・視点(飛行)   … HICity / 大田区全景 / 蒲田 / 京急蒲田 / 大森 / 羽田空港へ自動で飛行
  ・PLATEAU     … 建築物LOD2(テクスチャ) / 道路LOD3 / 橋梁LOD2 の切替
  ・ベースマップ … 地形(標高)のON/OFF、航空写真 / 地図 / なし の切替
  ・オーバーレイ … HICity図面(IFC)、施設内滞留ヒート、駅構造・路線、
                   新空港線(構想・赤)、列車運行、人流リプレイ
  ・時刻         … スライダーと再生速度(×60/×240/×900)。「太陽同期」ONで
                   日照が時刻に連動します（朝夕は影が長くなります）
  ・マウス       … 左ドラッグ:回転 / 右ドラッグ:移動 / ホイール:ズーム

■ 注記（本プロダクトはデモです）
  ・駅の構内配置、新空港線(蒲蒲線)の線形・駅位置は公開情報に基づく想定・概形です。
  ・列車の運行間隔は実ダイヤを参考にした目安であり、実際の時刻表とは異なります。
  ・新空港線は構想段階であり、未開業です（赤色で表示しています）。
