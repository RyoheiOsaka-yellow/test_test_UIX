# 実物インソール観察メモ（BestPosition / ファーストワン社）

参考写真：茶色スエードのトップカバー、左右一対、真上から撮影。
`L9_insole`（SPEC §4-5）の形状要件はこの観察に基づく。写真そのものは
機密扱いのためリポジトリには含めない。

## 外形

| 観察 | 実装への反映 |
|---|---|
| 全長タイプ。踵から趾先まで覆う | インソール外形は `v ∈ [0,1]` 全域を持つ。3/4 レングスではない |
| **趾が分離していない。先端は単一の丸みで閉じる** | `TOE_MERGE = 0.86` 以降を円弧キャップにブレンド。足シルエットの趾間の凹みを消す |
| 踵は足の輪郭より絞られ、円弧に近い | `HEEL_ROUND = 0.10` 以下を円弧キャップにブレンド |
| 外形が全体に平滑。母趾側の張り出しが足型より穏やか | 半幅プロファイルを `v` 方向に移動平均してから使う。`hvaDeg` は外形に反映しない |
| 最大幅は中足骨頭部（足長比 0.60 前後）にある | 足の半幅プロファイルと同じ位置。ここは変えない |

**最重要**：インソールの外形は足のシルエットではなく **靴のラスト（木型）の底面**に従う。
足の輪郭をそのまま押し出すと、顧客が手元の実物と結び付けられない絵になる。

## 上面

| 観察 | 実装への反映 |
|---|---|
| **内側縦アーチの盛り上がりが明確**。足長比 40〜50% 付近、内側寄りに単一の山 | `navicular` カーネル中心 `(-0.16, 0.44)`（SPEC §3-6） |
| 前足部はほぼフラット | 前足部に既定の補正を置かない。処方があるときだけ盛る |
| 踵は浅いカップ。縁がわずかに立ち上がる | `CUP_MM = 4.5`、`G(v; 0.10, 0.09) × 縁への近さ` |
| 趾の付け根から先は細かい凹凸がない | 足の高さ場を `SMOOTH_ITER = 6` 回平滑化してから補正を載せる |
| ロゴの箔押しがアーチ部にある | 装飾。Phase 0 では再現しない |

## 色

トップカバーは中間色の茶（スエード）。側面・底面の単色を `#B99A6B` とした（SPEC §8）。
ただし**上面は差分カラーマップで塗る**。実物の色を再現することが目的ではなく、
「義肢装具士が何 mm 持ち上げたか」を見せることが `L9` の目的であるため。
