# 来場者数カウンター（アスルクラロ沼津）

`index.html` 1枚で完結するページです。ビルド不要、そのままブラウザで開けます。

## 数字の更新

`index.html` 内の `const SEASON = { ... }` だけを書き換えてください。

- `matches` … 全ホームゲームの配列。`attendance` に実数を入れる
- `goals` … 目標ライン（3万 / 4.5万 / 5万）

`DEMO_PRESETS` と、ページ下部の「【デモ用】」ブロックは公開時に削除してください。
`PLAYED`（消化済み試合数）はデモ切り替え用の変数なので、公開時は
実際に消化した試合数を入れるか、`SEASON.matches.length` などに置き換えます。

## 公開前に必ず埋めるところ

### 1. リンク先（`LINKS`）

```js
const LINKS = { ticket:"", access:"", official:"" };
```

空のままだと、ボタンが「チケットを買う（URL未設定）」という
押せない灰色の表示になります（気づかず公開してしまわないための状態です）。

### 2. SNSカード（OGP）

`<head>` の `REPLACE-WITH-YOUR-DOMAIN` を公開ドメインに差し替えてください。
**`og:image` と `og:url` は絶対URLでないと X／Facebook が画像を取得できません。**
クローラーは JavaScript を実行しないので、ここだけは静的に書く必要があります。

カード画像は `assets/og.png`（1200×630）です。
**あえて来場者数を入れていません。** 数字を焼き込むと、更新のたびに
画像を作り直さないと古い数字が出回ってしまうためです。
節目のタイミングで「3万人突破」版に差し替える運用は問題ありません。

### 3. ハッシュタグ（`SHARE.tags`）

```js
const SHARE = { url:"", tags:["アスルクラロ沼津"] };
```

キャンペーンタグが決まったら 2つ目に足してください。
`url` は空ならページ自身のURLを使います。

## シェアの動き

| 環境 | 挙動 |
|---|---|
| スマホ | OS の共有シート（Web Share API）。X・LINE・Instagram など宛先を選べる |
| PC | X の投稿画面が開く（テキストとURLを事前入力） |
| 共通 | 「文章をコピー」で本文をクリップボードへ |

X は URL パラメータで画像を添付できません。
投稿に出る画像は、リンクが展開されたときの **OGPカードが担当**します。
そのため 2. の絶対URL設定を済ませないと、投稿が味気ない見た目になります。

## 「あなたが埋めたマス」

行った試合を選ぶと、その試合で埋まったマスがグリッド上で光り、
「合計何人の場にいたか／全体の何%か」が出ます。シェア文にも反映されます。

選択内容は `localStorage`（キー `acn26_mine`）にのみ保存され、
サーバーには送信しません。バックエンド不要で動きます。

## ロゴ・マスコット

いただいた Illustrator データからパスを起こして SVG 化しています。
`index.html` にはインラインで収録済み（外部画像の読み込みなし）なので、
HTML 1枚だけで完結します。

| ID | 内容 | 掲出箇所 |
|---|---|---|
| `#ac-emblem` | エンブレム（盾マーク） | 左上のクラブバー / 盤面の左上 / フッター |
| `#ac-wordmark` | ロゴタイプ「azul claro」 | 左上のクラブバー |
| `#ac-mascot` | アスルくん（正面） | 盤面の背景 / ひとことエリア / フッターの背景 |

別ファイルとしても `assets/` に置いてあります（他媒体での再利用用）。

```html
<svg><use href="#ac-emblem"/></svg>
```

### 元データについて

いただいた 2つの `.ai` は「PDF 互換ファイルを作成」を外して保存されていたため、
PDF として開くと Illustrator の注意書きしか表示されません。
実データは以下のとおり `.ai` 内部の非公開ストリームに入っていたので、
そこから展開してパス化しました。

- `_130222_azul_claro_logo.ai` … `%AI12_CompressedData`（zlib 圧縮）
- `azul_last_black.ai` … `%AI24_ZStandard_Data`（zstd 圧縮）

ロゴの `.ai` はガイドライン台紙（4C 版 / BK 版 / 色指定 / 版ごとの見本）だったため、
そのうち 4C のエンブレムとロゴタイプだけを切り出しています。
マスコットの `.ai` は正面・背面の 2 図だったため、正面のみを使用しています。

色は CMYK 指定だったので、ジャパンカラー相当のインキ原色を使った
減法混色で sRGB に変換しています（例: DIC 179s → `#00A0E9`、DIC 222s → `#001886`）。
BK 版のエンブレム・ロゴタイプが必要になった場合は、元データから同様に切り出せます。

## 動作について

- カウンター・マス・グラフは、それぞれ**画面に入った時点で**動き出します
  （先に全部動かすと、スクロールして着いた頃には終わっているため）
- 目標ラインを越えた瞬間、アスルくんが跳ねます
- グラフは棒にカーソルを乗せる／フォーカスすると内訳が出ます（キーボード操作可）
- `prefers-reduced-motion: reduce` の環境ではアニメーションを止めます
- 数字の桁は、動き終わったあと必ず実数とぴったり一致する位置で止まります
- 読み上げは、カウントアップ中ではなく確定値だけを1回読みます

## まだ手を付けていない案

- **来場者の声の投稿**：バックエンドか外部フォームが要ります
- **節目の自動お知らせ**：3万人突破時に自動投稿するなら、更新の仕組みとセットで
- **数字入りOGP画像**：更新のたびに画像生成が必要なので、動的生成の仕組みが前提
