# 対戦相手のロゴ

ここに画像を置いて、`index.html` の `SEASON.matches` から参照します。

```js
{ round: 1, date: "3/8", vs: "A FC", attendance: 3412, result: "W",
  logo: "assets/opponents/a-fc.svg" }
```

- 形式は SVG / PNG どちらでも構いません（背景透過を推奨）
- **正方形**で書き出してください。円形に切り抜いて表示します
- `logo` を書かない試合は、チーム名の頭文字バッジで表示されます。
  全チーム分そろっていなくてもレイアウトは崩れません
- 画像が見つからなかった場合も、自動で頭文字バッジに切り替わります

各クラブのロゴには利用規定があります。掲載前に必ずご確認ください。
