# 対象エリア選定（フェーズ0）

作成日: 2026-09-21　ステータス: **暫定決定 = 岡山市中心部**（人間の最終判断待ち。docs/QUESTIONS.md Q1）

## 選定基準（SPEC 4.3）

1. 直近数年分の歩行者通行量調査が **地点・時間帯付きで公開**されている（必須）
2. PLATEAU の建物用途・階数属性が整備されている
3. 駅を含み、商業地と住宅地が混在している
4. 将来の営業先になり得る（自治体案件化の可能性）

## 決定（暫定）

**岡山市中心部**（bbox 133.905–133.945E, 34.650–34.680N、約 3.6km × 3.3km）を v0.1 の対象とする。

- 決め手: 通行量が **機械可読・継続・オープンライセンス**で公開されている唯一の候補。自治体自身が通行量データを施策評価に使っているため、UC-G1（施策差分）の営業ストーリーが作りやすい。
- 補強策: 隔年の「商店街等通行量調査」（時間帯別）を手入力 CSV（`data/raw/counts_manual/`）で追加し、較正地点を増やす。
- 次点: 札幌市。FlatGeobuf 配布と地下歩行空間データがあり、v0.2 の 2 エリア目に適する。
