# 🏀 バスケットボール トラッキング分析 プロトタイプ

試合映像から**全選手(5対5)とボールをトラッキング**し、戦術の振り返り・次戦への
活用を目的とした詳細データを自動抽出するプロトタイプです。

入力映像はダミー(内蔵の試合シミュレータが生成する俯瞰映像)ですが、
**パイプライン本体は映像だけを入力**として動作します。実映像への移行時は
検出器とキャリブレーションの2箇所を差し替えるだけの構成です。

## 実行方法

```bash
pip install -r requirements.txt
python run_pipeline.py --duration 60 --fps 25 --seed 42 --out output
```

出力(`output/`):

| ファイル | 内容 |
|---|---|
| `raw.mp4` | 生成されたダミー試合映像(入力に相当) |
| `annotated.mp4` | トラッキング結果を重畳した映像(ID・軌跡・保持者・ボール) |
| `report.html` | 戦術振り返りレポート(ヒートマップ/パスネットワーク/シュートチャート等) |
| `tracks.csv` | 毎フレームの選手コート座標 [m]・速度(トラックID別) |
| `ball.csv` | 毎フレームのボールコート座標 [m] |
| `player_stats.csv` | 選手別集計(距離・速度ゾーン・スプリント・タッチ・パス・シュート) |
| `events_detected.json` | トラッキングから推定したイベント(パス/TO/シュート/保持区間) |
| `events_ground_truth.json` | シミュレータの正解イベント(精度評価用) |
| `evaluation.json` | 真値との突合による精度指標 |

## パイプライン構成

```
シミュレーション ──► ダミー映像 raw.mp4          ┌ 真値ログ (評価専用)
      │                    │                     │
      ▼                    ▼                     ▼
 [1] 生成          [2] 検出 + トラッキング   [5] 精度評価
                    (色検出 → カルマン+       (RMSE / ID一貫性 /
                     ハンガリアン対応付け)      イベントP/R)
                           │
                    [3] ホモグラフィで
                        コート座標 [m] へ
                           │
                    [4] 分析・イベント推定
                           │
                    [6] レポート / 注釈映像 / CSV
```

- **検出** (`src/bball_tracker/detection.py`) — ダミー映像用の色ベース検出器。
  `Detection` のリストを返すインターフェースに合わせれば YOLOv8 等へ差し替え可能。
- **トラッキング** (`tracking.py`) — SORT系。等速カルマンフィルタ + ハンガリアン法。
  同色選手の重なり(ブロブ結合)は未観測許容で乗り切り、ID を維持する。
- **キャリブレーション** (`calibration.py`) — コート基準点4点からホモモグラフィを推定し
  ピクセル → コート実座標 [m] に変換。実映像ではコート4隅などを指定する。
- **分析** (`analytics.py`) — トラッキング結果のみから算出(真値は不使用):
  - フィジカル: 走行距離、平均/最高速度、速度ゾーン別距離(ウォーク/ジョグ/ラン/スプリント)、
    スプリント回数、加速回数
  - ボール保持: 近接+ヒステリシス+ボール連動性による保持者推定と保持区間
  - イベント: パス、ターンオーバー(シュート起因の攻守交代は除外)、
    シュート(リング接近 + 進行方向 + 速度不連続の3条件)
- **評価** (`evaluate.py`) — シミュレータ真値と突合し、位置RMSE・検出カバレッジ・
  ID一貫性・イベント適合率/再現率を算出してレポートに表示。

## 現状の精度(60秒・2シード)

| 指標 | 値 |
|---|---|
| 選手位置 RMSE | 0.13–0.17 m |
| ID 一貫性 | 93–96 % |
| ボール検出カバレッジ | 100 % |
| パス検出 | 適合率 0.91–1.00 / 再現率 0.50–0.71 |
| シュート検出 | 適合率 0.80–1.00 / 再現率 0.67 |

短時間(0.3秒未満)の保持を挟む速いパス回しの取りこぼしが主な課題。
改善候補: ボール軌跡の折れ点検出によるパス推定、保持判定の学習ベース化。

## 実映像への移行時に差し替える箇所

1. `ColorDetector` → YOLO 系検出器(選手・ボール・チーム色分類)。
   `Detection(cx, cy, area, kind)` を返せばトラッキング以降は共通。
2. `CourtCalibration` に渡す基準点 → 映像上のコート4隅(手動クリック or 自動検出)。
3. (推奨)背番号 OCR / ReID を追加してトラックIDを実名に紐付け。

## 開発メモ

- ダミー映像にはガウスノイズを付与し、mp4 圧縮を経由して検出するため、
  検出・トラッキングは「きれいな座標」ではなく現実的な観測誤差の下で動作する。
- パイプラインは真値を一切参照しない(真値は評価とスコア表示のみに使用)。
