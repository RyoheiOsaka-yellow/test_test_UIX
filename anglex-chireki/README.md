# ANGLEX 地歴スクリーニング（プロトタイプ）

単一HTML（`index.html`）で動く地歴調査の台紙。ブラウザで開くだけで動作します。

## タブ

| タブ | 役割 |
|---|---|
| 調査 | 地点・年代別空中写真・判読・法指定区域・周辺事業場 → リスク指標。法規制パネルは土対法＋**条例レジストリ**（住所から都道府県・政令市を判定）で評価 |
| 閉鎖謄本 | 手書き謄本の画像をAIで構造化し、所有者の業種からリスクに反映 |
| データソース | 公開データの一覧と自動化の可否 |
| 取込 | 要措置区域一覧・水濁法届出事業場・PRTRのCSV取込 |
| 報告書 | 既往の地歴調査報告書PDFの**読み取り → 整合性チェック → 法・条例照合 → 同じ章立ての下書き生成** |

## 報告書タブ

- **読み取り**：PDFをドロップし Claude API で章ごとにJSON化（調査概要／関連法規／法規制の確認結果／登記履歴／地図・空中写真の利用履歴／ヒアリング・法人登記／所見／ページ参照）。APIキーはブラウザ内でのみ使用。
- **サンプル**：実物2通（大阪市東住吉区駒川 2023・渋谷区西原 2024）を読み取り済みデータとして同梱。
- **整合性チェック**：地積（筆一覧＝敷地面積＝登記簿）、地番、年次の昇順と和暦⇄西暦、利用履歴・ヒアリング・法人目的のキーワードと所見の整合、法規制7項目の網羅、条例確認の有無、引用法令の改正年、ヒアリング日と調査期間、根拠資料と添付資料、登記名義人と住宅地図の対応。
- **法・条例照合**：土対法3条・4条・6/11条と、該当都道府県・政令市の条例を 面積要件／有害物質取扱施設の廃止／台帳 の3種のトリガーで評価。
- **下書き**：調査タブの状態・閉鎖謄本・読み込んだ報告書から、エコ・テック社報告書と同じ章立て（1.1〜1.7、2.1〜2.6、添付資料）を生成。本文は直接編集可。印刷（PDF保存）・JSON保存。
- **反映**：読み取った報告書の住所・面積・地形・利用履歴（工場等の年代）を調査タブへ流し込み、リスク指標に「既往報告書」因子を追加。

## 条例レジストリ

`index.html` 内の `ORD` 配列。都道府県（＋政令市）ごとに `rules[]` を持ち、各ルールは
`{art, trigger:'area'|'facility'|'ledger', th, title, duty, conf:'high'|'mid'|'low'}`。
`conf` は **high=条文・閾値を確認済（東京都のみ）／mid=条文番号は要確認／low=法務確認前の下書き**。
報告書タブの「条例レジストリ」からJSONで差し替え・保存できます。法務確認が済んだら `conf` を `high` に上げてください。

## 既知の制約

- Claude API は `anthropic-dangerous-direct-browser-access` でブラウザから直接呼びます。本番ではサーバー経由にしてください。
- 住所→座標は国土地理院の町丁目代表点。区画の位置は概略です。
- 法指定区域・事業場の点はデモ用サンプル。実データは取込タブから。
